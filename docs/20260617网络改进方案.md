# Conv-Spatial EIT 网络改进方案

> 基于 mixed_dataset 验证结果 (RE=0.331) 与 GPT 算法优化咨询报告的综合改进计划

---

## 问题定位

| 基准 | 数据集 | RE | CC | 说明 |
|------|--------|:--:|:--:|------|
| v2 | circle-only (固定4x对比度) | 0.108 | 0.976 | 单一分布，模型学统计映射即可 |
| v3 | mixed (4形状+随机2-9x对比度) | 0.331 | 0.918 | 分布变宽，统计映射失效 |

**根因**（引自 GPT 咨询报告）：
> GridSampler 将 13×16 的电压特征图采样到 FEM 网格——但电压特征图的坐标轴并不直接对应 EIT 域内的 (x,y) 空间位置，模型实际在"学习统计映射"而非"物理重建"。

## Phase 1：轻量改进（预计 RE ↓ 20-30%）

### 1.1 Jᵀr 物理残差反投影特征

**核心思路**：将电压残差通过 Jacobian 转置反投影到 FEM 网格，直接告诉 GNN "当前预测在哪里偏差最大"。

#### 修改 `models/conv_spatial_eit.py`

**a) `setup_mesh()` 新增 Jacobian 参数**

```python
def setup_mesh(self, centers: np.ndarray, elements: np.ndarray,
               jacobian: Optional[np.ndarray] = None,
               sigma_ref: float = 0.01):
    """设置网格 + 位置编码 + Jacobian"""
    # ... 原有代码不变 ...
    
    # ── 新增：Jacobian 残差反投影 ──
    self.sigma_ref = sigma_ref
    if jacobian is not None:
        J = torch.from_numpy(jacobian).float()  # (n_meas, n_elems)
        self.register_buffer('J', J)
        self.register_buffer('J_T', J.T.contiguous())  # (n_elems, n_meas)
        # 残差校正头（输入维 +1）
        corr_in = self.gnn_hidden + 1
        self.correction_head = nn.Sequential(
            nn.Linear(corr_in, self.gnn_hidden // 2),
            nn.GELU(),
            nn.Dropout(self.gnn_dropout * 0.5),
            nn.Linear(self.gnn_hidden // 2, 1),
        )
        print(f"  [ConvSpatial] Jacobian 加载: {jacobian.shape}, "
              f"校正头输入: {corr_in}维")
    else:
        # 无 Jacobian 时，用恒等映射
        self.correction_head = nn.Identity()
```

**b) `forward()` 新增残差反投影路径**

```python
def forward(self, voltages: torch.Tensor) -> dict:
    B = voltages.shape[0]
    device = voltages.device

    # ── 多频融合 ──
    if voltages.dim() == 3:
        x = voltages.view(B, 6, 13, 16)
    else:
        x = voltages
    x = self.freq_fusion(x)           # (B, 1, 13, 16)

    # ── 输入归一化 ──
    amax = x.flatten(1).abs().max(dim=1)[0].view(B, 1, 1, 1) + 1e-8
    x = x / amax

    # 1. Conv 编码
    feat = self.encoder(x)            # (B, 128, 13, 16)

    # 2. Grid Sampling
    node_feat = self.sampler(feat)    # (B, n_elems, 128)

    # 3. 拼接位置编码
    pe = self.pos_encoding.to(device).unsqueeze(0).expand(B, -1, -1)
    h = torch.cat([node_feat, pe], dim=-1)  # (B, n_elems, 128+pos_dim)

    # 4. GNN 主路径
    if self._edge_idx is not None:
        edge_idx = self._edge_idx.to(device)
        edge_weight = self._edge_weight.to(device)
        for gnn in self.gnn_blocks:
            h = gnn(h, edge_idx, edge_weight)   # (B, n_elems, gnn_hidden)

    # 5a. 初始预测 σ₀（当前主路径输出）
    sigma_0 = self.output_head(h).squeeze(-1)   # (B, n_elems)

    # 5b. Jᵀr 残差反投影（新增）
    if hasattr(self, 'J'):
        # 线性化电压：V_lin ≈ J·σ₀  (相对 σ_ref 的偏移)
        sigma_delta = sigma_0 - self.sigma_ref   # (B, n_elems)
        V_lin = (self.J.unsqueeze(0) @ sigma_delta.unsqueeze(-1)
                 ).squeeze(-1)                   # (B, n_meas)
        
        # 电压残差：使用多频融合后的单频电压
        V_meas = x.squeeze(1).view(B, -1)        # (B, 208), flatten 13×16
        r = V_meas - V_lin                        # (B, n_meas)
        
        # 反投影到网格
        g = (self.J_T.unsqueeze(0) @ r.unsqueeze(-1)
             ).squeeze(-1)                        # (B, n_elems)
        
        # 拼接到 GNN 特征
        h_corr = torch.cat([h, g.unsqueeze(-1)], dim=-1)  # (B, n_elems, gnn_hidden+1)
        delta = self.correction_head(h_corr).squeeze(-1)   # (B, n_elems)
    else:
        delta = 0.0

    # 5c. 最终输出
    sigma = sigma_0 + delta
    sigma = torch.sigmoid(sigma) * (self.sigma_max - self.sigma_min) + self.sigma_min

    return {
        'sigma': sigma,
        'sigma_0': sigma_0,     # 初始预测（用于消融分析）
        'delta': delta,          # 残差修正量
        'residual': r if hasattr(self, 'J') else None,  # 电压残差
    }
```

**c) `train_conv_spatial.py` 中传入 Jacobian**

### 1.2 残差输出 (σ₀ → Δσ)

已在 1.1 的 `forward()` 中实现。关键要点：

```
σ = σ₀ + Δσ
   ↑     ↑
  GNN主路径  校正头 (轻量 MLP)
```

- σ₀ 从当前主路径获取（保持现有架构不变）
- Δσ 从校正头输出（新增轻量 MLP）
- 最终 σ 用 Sigmoid 约束到 [σ_min, σ_max]（保持与现有输出一致）
- **验证时也输出 σ₀，做消融：对比 σ₀ vs σ 的 RE 差异**

### 1.3 边特征增强

**修改 `SimpleGNNLayer` → `EdgeFeatureGNNLayer`**

```python
class EdgeFeatureGNNLayer(nn.Module):
    """
    边特征感知的图卷积层
    
    边特征 e_ij:
      - 单元中心距离 (归一化)
      - 共享边长 (归一化)
      - 单元面积比
      - 初始重建差异 |σ⁰_i - σ⁰_j|
    """
    def __init__(self, in_dim: int, out_dim: int, edge_dim: int = 4,
                 dropout: float = 0.1):
        super().__init__()
        self.edge_net = nn.Sequential(   # 边特征编码
            nn.Linear(edge_dim, out_dim),
            nn.GELU(),
        )
        self.node_net = nn.Sequential(   # 节点更新
            nn.Linear(in_dim + out_dim, out_dim),
            nn.LayerNorm(out_dim),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(out_dim, out_dim),
            nn.LayerNorm(out_dim),
        )

    def forward(self, x, edge_idx, edge_weight, edge_feat=None):
        B, N, D = x.shape
        device = x.device
        
        # 边消息聚合
        n_edges = edge_idx.shape[1]
        src, dst = edge_idx
        
        # 边特征编码（共享 MLP）
        if edge_feat is not None:
            e_feat = self.edge_net(edge_feat)  # (n_edges, out_dim)
        else:
            e_feat = edge_weight.unsqueeze(-1).expand(-1, D)
            e_feat = self.edge_net(e_feat) if hasattr(self, 'edge_net') else e_feat
        
        # 消息传递（chunk 分块防止 OOM）
        x_agg = torch.zeros(B, N, self.node_net[0].in_features - D,
                           device=device)
        chunk_size = 20000
        for start in range(0, n_edges, chunk_size):
            end = min(start + chunk_size, n_edges)
            s, d, ef = src[start:end], dst[start:end], e_feat[start:end]
            msg = torch.cat([x[:, s], ef.unsqueeze(0).expand(B, -1, -1)], dim=-1)
            x_agg.scatter_add_(1,
                d.view(1, -1, 1).expand(B, -1, msg.shape[-1]),
                self.node_net[0](msg.view(B * (end-start), -1)
                                 ).view(B, end-start, -1))
        
        h = torch.cat([x, x_agg], dim=-1)
        h = self.node_net(h.view(B * N, -1)).view(B, N, -1)
        return h
```

**在 `setup_mesh()` 中预计算边特征**：

```python
# 边特征： [距离, 共享边长, 面积比, 灵敏度相似性]
n_edges = edge_list.shape[1]
edge_feat = np.zeros((n_edges, 4), dtype=np.float32)

for e_idx, (i, j) in enumerate(zip(edge_list[0], edge_list[1])):
    ci, cj = centers[i, :2], centers[j, :2]
    edge_feat[e_idx, 0] = np.linalg.norm(ci - cj)  # 距离
    
    # 共享节点数量 → 近似共享边长
    shared = len(set(elements[i]) & set(elements[j]))
    edge_feat[e_idx, 1] = shared / 3.0  # 归一化
    
    # 面积比（若可用）
    # edge_feat[e_idx, 2] = ...

self.register_buffer('edge_feat', torch.from_numpy(edge_feat).float())
```

**pyEIT Tikhonov 接口**（在 `EITForwardSolver` 中新增）：

```python
def solve_tikhonov(self, voltages, lambda_reg=0.01):
    """快速 Tikhonov 重建"""
    jac = self.jacobian  # (n_meas, n_elems)
    JtJ = jac.T @ jac
    JtV = jac.T @ (voltages - self.ref_voltages)
    reg = lambda_reg * np.eye(JtJ.shape[0])
    delta_sigma = np.linalg.solve(JtJ + reg, JtV)
    return self.ref_sigma + delta_sigma
```

## Phase 3：论文版完整框架

```
PG-MeshGNN: 物理引导的 FEM 图神经网络 EIT 重建
=============================================

输入: V (多频边界电压)
        ↓
Branch A: Tikhonov/GN 初始重建 → σ₀
Branch B: Jᵀ(V - F(σ₀))        → g (残差反投影)  
Branch C: ConvEncoder(V)        → z_v (全局电压特征)
        ↓
FEM 图节点特征: h_i = [σ₀_i, g_i, s_i, x_i, y_i, r_i, z_v]
        ↓
Edge-aware MeshGNN (4层, 含边特征距离/共享边/面积比)
        ↓
Δσ = MeshGNN(h)
σ̂ = σ₀ + Δσ
        ↓
Loss: L_img + λ_v·L_voltage + λ_r·L_residual + λ_gTV·L_gTV
```
