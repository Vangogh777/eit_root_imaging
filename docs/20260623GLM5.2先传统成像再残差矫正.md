## 1. 问题诊断：当前路线A的系统性瓶颈

### 1.1 路线A的本质

```
V → 神经网络 → σ（绝对值）
```

所有现有模型（SFSBLC、Conv-Spatial EIT、PhysicsGNN）都是端到端直接映射。网络的输出是从零开始预测绝对电导率，物理约束仅通过损失函数事后施加。

### 1.2 三个根本性矛盾

**矛盾1：Jacobian线性化半径 vs. 电导率动态范围**

`MeasurementConsistencyLoss`（`training/loss.py:69-75`）的核心计算：

```python
V_jac = J @ (σ_pred - σ_ref)    # σ_ref = 0.01 S/m
```

这是一阶Taylor展开，仅在 $\|\sigma - \sigma_{ref}\| \ll \sigma_{ref}$ 时有效。但EIT中目标电导率可以是背景的5-10倍（如 $\sigma_{soil}=0.01$, $\sigma_{inclusion}=0.05\text{-}0.1$），此时 $\Delta\sigma / \sigma_{ref} = 4\text{-}9$，线性化误差巨大。

监督训练时，GT $\sigma$ 直接拉住预测，Jacobian只需提供梯度方向即可；无监督时，Jacobian线性化既是唯一的物理锚点，又是严重失准的——模型必然漂移。

**矛盾2：SigmaDeviationLoss vs. 重建目标**

`SigmaDeviationLoss`（`training/loss.py:314-340`）惩罚 $\sigma$ 偏离 $\sigma_{ref}=0.01$：

```python
loss = ||σ_pred - σ_ref||² / n_elems
```

这个loss的存在是为了保护Jacobian线性化的有效性，但它和重建高电导率包含物的目标直接冲突：

- 去掉 → 模型漂移，物理约束失效
- 保留 → 模型被拉向 $\sigma=0.01$，学不到 $\sigma > 0.01$ 的目标

这是路线A的结构性矛盾，调权重只是治标。

**矛盾3：GridSampler的物理语义缺失**

Conv-Spatial EIT的GridSampler（`models/conv_spatial_eit.py:145-174`）将 $13 \times 16$ 的feature map（激励模式 $\times$ 测量通道）通过双线性插值映射到FEM网格。但 $13 \times 16$ 的坐标轴不是物理空间坐标，feature map中的空间结构主要靠网络学习，缺乏物理投影的先验。

### 1.3 诊断总结

| 问题 | 根因 | 路线A能否解决 |
|------|------|--------------|
| 无监督漂移 | Jacobian线性化在大偏差下失效 | 不能（结构性矛盾） |
| SigmaDeviationLoss冲突 | 线性化约束 vs. 重建目标 | 只能调权重妥协 |
| GridSampler物理含义弱 | 非物理坐标到物理空间的桥接靠学习 | 不能（架构限制） |
| 多频信息浪费 | pyEIT不区分频率，6频=6份相同数据 | 需要物理模型扩展 |

## 2. 路线B的核心思想

### 2.1 数据流

```
V → 传统重建(GN/SBL) → σ₀ → r=V-F(σ₀) → g=Jᵀr → MeshGNN(σ₀, g, z_v) → Δσ → σ̂=σ₀+Δσ
     ↑                                               ↑
     └── 独立于网络，可微分停止 ──┘    └── ConvEncoder全局特征 z_v
```

**关键转变**：网络从"预测绝对值 $\sigma$"变为"预测残差 $\Delta\sigma$"。

### 2.2 为什么路线B根本性地解决了路线A的矛盾

**对矛盾1**：$\sigma_0$ 已经是传统重建给出的物理合理初始解，满足 $F(\sigma_0) \approx V$ 到一定程度。网络只需修正小残差 $\Delta\sigma$，此时测量一致性损失

$$\|F(\sigma_0 + \Delta\sigma) - V\|^2 \approx \|J \cdot \Delta\sigma + (F(\sigma_0) - V)\|^2$$

因为 $\Delta\sigma$ 小，线性化误差小，Jacobian约束可靠。

**对矛盾2**：残差学习框架下不再需要SigmaDeviationLoss。替代为残差约束 $\|\Delta\sigma\|_1$，鼓励网络做最小修正，不与重建目标冲突。

**对矛盾3**：$J^T r$ 是天然的空间物理特征——Jacobian转置直接将电压残差从测量空间投影到FEM网格单元空间，物理含义明确：每个单元对电压残差的"责任"大小。不需要GridSampler从非物理特征图采样。

### 2.3 路线B vs. 路线A对比

| 维度 | 路线A (端到端 V→σ) | 路线B (先重建再残差校正) |
|------|-------------------|------------------------|
| 网络任务 | 预测绝对值σ（范围0.005-0.1） | 预测残差Δσ（范围通常<0.01） |
| Jacobian线性化 | 在σ_ref附近线性化，大偏差失准 | 在σ₀附近线性化，Δσ小，线性化准确 |
| 无监督可行性 | 差（物理约束弱） | 好（物理约束强且准确） |
| 初始解质量 | 无（从随机初始化开始） | σ₀已是物理合理的粗解 |
| 物理特征 | GridSampler（非物理桥接） | Jᵀr（直接物理投影） |
| 泛化能力 | 差（依赖训练数据覆盖） | 好（传统重建提供域无关基线） |
| 复杂结构 | 容易学成模糊团 | σ₀已有结构，GNN只做细化 |
| 额外计算 | 无 | 传统重建前置步骤（可并行批处理） |

## 3. 架构设计

### 3.1 总体架构：ResidualEIT

```
┌──────────────────────────────────────────────────────────────────────┐
│                        ResidualEIT Pipeline                         │
│                                                                      │
│  Input: V (B, n_freq, n_meas)                                       │
│    │                                                                 │
│    ├─→ [Branch A] TraditionalReconstructor ──→ σ₀ (B, n_elems)      │
│    │        (GN/SBL, 不参与梯度)                                      │
│    │                                                                 │
│    ├─→ [Branch B] ResidualComputer ──→ g = Jᵀ(V-F(σ₀)) (B,n_elems) │
│    │        (可微分)                                                   │
│    │                                                                 │
│    ├─→ [Branch C] ConvEncoder ──→ z_v (B, D)                        │
│    │        (全局电压特征)                                             │
│    │                                                                 │
│    └─→ [Merge] MeshGNN(node_feat=[σ₀, g, pe], global=z_v)           │
│              ──→ Δσ (B, n_elems)                                     │
│              ──→ σ̂ = σ₀ + Softplus(Δσ)                              │
│              ──→ σ̂ = clamp(σ̂, σ_min, σ_max)                        │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 Branch A：传统重建模块

**现状**：`TwoStageEITModel`（`models/two_stage_model.py`）已实现BP和JAC，但存在以下问题：

1. **只支持BP/JAC**，缺少SBL/BSBL等对稀疏包含物更优的算法
2. **BP重建质量差**，仅提供模糊轮廓
3. **JAC容易奇异矩阵问题**（`two_stage_model.py:44-49`）
4. **未集成到主训练流程**中，只是独立模型

**改进方案**：

#### 3.2.1 增加SBL（Sparse Bayesian Learning）重建

SBL对EIT的稀疏包含物场景天然适合：

```python
class SBLReconstructor:
    """
    稀疏贝叶斯学习重建器

    原理：
      1. 似然模型: V = J·Δσ + ε,  ε ~ N(0, Σ_noise)
      2. 先验: Δσ ~ N(0, diag(α⁻¹)),  α通过Type-II ML自动估计
      3. 自动确定稀疏性：不需要手动调正则化参数

    优势（vs BP/JAC）：
      - 自动稀疏性：对EIT中少量高电导率包含物更准确
      - 自适应正则化：不需要手动调λ
      - 不确定性量化：每个单元的重建方差可用作GNN的置信度特征
    """

    def __init__(self, J, V_ref, sigma_ref, max_iter=50, tol=1e-4):
        self.J = J                    # (n_meas, n_elems) Jacobian
        self.JTJ = J.T @ J           # (n_elems, n_elems) 预计算
        self.V_ref = V_ref           # (n_meas,) 参考电压
        self.sigma_ref = sigma_ref   # (n_elems,) 参考电导率
        self.max_iter = max_iter
        self.tol = tol

    def reconstruct(self, V_meas):
        """
        SBL重建

        参数:
            V_meas: (n_meas,) 测量电压（绝对值）

        返回:
            sigma: (n_elems,) 重建电导率
            variance: (n_elems,) 重建方差（不确定性）
        """
        delta_v = V_meas - self.V_ref   # 差分电压
        J = self.J
        n_meas, n_elems = J.shape

        # 初始化超参数 α
        alpha = np.ones(n_elems)        # 精度超参数
        beta = 1.0 / np.var(delta_v)    # 噪声精度

        for iteration in range(self.max_iter):
            # 后验协方差和均值
            Sigma = np.linalg.inv(np.diag(alpha) + beta * self.JTJ)
            mu = beta * Sigma @ J.T @ delta_v

            # 更新超参数 (Type-II ML)
            gamma = 1 - alpha * np.diag(Sigma)
            alpha_new = gamma / (mu**2 + 1e-10)

            # 噪声精度更新
            beta_new = (n_meas - gamma.sum()) / \
                       (np.sum((delta_v - J @ mu)**2) + 1e-10)

            # 收敛检查
            if np.max(np.abs(alpha_new - alpha) / (alpha + 1e-10)) < self.tol:
                break
            alpha = alpha_new
            beta = beta_new

        # 后验统计量
        Sigma_final = np.linalg.inv(np.diag(alpha) + beta * self.JTJ)
        mu_final = beta * Sigma_final @ J.T @ delta_v
        variance = np.diag(Sigma_final)

        # 转换为绝对电导率
        sigma = self.sigma_ref + mu_final
        sigma = np.clip(sigma, 0.001, 0.2)

        return sigma.astype(np.float32), variance.astype(np.float32)
```

#### 3.2.2 增加BSBL（Block Sparse Bayesian Learning）

对具有空间连续性的包含物（不是点状而是区域状），BSBL比SBL更优：

```python
class BSBLReconstructor:
    """
    块稀疏贝叶斯学习重建器

    与SBL的区别：
      - SBL假设每个单元独立稀疏 → 适合点状目标
      - BSBL假设相邻单元组（块）共同稀疏 → 适合区域状目标

    块结构：基于FEM网格的邻接关系，将相邻单元组成块
    每个块的大小 = 该单元及其1-ring邻居的数量
    """
```

#### 3.2.3 传统重建模块的统一接口

```python
class TraditionalReconstructor:
    """统一的传统重建接口"""

    METHODS = {
        'bp': BPReconstructor,
        'jac': JACReconstructor,
        'sbl': SBLReconstructor,
        'bsbl': BSBLReconstructor,
        'gn': GaussNewtonReconstructor,
    }

    def __init__(self, solver, method='sbl', **kwargs):
        self.reconstructor = self.METHODS[method](solver, **kwargs)

    def reconstruct(self, V_meas):
        """返回 (sigma, variance)"""
        return self.reconstructor.reconstruct(V_meas)

    def batch_reconstruct(self, V_batch):
        """批量重建，可并行"""
        # 使用 joblib 或 multiprocessing 加速
        sigmas, variances = zip(*[
            self.reconstruct(V_batch[i])
            for i in range(len(V_batch))
        ])
        return np.stack(sigmas), np.stack(variances)
```

#### 3.2.4 关键设计决策：传统重建不参与梯度

$\sigma_0$ 由传统算法计算，**detach** 不传梯度到网络。原因：

1. 传统算法（特别是SBL的矩阵求逆）不可微分或微分代价极高
2. 梯度应通过 $J^T r$ 路径回传，物理含义更明确
3. 避免梯度通过不可靠的数值路径传播

### 3.3 Branch B：物理残差特征 $g = J^T r$

**现状**：Conv-Spatial EIT已有 $J^T r$ correction_head（`conv_spatial_eit.py:490-505`），但仅作为"修正头"的辅助输入，不是主特征。

**改进**：将 $g = J^T r$ 从"修正头"升级为MeshGNN的**主节点特征**之一。

#### 3.3.1 残差计算（可微分）

```python
class ResidualComputer(nn.Module):
    """
    物理残差特征计算

    计算: g = Jᵀ · r,  r = V_meas - F(σ₀)

    这里 F(σ₀) 用 Jacobian 线性化近似:
        F(σ₀) ≈ V_ref + J · (σ₀ - σ_ref)
    因此:
        r = V_meas - V_ref - J · (σ₀ - σ_ref)
        g = Jᵀ · r

    梯度通过 r 回传到 σ₀（如果需要），但 σ₀ 本身是 detach 的，
    所以实际梯度只影响后续网络参数。
    """

    def __init__(self, jacobian, V_ref, sigma_ref):
        super().__init__()
        # jacobian: (n_meas, n_elems)
        J = torch.from_numpy(jacobian).float()
        self.register_buffer('J', J)           # (n_meas, n_elems)
        self.register_buffer('JT', J.T.contiguous())  # (n_elems, n_meas)
        self.register_buffer('V_ref', torch.from_numpy(V_ref).float())
        self.register_buffer('sigma_ref',
                             torch.from_numpy(sigma_ref).float())

    def forward(self, V_meas, sigma_0):
        """
        参数:
            V_meas: (B, n_meas) 测量电压（差分）
            sigma_0: (B, n_elems) 传统重建电导率（detached）

        返回:
            g: (B, n_elems) 物理残差特征
            r: (B, n_meas) 电压残差（用于测量一致性损失）
        """
        # Jacobian预测的电压
        delta_sigma = sigma_0 - self.sigma_ref.unsqueeze(0)  # (B, n_elems)
        V_pred = (self.J.unsqueeze(0) @
                  delta_sigma.unsqueeze(-1)).squeeze(-1)      # (B, n_meas)

        # 电压残差
        r = V_meas - V_pred                                   # (B, n_meas)

        # 反投影到网格
        g = (self.JT.unsqueeze(0) @
             r.unsqueeze(-1)).squeeze(-1)                      # (B, n_elems)

        return g, r
```

#### 3.3.2 $g = J^T r$ 的物理含义

$J^T r$ 的第 $i$ 个分量为：

$$g_i = \sum_{m=1}^{M} J_{mi} \cdot r_m = \sum_{m} \frac{\partial V_m}{\partial \sigma_i} \cdot r_m$$

物理含义：**单元 $i$ 对所有测量残差的"总责任"**。$g_i > 0$ 意味着单元 $i$ 的电导率应该增大（以减小残差），$g_i < 0$ 则应减小。这就是Gauss-Newton迭代中的梯度方向——天然的空间物理特征。

### 3.4 Branch C：全局电压特征 $z_v$

**动机**：$\sigma_0$ 和 $g$ 已经编码了大部分物理信息，但它们是基于单频Jacobian的。多频测量中不同频率携带的信息（即使pyEIT目前不区分频率，实际硬件测量的多频数据也有差异）需要一个全局编码器来捕捉。

**设计**：复用Conv-Spatial EIT的ConvEncoder，但输出从GridSampler改为全局池化：

```python
class VoltageGlobalEncoder(nn.Module):
    """
    全局电压特征编码器

    与GridSampler的区别：
      - GridSampler: 输出 (B, n_elems, D) — 每个单元一个特征向量
      - GlobalEncoder: 输出 (B, D) — 一个全局特征向量

    用途：作为MeshGNN的全局条件，拼接到每个节点的特征上。
    """

    def __init__(self, n_freq=6, n_meas=208, hidden_dim=256):
        super().__init__()
        # 多频融合
        self.freq_fusion = FrequencyCrossAttention(n_freq=n_freq, d_model=64)
        # Conv编码（复用Conv-Spatial的ConvEncoder）
        self.encoder = ConvEncoder(in_channels=1, base_ch=96)
        # 全局池化 + 投影
        self.global_proj = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),   # (B, 256, 1, 1)
            nn.Flatten(),               # (B, 256)
            nn.Linear(256, hidden_dim),
            nn.LayerNorm(hidden_dim),
            nn.GELU(),
        )

    def forward(self, voltages):
        """
        参数:
            voltages: (B, n_freq, n_meas)

        返回:
            z_v: (B, hidden_dim) 全局电压特征
        """
        B = voltages.shape[0]
        x = voltages.view(B, 6, 13, 16)
        x = self.freq_fusion(x)       # (B, 1, 13, 16)
        feat, _ = self.encoder(x)     # (B, 256, 13, 16)
        z_v = self.global_proj(feat)  # (B, hidden_dim)
        return z_v
```

### 3.5 MeshGNN：残差预测网络

**核心设计**：GNN的每个节点接收三类特征：

1. **$\sigma_0$**（标量）：传统重建的初始估计，网络的"起点"
2. **$g = J^T r$**（标量）：物理梯度方向，告诉网络"往哪个方向修正"
3. **位置编码 $pe$**（向量）：空间位置信息，区分中心/边缘（EIT灵敏度差异巨大）

加上全局条件：
4. **$z_v$**（向量）：多频电压全局特征，广播到每个节点

```python
class ResidualMeshGNN(nn.Module):
    """
    残差预测MeshGNN

    输入:
        - node_feat: (B, n_elems, node_dim) = [σ₀, g, pe] 拼接
        - z_v: (B, global_dim) 全局电压特征
        - edge_idx: (2, n_edges) 边索引
        - edge_weight: (n_edges,) 边权重

    输出:
        - delta_sigma: (B, n_elems) 残差修正
    """

    def __init__(self, node_dim, global_dim, hidden_dim=256,
                 n_layers=6, n_heads=4, dropout=0.1):
        super().__init__()

        # 节点特征投影（含全局条件拼接后的维度）
        self.node_proj = nn.Sequential(
            nn.Linear(node_dim + global_dim, hidden_dim),
            nn.LayerNorm(hidden_dim),
            nn.GELU(),
        )

        # GATv2 图注意力层
        self.gnn_layers = nn.ModuleList([
            GATv2Layer(hidden_dim, hidden_dim, dropout, n_heads)
            for _ in range(n_layers)
        ])

        # 残差预测头
        self.delta_head = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.GELU(),
            nn.Dropout(dropout * 0.5),
            nn.Linear(hidden_dim // 2, 1),
        )

    def forward(self, node_feat, z_v, edge_idx, edge_weight):
        """
        参数:
            node_feat: (B, n_elems, node_dim) — [σ₀, g, pe]
            z_v: (B, global_dim) — 全局特征
            edge_idx: (2, n_edges)
            edge_weight: (n_edges,)

        返回:
            delta_sigma: (B, n_elems)
        """
        B, N, D = node_feat.shape

        # 广播全局特征到每个节点
        z_expand = z_v.unsqueeze(1).expand(B, N, -1)  # (B, N, global_dim)

        # 拼接节点特征 + 全局条件
        h = torch.cat([node_feat, z_expand], dim=-1)   # (B, N, node_dim+global_dim)
        h = self.node_proj(h)                           # (B, N, hidden_dim)

        # GNN消息传递
        for gnn in self.gnn_layers:
            h = h + gnn(h, edge_idx, edge_weight)       # 残差连接

        # 残差预测
        delta = self.delta_head(h).squeeze(-1)          # (B, n_elems)

        return delta
```

### 3.6 完整模型：ResidualEIT

```python
class ResidualEIT(nn.Module):
    """
    路线B完整模型：先传统成像再残差校正

    数据流:
        V → [Branch A] σ₀ (传统重建, detached)
        V → [Branch B] g = Jᵀr (物理残差特征)
        V → [Branch C] z_v (全局电压特征)
        MeshGNN(σ₀, g, pe, z_v) → Δσ
        σ̂ = σ₀ + Softplus(Δσ)
    """

    def __init__(self, reconstructor, jacobian, V_ref, sigma_ref,
                 centers, elements, n_freq=6, n_meas=208,
                 hidden_dim=256, n_gnn_layers=6, sigma_min=0.005,
                 sigma_max=0.1):
        super().__init__()

        self.reconstructor = reconstructor  # 传统重建（不在计算图中）
        self.sigma_min = sigma_min
        self.sigma_max = sigma_max

        # Branch B: 物理残差
        self.residual_computer = ResidualComputer(jacobian, V_ref, sigma_ref)

        # Branch C: 全局电压编码
        self.voltage_encoder = VoltageGlobalEncoder(n_freq, n_meas, hidden_dim)

        # 位置编码
        pe = self._build_position_encoding(centers)
        self.register_buffer('pos_encoding', pe)
        pos_dim = pe.shape[1]

        # 图结构
        edge_idx, edge_weight = self._build_graph(elements, centers)
        self.register_buffer('_edge_idx', edge_idx)
        self.register_buffer('_edge_weight', edge_weight)

        # MeshGNN
        node_dim = 2 + pos_dim   # σ₀(1) + g(1) + pe(pos_dim)
        self.mesh_gnn = ResidualMeshGNN(
            node_dim=node_dim,
            global_dim=hidden_dim,
            hidden_dim=hidden_dim,
            n_layers=n_gnn_layers,
        )

    def forward(self, voltages):
        """
        参数:
            voltages: (B, n_freq, n_meas) 边界电压

        返回:
            dict: {
                'sigma': (B, n_elems) 最终重建,
                'sigma_0': (B, n_elems) 传统重建初始解,
                'delta_sigma': (B, n_elems) 残差修正,
                'residual': (B, n_meas) 电压残差,
                'g': (B, n_elems) 物理残差特征,
            }
        """
        B = voltages.shape[0]
        device = voltages.device

        # Branch A: 传统重建（detached）
        with torch.no_grad():
            V_np = voltages[:, 0, :].cpu().numpy()  # 取第1频
            sigma_0_list = []
            for b in range(B):
                sigma_b, _ = self.reconstructor.reconstruct(V_np[b])
                sigma_0_list.append(sigma_b)
            sigma_0 = torch.from_numpy(np.stack(sigma_0_list)).to(device)
        sigma_0 = sigma_0.detach()

        # Branch B: 物理残差特征
        V_meas = voltages[:, 0, :]   # (B, n_meas) 取第1频
        g, r = self.residual_computer(V_meas, sigma_0)

        # Branch C: 全局电压特征
        z_v = self.voltage_encoder(voltages)  # (B, hidden_dim)

        # 构建节点特征
        pe = self.pos_encoding.unsqueeze(0).expand(B, -1, -1)
        node_feat = torch.cat([
            sigma_0.unsqueeze(-1),   # (B, n_elems, 1)
            g.unsqueeze(-1),         # (B, n_elems, 1)
            pe,                      # (B, n_elems, pos_dim)
        ], dim=-1)                   # (B, n_elems, node_dim)

        # MeshGNN
        edge_idx = self._edge_idx.to(device)
        edge_weight = self._edge_weight.to(device)
        delta_sigma = self.mesh_gnn(node_feat, z_v, edge_idx, edge_weight)

        # 残差组合：Softplus保证 Δσ > -σ₀（σ̂不会变负）
        sigma = sigma_0 + F.softplus(delta_sigma) * torch.sign(delta_sigma)

        # 或者更简单的方式：
        # sigma = sigma_0 + delta_sigma
        # sigma = torch.clamp(sigma, self.sigma_min, self.sigma_max)

        sigma = torch.clamp(sigma, self.sigma_min, self.sigma_max)

        return {
            'sigma': sigma,
            'sigma_0': sigma_0,
            'delta_sigma': delta_sigma,
            'residual': r,
            'g': g,
            'z_v': z_v,
        }
```

## 4. 损失函数重设计

### 4.1 路线B的损失函数体系

路线A的6个loss中，有些需要保留，有些需要修改，有些需要替换：

| 路线A损失 | 路线B处置 | 理由 |
|-----------|----------|------|
| `MeasurementConsistencyLoss` | **保留，但重新设计** | 核心物理约束，但现在在σ₀附近线性化 |
| `TVRegularizationLoss` | **保留** | 仍需抑制伪影 |
| `FrequencyCrossConsistencyLoss` | **保留** | 多频一致性仍有价值 |
| `BLCCorrectionLoss` | **删除** | BLC模块在路线B中不存在 |
| `SmoothnessLoss` | **保留** | 物理合理性 |
| `SigmaDeviationLoss` | **替换为残差约束** | 不再需要约束σ靠近σ_ref |

### 4.2 新的损失函数

```python
class ResidualMeasurementConsistencyLoss(nn.Module):
    """
    残差测量一致性损失（路线B核心）

    关键改进: 在 σ₀ + Δσ 处线性化，而非 σ_ref 处

    L_meas = ||J · (σ̂ - σ₀) + F(σ₀) - V||²
           = ||J · Δσ + (F(σ₀) - V)||²
           = ||J · Δσ - r||²

    因为 Δσ 小，Jacobian 线性化更准确！
    """

    def __init__(self, jacobian, fem_solver=None, fem_interval=5):
        super().__init__()
        J = torch.from_numpy(jacobian).float()
        self.register_buffer('J', J)
        self.forward_solver = fem_solver
        self.fem_interval = fem_interval
        self._fem_step = 0
        self._cached_V_full = None

    def forward(self, sigma_pred, sigma_0, voltages_measured, residual):
        """
        参数:
            sigma_pred: (B, n_elems) σ̂ = σ₀ + Δσ
            sigma_0: (B, n_elems) 传统重建初始解
            voltages_measured: (B, n_meas) 测量电压
            residual: (B, n_meas) 电压残差 r = V - F(σ₀)

        返回:
            loss: 标量
        """
        B = sigma_pred.shape[0]
        delta_sigma = sigma_pred - sigma_0  # (B, n_elems)

        # Jacobian线性化（在σ₀附近，而非σ_ref）
        V_jac = (self.J.unsqueeze(0) @
                 delta_sigma.unsqueeze(-1)).squeeze(-1)  # (B, n_meas)

        # 核心: ||J·Δσ - r||²
        # 即预测的电压修正应该匹配实际的电压残差
        loss_main = F.mse_loss(V_jac, residual)

        # 可选: FEM验证（与路线A相同的设计，定期用FEM校正）
        if self.forward_solver is not None and self._fem_step % self.fem_interval == 0:
            with torch.no_grad():
                sigma_np = sigma_pred.detach().cpu().numpy()
                V_full_list = []
                for b in range(B):
                    V_b = self.forward_solver(sigma_np[b])
                    V_full_list.append(V_b.astype(np.float32))
                V_full = torch.from_numpy(np.stack(V_full_list)).to(sigma_pred.device)
                self._cached_V_full = V_full

        if self._cached_V_full is not None:
            loss_aux = F.mse_loss(V_jac, self._cached_V_full.detach())
            loss_main = loss_main + 0.1 * loss_aux

        self._fem_step += 1
        return loss_main


class ResidualSparsityLoss(nn.Module):
    """
    残差稀疏约束（替代SigmaDeviationLoss）

    路线A: L_dev = ||σ - σ_ref||²  — 约束σ靠近σ_ref，与重建目标冲突
    路线B: L_res = ||Δσ||₁         — 鼓励最小修正，不与重建目标冲突

    物理含义: 传统重建σ₀已经是"够好的"解，网络只应在确实需要的地方做修正。
    """
    def forward(self, delta_sigma):
        return torch.abs(delta_sigma).mean()


class ResidualSmoothnessLoss(nn.Module):
    """
    残差平滑约束

    鼓励残差在空间上平滑，避免孤立的修正点。
    这与TV正则化互补：TV保持σ的边缘，Smoothness约束Δσ的空间连续性。
    """
    def __init__(self, edge_idx):
        super().__init__()
        self.register_buffer('edge_idx', edge_idx)

    def forward(self, delta_sigma):
        edge_idx = self.edge_idx.to(delta_sigma.device)
        diff = delta_sigma[:, edge_idx[0]] - delta_sigma[:, edge_idx[1]]
        return (diff ** 2).mean()
```

### 4.3 总损失

$$L_{total} = \lambda_m L_{meas} + \lambda_{tv} L_{tv} + \lambda_{res} L_{res} + \lambda_{smooth} L_{smooth} + \lambda_{freq} L_{freq}$$

推荐权重（初始值，后续可自适应）：

| 损失 | 符号 | 推荐权重 | 说明 |
|------|------|---------|------|

| TV正则化 | $\lambda_{tv}$ | 0.05 | 边缘保持 |
| 残差稀疏 | $\lambda_{res}$ | 0.01 | 最小修正 |
| 残差平滑 | $\lambda_{smooth}$ | 0.02 | 空间连续性 |
| 频率一致性 | $\lambda_{freq}$ | 0.1 | 多频约束 |

## 5. 多频差异化

### 5.1 当前问题

`eit_forward.py:149-162` 中 `solve_multi_frequency` 只是 tile 同一份结果：

```python
def solve_multi_frequency(self, sigma):
    v = self.solve(sigma)
    return np.tile(v, (len(self.frequencies), 1))
```

6个频率的测量完全相同，多频信息被浪费。

### 5.2 物理基础：Cole-Cole模型

生物组织的电导率是频率相关的：

$$\sigma(\omega) = \sigma_\infty + \frac{\sigma_0 - \sigma_\infty}{1 + (j\omega\tau)^\alpha}$$

其中：
- $\sigma_0$：低频电导率（直流）
- $\sigma_\infty$：高频电导率
- $\tau$：弛豫时间常数
- $\alpha$：弥散系数（0-1）

不同组织（土壤、根系、水）的Cole-Cole参数不同，因此多频测量携带了包含物类型的信息。

### 5.3 实现方案

```python
class MultiFrequencyEITSolver:
    """
    多频EIT正问题求解器

    在pyEIT单频求解的基础上，通过Cole-Cole模型引入频率依赖性。

    核心思路：
      1. 为每种材料分配Cole-Cole参数 (σ₀, σ∞, τ, α)
      2. 对每个频率计算该材料的有效电导率 σ_eff(f)
      3. 用 σ_eff(f) 调用pyEIT单频求解器
      4. 不同频率得到不同的边界电压
    """

    def __init__(self, solver, material_params):
        """
        参数:
            solver: EITForwardSolver 单频求解器
            material_params: dict, 每种材料的Cole-Cole参数
                {
                    'soil': {'sigma_0': 0.01, 'sigma_inf': 0.015, 'tau': 1e-4, 'alpha': 0.5},
                    'root': {'sigma_0': 0.05, 'sigma_inf': 0.08,  'tau': 5e-5, 'alpha': 0.7},
                    'water': {'sigma_0': 0.02, 'sigma_inf': 0.03,  'tau': 2e-4, 'alpha': 0.3},
                }
        """
        self.solver = solver
        self.material_params = material_params
        self.frequencies = solver.frequencies

    def cole_cole(self, freq, sigma_0, sigma_inf, tau, alpha):
        """Cole-Cole模型计算有效电导率（取实部）"""
        omega = 2 * np.pi * freq
        j_omega_tau = 1j * omega * tau
        sigma_complex = sigma_inf + (sigma_0 - sigma_inf) / (1 + j_omega_tau ** alpha)
        return sigma_complex.real

    def solve_multi_frequency(self, sigma, material_map=None):
        """
        多频求解

        参数:
            sigma: (n_elems,) 低频电导率分布
            material_map: (n_elems,) 每个单元的材料ID (0=soil, 1=root, ...)
                          如果为None，从sigma值推断

        返回:
            voltages: (n_freq, n_meas) 多频边界电压
        """
        if material_map is None:
            material_map = self._infer_material(sigma)

        voltages = np.zeros((len(self.frequencies), self.solver.n_measurements))
        for i, freq in enumerate(self.frequencies):
            sigma_freq = self._compute_sigma_at_freq(sigma, material_map, freq)
            voltages[i] = self.solver.solve(sigma_freq)

        return voltages

    def _infer_material(self, sigma):
        """从电导率值推断材料类型"""
        material_map = np.zeros(len(sigma), dtype=np.int32)
        # 简单阈值分割
        material_map[sigma > 0.03] = 1  # root
        material_map[sigma < 0.005] = 2  # air/low
        return material_map

    def _compute_sigma_at_freq(self, sigma_base, material_map, freq):
        """计算指定频率下的电导率"""
        sigma_freq = sigma_base.copy()
        materials = ['soil', 'root', 'water']
        for mat_id, mat_name in enumerate(materials):
            if mat_name not in self.material_params:
                continue
            mask = material_map == mat_id
            if mask.sum() == 0:
                continue
            params = self.material_params[mat_name]
            sigma_eff = self.cole_cole(freq, **params)
            sigma_freq[mask] = sigma_eff
        return sigma_freq
```

```python
class ResidualEITDataModule:
    """
    路线B的数据模块

    预处理步骤（一次性）：
      1. 传统重建: V → σ₀ (SBL/BSBL)
      2. 物理残差: g = Jᵀ(V - J·(σ₀ - σ_ref))
      3. 存储到HDF5: voltages, sigma_0, g, sigma_gt(验证用)
    """

    def __init__(self, h5_path, reconstructor, residual_computer, ...):
        self.h5_path = h5_path
        self.reconstructor = reconstructor
        self.residual_computer = residual_computer

    def prepare_data(self):
        """预处理并缓存σ₀和g到HDF5"""
        if os.path.exists(self.h5_path):
            # 检查是否已包含 sigma_0 和 g
            with h5py.File(self.h5_path, 'r') as f:
                if 'sigma_0' in f and 'g' in f:
                    print("  已有预处理数据，跳过")
                    return

        print("  预处理: 计算σ₀和g...")
        with h5py.File(self.h5_path, 'a') as f:
            n_samples = f['voltages'].shape[0]
            n_elems = f['voltages'].shape[-1] if f['voltages'].ndim == 2 else \
                      self.reconstructor.solver.n_elems

            sigma_0_ds = f.create_dataset('sigma_0', (n_samples, n_elems), dtype='float32')
            g_ds = f.create_dataset('g', (n_samples, n_elems), dtype='float32')

            for i in tqdm(range(n_samples)):
                V = f['voltages'][i]
                sigma_0, _ = self.reconstructor.reconstruct(V)
                g, _ = self.residual_computer(V, sigma_0)
                sigma_0_ds[i] = sigma_0
                g_ds[i] = g
```

### 6.2 训练循环

```python
class ResidualEITTrainer:
    """
    路线B训练器

    关键区别（vs 路线A的UnsupervisedTrainer）：
      1. σ₀从预计算数据加载，不参与梯度
      2. 测量一致性在σ₀附近线性化
      3. 残差约束替代SigmaDeviationLoss
      4. 无BLCCorrectionLoss
    """

    def _train_one_epoch(self, train_loader, epoch):
        self.model.train()
        for batch in train_loader:
            voltages = batch['voltages'].to(self.device)
            sigma_0 = batch['sigma_0'].to(self.device)  # 预计算的传统重建
            g = batch['g'].to(self.device)               # 预计算的物理残差
            r = batch['residual'].to(self.device)         # 预计算的电压残差

            sigma_0 = sigma_0.detach()  # 确保不参与梯度
            g = g.detach()
            r = r.detach()

            # 模型前向
            out = self.model(voltages)  # 内部使用预计算的σ₀和g

            sigma_pred = out['sigma']
            delta_sigma = out['delta_sigma']

            # 损失计算
            losses = {}
            losses['meas'] = self.loss_fns['meas'](
                sigma_pred, sigma_0, voltages[:, 0, :], r)
            losses['tv'] = self.loss_fns['tv'](sigma_pred)
            losses['res'] = self.loss_fns['res'](delta_sigma)
            losses['smooth'] = self.loss_fns['smooth'](delta_sigma)
            losses['freq'] = self.loss_fns['freq'](out.get('z_v'), sigma_pred)

            # 加权总损失
            total = sum(self.loss_weights[k] * losses[k]
                       for k in losses if k in self.loss_weights)

            # 反向传播
            self.optimizer.zero_grad()
            total.backward()
            torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
            self.optimizer.step()
```

### 6.3 训练策略

**阶段1：预热（前10% epochs）**

- 冻结MeshGNN，只训练残差预测头的偏置，使初始 $\Delta\sigma \approx 0$
- 目的：让 $\sigma_0$ 作为网络输出的合理起点

**阶段2：联合训练（10%-100% epochs）**

- 解冻全部参数
- 学习率：3e-4，cosine annealing
- 梯度累积：如果batch_size=32显存不够，用gradient accumulation

**阶段3：精调（可选，最后10% epochs）**

- 降低学习率至1e-5
- 增大TV权重（0.05 → 0.1），进一步抑制伪影
- 增大残差稀疏权重（0.01 → 0.05），鼓励更精细的修正

## 8. 与大模型的结合

### 8.1 为什么EIT可以引入大模型

EIT重建的核心挑战是：从有限且噪声的边界测量推断内部电导率分布，这是一个**严重不适定的逆问题**。大模型的价值在于：

1. **先验知识注入**：大模型在2D/3D视觉数据上预训练，学到了丰富的空间结构先验（边缘、纹理、形状）
2. **跨模态推理**：如果同时有RGB图像或其他传感器数据，大模型可以融合多模态信息
3. **不确定性估计**：大模型可以通过生成式方法估计重建的不确定性

### 8.2 结合方案

#### 方案A：大模型作为视觉先验（推荐）

```
V → 传统重建 → σ₀ → scatter_to_grid(σ₀) → image_σ₀
                                          ↓
                            Vision Foundation Model (frozen)
                                          ↓
                              visual features (B, C, H, W)
                                          ↓
                              grid_sample → mesh features
                                          ↓
                    MeshGNN(σ₀, g, mesh_features_from_LLM, z_v) → Δσ
```

**具体实现**：

```python
class VisionPriorEncoder(nn.Module):
    """
    使用视觉基础模型提取σ₀的结构先验

    流程:
      1. 将σ₀从FEM网格scatter到规则图像网格 (64×64)
      2. 通过预训练视觉模型（如DINOv2/SAM的encoder）提取特征
      3. 将特征grid_sample回FEM网格
      4. 作为MeshGNN的额外节点特征

    优势:
      - 视觉模型学到的边缘/形状先验帮助GNN更好地定位包含物边界
      - 不需要微调视觉模型，直接用frozen encoder
    """

    def __init__(self, vision_model='dinov2', grid_size=64, out_dim=128):
        super().__init__()
        self.grid_size = grid_size

        if vision_model == 'dinov2':
            self.encoder = torch.hub.load('facebookresearch/dinov2',
                                          'dinov2_vits14')
            feat_dim = 384
        elif vision_model == 'sam':
            from segment_anything import sam_image_encoder
            self.encoder = sam_image_encoder  # ViT-H
            feat_dim = 256

        # 冻结视觉模型
        for param in self.encoder.parameters():
            param.requires_grad = False

        # 投影层（可训练）
        self.proj = nn.Sequential(
            nn.Linear(feat_dim, out_dim),
            nn.LayerNorm(out_dim),
            nn.GELU(),
        )

    def forward(self, sigma_0, element_centers):
        """
        参数:
            sigma_0: (B, n_elems) 传统重建电导率
            element_centers: (n_elems, 2) 单元中心坐标

        返回:
            visual_feat: (B, n_elems, out_dim) 每个单元的视觉特征
        """
        B = sigma_0.shape[0]

        # scatter到图像网格
        img = self._scatter_to_image(sigma_0, element_centers)  # (B, 1, 64, 64)
        img = img.repeat(1, 3, 1, 1)  # 灰度→3通道

        # 视觉特征提取
        feat_map = self.encoder(img)  # (B, feat_dim, H', W')

        # grid_sample回FEM网格
        visual_feat = self._sample_to_mesh(feat_map, element_centers)  # (B, n_elems, feat_dim)

        # 投影
        visual_feat = self.proj(visual_feat)  # (B, n_elems, out_dim)

        return visual_feat
```

#### 方案B：大模型作为条件生成器

```
V → 传统重建 → σ₀ → VLM(σ₀, "Describe the inclusions") → text_features
                                                         ↓
                            MeshGNN conditioned on text_features → Δσ
```

适合多模态场景（如同时有EIT测量和视觉/文本描述）。

#### 方案C：迭代精调中的大模型指导

```
for i in range(n_iters):
    σ̂ᵢ = σ₀ + Σ Δσⱼ (j=0..i-1)
    V_pred = F(σ̂ᵢ)
    r = V - V_pred
    g = Jᵀr

    # 大模型提供结构先验
    structure_prior = VLM(σ̂ᵢ, "Identify inclusion boundaries")

    Δσᵢ = MeshGNN(σ̂ᵢ, g, structure_prior)
```

每次迭代都用大模型重新评估结构，提供更准确的边界先验。

### 8.3 计算成本与实用性

| 方案 | 额外计算 | 额外参数 | 推荐场景 |
|------|---------|---------|---------|
| A (frozen encoder) | +10ms (DINOv2) | 0 (frozen) + 0.5M (proj) | 通用，推荐首选 |
| B (VLM) | +100ms | 0 (frozen) + 1M | 多模态场景 |
| C (迭代+VLM) | +100ms×n_iters | 0 (frozen) + 1M | 高精度需求 |

## 9. 实现路线图

### Phase 1：核心架构（1-2周）

1. **实现 `SBLReconstructor`** — 替换BP/JAC作为默认传统重建
2. **实现 `ResidualComputer`** — $g = J^T r$ 计算
3. **实现 `ResidualMeshGNN`** — 基于 `ConvSpatialEIT` 的GATv2层
4. **实现 `ResidualEIT`** — 完整模型，Branch A/B/C + MeshGNN
5. **实现新的损失函数** — `ResidualMeasurementConsistencyLoss` + `ResidualSparsityLoss`

### Phase 2：训练与验证（1-2周）

1. **实现 `ResidualEITTrainer`** — 替换 `UnsupervisedTrainer`
2. **单频训练验证** — 先在单频数据上验证路线B的优越性

### Phase 4：大模型集成（1-2周）

### Phase 5：工程化（1周）

1. **推理引擎** — `ResidualEITInference`

4. **文档与测试** — 完整的单元测试和集成测试

## 11. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| SBL重建速度慢（矩阵求逆） | 训练数据预处理耗时 | 预计算一次存储；推理时用Cholesky分解加速 |
| σ₀质量差时拖累最终结果 | 重建精度下降 | 多方法fallback：SBL→JAC→BP；σ₀质量评估 |
| 传统重建不可微 | 无法端到端优化 | 梯度通过J·Δσ路径回传，无需通过σ₀ |
| GNN过平滑 | 边缘模糊 | 使用GATv2注意力；增加跳跃连接；TV正则化 |
| 多频Cole-Cole参数难获取 | 多频差异化不准确 | 从测量数据反演参数；使用文献典型值 |
| 大模型推理开销 | 实时性下降 | Frozen encoder只需前向传播；可用蒸馏模型 |
