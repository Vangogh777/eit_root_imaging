## 0. 论文定位

### 0.1 一句话摘要

> 首次将扩散模型直接部署在 FEM 三角网格上，通过**灵敏度感知的多尺度条件注入 + 确定性预热 + 物理梯度引导**，在严重病态的 EIT 逆问题上实现 SOTA 精度和不确定性量化。

### 0.2 四项核心贡献（均可消融验证）

| # | 贡献 | 解决的问题 | 消融方式 |
|---|------|-----------|---------|
| **C1** | **Hierarchical Mesh Diffusion** — 直接在 FEM 三角网格上做多尺度扩散 | CNN GridSampler 插值瓶颈 | vs. ConvSpatialEIT (CNN→Mesh) |
| **C2** | **Sensitivity-Aware Conditioning** — J^T·V 灵敏度 + 电压编码注入每层 | 不同空间位置灵敏度差异巨大 | vs. 仅全局电压条件 |


## 2. 核心创新详细展开

### 2.1 C1: Hierarchical Mesh Diffusion

**为什么需要多尺度：**

单层 GNN（如 Alberti RDPS）只在原始 4424 个节点上做消息传递。对于扩散模型来说，这意味着每一步去噪都要在 4424 个节点间传递信息——感受野受限，收敛慢。

**我们的方案:**

```
Level 0: 4424 nodes — 精细的局部特征（边界、小内含物）
Level 1: 1100 nodes — 中等尺度（内含物大致形状）
Level 2:  275 nodes — 粗尺度（全局 pattern）
Bottleneck: 70 nodes — 全局语义（"有几个内含物？什么类型？"）
```

**关键设计:**
- Pooling 用 Graclus 图聚类（保持 FEM 拓扑），而非简单的 FPS（丢失邻接关系）
- 每层有独立的 Skip Connection（类似 U-Net），解码器能访问编码器对应尺度的特征
- Bottleneck 用 Self-Attention 做全局交互（70 个节点，注意力矩阵 70×70，极轻量）

**新颖性:** 在此之前，没有人在 FEM 三角网格上构建过多尺度扩散模型。Alberti 2026 是单层图 score network；CNN U-Net 需要规则 grid。我们是第一个在 unstructured mesh 上实现 hierarchical diffusion 的。

**消融:** vs. 单层 GNN 扩散（去掉 Pool/Unpool），验证多尺度的作用。

---

### 2.2 C2: Sensitivity-Aware Conditioning

**为什么需要灵敏度感知：**

EIT 的灵敏度在不同空间位置差异极大（中心 vs 边界可达 100 倍）。标准扩散模型对所有位置一视同仁——这是不对的。

**我们的方案:**

```python
# 三个层次的条件注入

# 1. 全局电压编码 (所有层共享)
V_global = MLP(V)  # 208 → 512

# 2. 灵敏度特征 (每节点,从 Jacobian 导出)
J_sensitivity = J^T @ V  # (4424,) — 每个元素对 V 的灵敏度
J_energy = (J^2).sum(dim=0)  # (4424,) — 每个元素的 Jacobian 能量

# 3. 逐尺度自适应注入
# Level 0: 原始分辨率的灵敏度 + 全局电压
# Level 1: Pooled 灵敏度（粗化后的"区域灵敏度"）+ 全局电压
# Level 2: 更粗化的灵敏度 + 全局电压
# Bottleneck: 仅全局电压（纯粹的语义空间）
```

**新颖性:** 在 EIT 扩散模型中显式编码 Jacobian 灵敏度作为空间条件，且在不同尺度注入不同粒度的灵敏度信息。现有工作（Alberti, Score-EIT）只在采样时用 J 做梯度引导，不在网络内部做条件注入。

**消融:** vs. 仅全局电压条件（去掉 J_sensitivity 特征），验证灵敏度信息的作用。

---

### 2.3 C3: Deterministic Warm-Start

**为什么需要预热：**

标准扩散从纯噪声 σ_T ~ N(0, I) 开始。对 EIT 来说，σ 的物理范围是 [0.005, 0.1]，绝大部分元素是背景（0.01）。从 N(0,I) 起步浪费时间在"发现"这些基本事实上。

**我们的方案:**

```python
# 用 2 层轻量 SimpleGNN（~1M 参数，20ms 推理）先出粗估计
σ_warm = LightGNN(V, J^T·V, mesh)  # RE ≈ 0.25

# 扩散只对残差建模
residual = σ_true - σ_warm  # 残差的方差 << σ_true 的方差
r_T ~ N(0, σ_residual²)     # 从更小的噪声开始

# 最终输出
σ_final = σ_warm + r_0       # 粗估计 + 扩散修正
```

**好处:**
1. **更快收敛:** 残差的分布比原始 σ 更集中，更容易建模（训练 loss 降得快）
2. **更多样的初始化:** σ_warm 已经提供了形状的大致位置，扩散只需补充细节
3. **更少的采样步数:** 可以用更少的时间步（100→50）达到相同质量
4. **自然的论文对比:** deterministic vs. +diffusion 的增益一目了然

**新颖性:** 现有 EIT 扩散模型（Alberti, Score-EIT）都从纯噪声开始。将 deterministic 重建作为扩散的"初始猜测"并只在残差上扩散，是全新的思路。这也和传统图像修复的做法不同——那里没有可用的 deterministic 初始值。

**消融:** vs. 无预热的标准扩散，验证收敛速度和最终 RE 的差异。

### 2.4 C4: Physics-Gradient Guidance

**为什么需要物理引导：**

纯数据驱动的扩散模型可能生成"看起来合理"但物理上不可能的 σ——即 F(σ) ≠ V。对 EIT 来说这尤其严重，因为不同 σ 分布可以产生几乎相同的 V。

**我们的方案:**

```python
# 每一步去噪: 学习先验 + 物理约束
epsilon_combined = epsilon_theta(sigma_t, t, V_cond)        # 学习先验
                 + w_phys * gradient_phys(sigma_t, V, J)    # 物理引导

# 物理梯度: 测量一致性
def gradient_phys(sigma_t, V, J):
    # 1. 从当前的 noisy σ_t 估计干净 σ
    sigma_0_hat = (sigma_t - sqrt(1-ᾱ_t) * epsilon_pred) / sqrt(ᾱ_t)

    # 2. 计算电压残差 (Jacobian 线性化)
    V_pred = J @ (sigma_0_hat - sigma_ref)
    mse = ||V_pred - V||²

    # 3. 梯度回传到 σ_t
    return ∇_{σ_t} mse
```

**引导权重调度:**
```
t=500→300 (早期): w_phys = 0.3  — 强引导，确保大形状正确
t=300→100 (中期): w_phys = 0.1  — 平衡先验和物理
t=100→1   (后期): w_phys = 0.02 — 弱引导，让扩散补细节
```

**新颖性:** Alberti 用 TV+Tikhonov 正则化引导——这是通用的图像正则项，不利用 EIT 的特定物理。我们用 **Jacobian 线性化的测量一致性梯度**，直接利用 EIT 的正演模型。这更精确（针对具体物理）且更快（只需 J@Δσ，不用跑 FEM）。

**消融:** vs. 无物理引导；vs. TV 引导；验证不同引导的效果差异。

## 4. 详细架构规格

### 4.1 Lightweight GNN (Deterministic Warm-Start)

```python
class LightEIT(nn.Module):
    """
    2 层 SimpleGNN，~1M 参数，~20ms 推理
    输出 σ_warm (RE≈0.25) + 特征 h_warm
    """
    def __init__(self, n_meas=208, n_elems=4424, hidden=256):
        self.volt_encoder = MLP(n_meas → hidden → hidden)
        self.node_init = MLP(hidden + 35 + 2 → hidden)  # V + PE + J特征
        self.gnn1 = SimpleGNNLayer(hidden, hidden)
        self.gnn2 = SimpleGNNLayer(hidden, hidden)
        self.out_head = MLP(hidden → 128 → 1)

    def forward(self, V, J_T_V, mesh):
        v_enc = self.volt_encoder(V).expand(n_elems, -1)  # 广播
        x = cat([v_enc, pos_encoding, J_T_V, J_energy])
        x = self.gnn1(x, edges)
        x = self.gnn2(x, edges)
        sigma_warm = sigmoid(self.out_head(x)) * (σ_max-σ_min) + σ_min
        return sigma_warm, x  # 返回 σ 和特征
```

### 4.2 Hierarchical Mesh U-Net (Diffusion Denoiser)

```
输入:
  σ_t (n_elems, 1)     ← 当前噪声版本
  t (1,)                ← 时间步
  V_cond (512,)         ← 电压条件
  J_features (n_elems, 3) ← J^T·V, ||J_i||, mean_J_i
  pos_enc (n_elems, 35)  ← Fourier 位置编码
  h_warm (n_elems, 256)  ← LightGNN 中间特征

编码器:
  L0: 4424 nodes, dim 256+512+3+35+1 = 807 → 384 → 384 (skip_0)
      ↓ Pool (Graclus 4x)
  L1: 1100 nodes, dim 384 → 512 → 512 (skip_1)
      ↓ Pool (Graclus 4x)
  L2:  275 nodes, dim 512 → 512 → 512 (skip_2)
      ↓ Pool (Graclus 4x)
  BN:   70 nodes, dim 512 → SelfAttention(4 heads) → 512 → 512

解码器:
  BN:   70 nodes → 512
      ↑ Unpool
  L2:  275 nodes, cat(U2, skip_2) = 1024 → 512 → 512
      ↑ Unpool
  L1: 1100 nodes, cat(U1, skip_1) = 1024 → 384 → 384
      ↑ Unpool
  L0: 4424 nodes, cat(U0, skip_0) =  768 → 256 → 256

输出头:
  ϵ_pred = Linear(256→128) → GELU → Linear(128→1)
```

### 4.3 Graclus 图池化

```python
def build_mesh_hierarchy(elements, centers):
    """
    预计算多尺度图结构

    返回: list of {
        'nodes': int,
        'edges': (2, n_edges),
        'edge_weight': (n_edges,),
        'edge_feat': (n_edges, 4),
        'centers': (nodes, 2),
        'cluster': (parent_nodes,)  # 每个节点的聚类 ID
    }
    """
    hierarchy = [build_level_0(elements, centers)]

    for level in range(3):
        parent = hierarchy[-1]
        # Graclus 聚类
        clusters = graclus_cluster(parent['edges'], parent['nodes'],
                                   target_clusters=parent['nodes'] // 4)

        # 构建父级图
        child = build_coarse_graph(parent, clusters)
        hierarchy.append(child)

    return hierarchy


class GraphPool(nn.Module):
    """max pooling within clusters"""
    def forward(self, x, cluster_map, n_parent):
        # scatter_max: 每个 cluster 内取 max
        out = scatter_max(x, cluster_map, dim=0, dim_size=n_parent)
        return out


class GraphUnpool(nn.Module):
    """broadcast parent features to all children in cluster"""
    def forward(self, x, cluster_map, n_child):
        return x[cluster_map]  # 简单索引广播
```

## 7. 附录: 和 ConvSpatialEIT / ResidualEIT 的演进关系

```
ConvSpatialEIT:  CNN → GridSampler → GNN → σ
    │  问题: CNN 插值瓶颈, end-to-end 黑盒
    │
    ▼
ResidualEIT:   GREIT → σ_coarse → GNN → Δσ
    │  问题: GREIT 太差, 单尺度 GNN, 无扩散
    │
    ▼

               + Physics-gradient guidance
               + Uncertainty quantification
```
