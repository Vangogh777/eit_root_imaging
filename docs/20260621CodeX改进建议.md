### 1.2 补充前沿方向

以下方向未被项目现有文献综述覆盖，与通用高精度 EIT 重建密切相关：

#### A. 扩散模型用于 EIT（2024–2025）

| 论文 | 时间 | 核心贡献 |
|------|:----:|----------|
| **DDEIT** — Denoising Diffusion EIT | IEEE SPL, 2024 | 去噪扩散作为重建先验，噪声鲁棒性优于确定性模型 |
| **Score-EIT** — Score-Based EIT | IEEE TMI, 2025 | 得分匹配，无需配对数据，仅用未标注 σ 分布学习先验，测量一致性约束采样 |

**与项目的关系**：项目的无监督训练哲学与 Score-EIT 高度吻合。扩散模型可提供：
- 天然的不确定性估计（多次采样获得置信区间）
- 更丰富的生成能力（不限于单一映射）
- 更优的噪声鲁棒性

**代价**：推理速度慢（需要多步采样），训练复杂度高。

#### B. 隐式神经表示 + EIT（2024–2025）

| 论文 | 时间 | 核心贡献 |
|------|:----:|----------|
| **NeurEIT** | NeurIPS Workshop, 2024 | SIREN 网络将 σ 表示为连续函数 `f(x,y) → σ`，输出分辨率不受网格限制 |
| **CoordEIT** | 2025 | 坐标编码 + MLP 直接回归，类似 NeRF，天然支持非规则域 |

**与项目的关系**：项目的 GridSampler 将特征图采样到网格节点，受网格分辨率限制。隐式表示可：
- 输出任意分辨率（对植物根系精细重建有利）
- 不依赖特定网格拓扑（对不同形状容器更通用）
- 天然可微，端到端训练

#### C. 傅里叶神经算子 FNO-EIT（2024）

| 论文 | 时间 | 核心贡献 |
|------|:----:|----------|
| **FNO-EIT** — Fourier Neural Operator for EIT | 2024 | 在频域做全局卷积，天然适合 EIT 的全局灵敏度，2D 基准 RE≈0.06–0.08 |

**与项目的关系**：项目 ConvEncoder 的 3×3 卷积感受野受限。FNO 在频域全局操作，与 EIT "每个测量受全场电导率影响" 的物理本质更匹配。但 FNO 需要规则网格输入，不直接适用于 FEM 网格。

#### D. Transformer 架构（2024–2025）

| 论文 | 时间 | 核心贡献 |
|------|:----:|----------|
| **EIT-Transformer** | IEEE TMI, 2024 | 电压测量序列作为 token，自注意力建模全局依赖，边界区域重建精度优于 MMV-Net |
| **CrossAttentionEIT** | 2025 | 交叉注意力融合多频率，显式建模频间相关性 |

**与项目的关系**：项目的频融合仅用 1×1 Conv。Cross-Attention 可显著提升多频信息利用率。

#### E. 物理信息神经网络 PINN-EIT（2023–2025）

| 论文 | 时间 | 核心贡献 |
|------|:----:|----------|
| **HP-EIT** — Hybrid Physics-Data EIT | 2024 | 混合物理-数据驱动，0.5M 参数达到高精度 |

- 项目已有 `PhysicsInformedEIT` 模型，方向一致
- 可借鉴：将 PDE 残差作为额外的物理损失项，强化无监督信号

#### F. Foundation Model 范式（2025–2026）

类似于 "EIT-BERT"：
- 在大规模多场景仿真数据上预训练基础重建模型
- 用 Adapter / LoRA 对特定场景（不同容器、电极、组织类型）微调
- 少样本（5–10 样本）即收敛

**与项目的关系**：与"通用算法"目标高度契合，是本建议文件 Phase C 的理论基础。

### 2.3 核心判断

1. **ConvSpatialEIT v2 没有过时** — 它是 2023–2024 年合理水平的设计，CNN-GNN 混合骨架仍是主流
2. **最大短板是数据多样性和多频融合** — 1×1 Conv 在 mixed 数据集上暴露不足
3. **最值得追的方向是物理先验注入 (DeepPrior 方向)** — 最小改动，最大杠杆
4. **GAT 注意力已被 2026 论文验证** — BoundaryAttn 就是 attention for EIT
5. **扩散模型和 Foundation Model 是终极方向** — 但工程投入大

## 3. 瓶颈定位

### 3.1 从训练记录看

| 指标 | circle-only | mixed | 差距原因 |
|------|:-----------:|:-----:|----------|
| RE | ~0.108 | ~0.33 | 形状+对比度多样性激增，统计映射失效 |
| CC | ~0.976 | ~0.918 | 结构一致性尚可，但定量精度不足 |
| 收敛 epoch | ~15 | >28（未收敛） | 数据复杂度增加，模型容量和训练策略不足 |

### 3.2 五个核心瓶颈

**1. 数据多样性不足（收益最大）**
- shape: 仅有圆/椭圆/多圆/环/多边形 5 类
- contrast: 仅 5x（0.05/0.01），真实场景 2–20x
- noise: 仅有高斯噪声，缺少电极偏移/脉冲/共模噪声
- 缺少真实根系形状的仿真数据

**2. 编码器容量受限**
- `base_ch=48`，输出 128 dim，对 4424/11466 单元来说编码维度偏低
- 3×3 Conv 感受野仅覆盖相邻电极对，无法捕获全局灵敏度模式
- 无通道注意力（SE/CBAM），特征通道等权处理

**3. 多频融合过于简单**
- 1×1 Conv 等价于线性加权融合
- 无法建模频率间的非线性交互（低频穿透深、高频分辨边界）
- 丢失频率选择性信息（不同频率对不同深度/尺寸的灵敏度不同）

**4. GNN 聚合缺少注意力**
- SimpleGNNLayer 使用 sum 聚合，等权对待所有邻居
- 边特征通过 sigmoid 门控调制权重，但缺少动态注意力
- 无法区分"重要边界"和"普通连接"

**5. 训练工程不够完善**
- 无 EMA 模型平滑
- LR 调度使用简单 CosineAnnealing，无 warm restart
- 损失函数对所有单元等权，边界过渡区域精度低
- 无数据增强（电压掩码已实现但未启用）

### A2. 编码器升级

代码量 ~60 行，预期 RE ↓ 0.02–0.03

**位置**: `models/conv_spatial_eit.py`

```python
class ConvEncoder(nn.Module):
    """Conv2D 编码器 v3
    - base_ch: 48 → 96（提升容量）
    - 新增 SE 通道注意力
    - 新增跳跃连接（保留多级特征）
    """
    def __init__(self, in_channels: int = 1, base_ch: int = 96):
        super().__init__()
        # ...原有结构，base_ch 升级...
        self.se = SEModule(base_ch * 4)  # 新增通道注意力

    def forward(self, x):
        # ...原有结构...
        x = self.se(x)  # 通道重校准
        return x, [feat1, feat2, feat3]  # 返回多级特征


class SEModule(nn.Module):
    """Squeeze-and-Excitation 通道注意力"""
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.gap = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction),
            nn.ReLU(),
            nn.Linear(channels // reduction, channels),
            nn.Sigmoid(),
        )

    def forward(self, x):
        b, c, _, _ = x.shape
        y = self.gap(x).view(b, c)
        y = self.fc(y).view(b, c, 1, 1)
        return x * y
```

**跳跃连接到 GNN**:

```python
# 在 forward() 中:
feat, multi_feats = self.encoder(x)
node_feat = self.sampler(feat)

# 跳跃连接：中间层特征也采样到节点
skip_feats = []
for f in multi_feats[:-1]:
    sf = self.sampler(f)
    skip_feats.append(sf)

node_feat = torch.cat([node_feat] + skip_feats, dim=-1)
```

### A3. GNN 升级为 GATv2

代码量 ~100 行，预期 RE ↓ 0.02–0.04

**位置**: `models/conv_spatial_eit.py`

```python
class GATv2Layer(nn.Module):
    """
    GATv2 图注意力层 (改进版 GAT，2022 ICLR)
    - 动态注意力（关注度取决于邻居双方）
    - 边特征作为注意力偏置
    - 多头注意力
    """
    def __init__(self, in_dim, out_dim, n_heads=4, dropout=0.1,
                 edge_dim=0):
        super().__init__()
        self.n_heads = n_heads
        self.head_dim = out_dim // n_heads
        assert out_dim % n_heads == 0

        # Q/K/V 投影
        self.W_q = nn.Linear(in_dim, out_dim, bias=False)
        self.W_k = nn.Linear(in_dim, out_dim, bias=False)
        self.W_v = nn.Linear(in_dim, out_dim, bias=False)

        # 注意力系数 MLP（GATv2 核心：拼接后过 MLP）
        attn_in_dim = self.head_dim * 2 + edge_dim if edge_dim > 0 else self.head_dim * 2
        self.a = nn.Sequential(
            nn.Linear(attn_in_dim, self.head_dim),
            nn.LeakyReLU(0.2),
            nn.Linear(self.head_dim, 1),
        )

        self.dropout = nn.Dropout(dropout)

    def forward(self, x, edge_idx, edge_weight, edge_feat=None):
        B, N, D = x.shape
        device = x.device
        n_edges = edge_idx.shape[1]
        src, dst = edge_idx

        # Q/K/V 投影 → 多头
        Q = self.W_q(x).view(B, N, self.n_heads, self.head_dim)
        K = self.W_k(x).view(B, N, self.n_heads, self.head_dim)
        V = self.W_v(x).view(B, N, self.n_heads, self.head_dim)

        Q_src = Q[:, src]
        K_dst = K[:, dst]

        # GATv2: 拼接 Q 和 K 后过 MLP
        attn_input = torch.cat([Q_src, K_dst], dim=-1)
        if edge_feat is not None:
            ef = edge_feat.unsqueeze(0).unsqueeze(2).expand(B, -1, self.n_heads, -1)
            attn_input = torch.cat([attn_input, ef], dim=-1)

        e = self.a(attn_input).squeeze(-1)

        # 掩码+softmax
        e = e.masked_fill(edge_weight.unsqueeze(0).unsqueeze(-1) == 0, float('-inf'))
        alpha = F.softmax(e, dim=1)
        alpha = self.dropout(alpha)

        # 消息聚合
        V_src = V[:, src]
        msg = V_src * alpha.unsqueeze(-1)

        x_agg = torch.zeros(B, N, self.n_heads, self.head_dim, device=device)
        x_agg.scatter_add_(
            1,
            dst.view(1, -1, 1, 1).expand(B, -1, self.n_heads, self.head_dim),
            msg,
        )
        x_agg = x_agg.view(B, N, -1)
        return x_agg
```

### A4. 多频 Cross-Attention 融合

代码量 ~50 行，预期 RE ↓ 0.01–0.02

**位置**: 替换 `ConvSpatialEIT.freq_fusion`

```python
class FrequencyCrossAttention(nn.Module):
    """
    频率交叉注意力融合
    每个频率 attend 所有其他频率的电压特征
    输出融合后的单频特征
    """
    def __init__(self, n_freq=6, n_meas=208, d_model=64):
        super().__init__()
        self.d_model = d_model

        # 将 13×16 电压图投影到 d_model 维
        self.proj = nn.Conv2d(n_freq, d_model, 1)
        self.pos_embed = nn.Parameter(torch.randn(1, d_model, 13, 16) * 0.02)

        # 自注意力
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)

        self.out_proj = nn.Conv2d(d_model, 1, 1)

    def forward(self, x):
        # x: (B, 6, 13, 16)
        B = x.shape[0]
        h = self.proj(x) + self.pos_embed          # (B, d, 13, 16)
        h_flat = h.view(B, self.d_model, -1)       # (B, d, 208)
        h_flat = h_flat.transpose(1, 2)             # (B, 208, d)

        Q = self.q_proj(h_flat)
        K = self.k_proj(h_flat)
        V = self.v_proj(h_flat)

        attn = torch.softmax(Q @ K.transpose(-2, -1) / (self.d_model ** 0.5), dim=-1)
        out = attn @ V                               # (B, 208, d)
        out = out.transpose(1, 2).view(B, self.d_model, 13, 16)
        out = self.out_proj(out)                     # (B, 1, 13, 16)
        return out
```

### B1. 三分支物理引导架构

代码量 ~400 行

```
PG-MeshTransformer: 物理引导的网格 Transformer EIT 重建
═══════════════════════════════════════════════════════════

输入: V (B, 6, 208) 多频边界电压
        │
   ┌────┼───────────────────┐
   │    │                   │
   ▼    ▼                   ▼
Branch A            Branch B             Branch C
Tikhonov/GN         Jᵀ(V − F(σ₀))        ConvEncoder
初始重建            残差反投影            Transformer
   │                 │                   │
   ▼                 ▼                   ▼
  σ₀_i               g_i                 z_v (全局特征)
(物理基线)          (物理梯度)           (数据驱动)
   │                 │                   │
   └─────────────────┼───────────────────┘
                     │
                     ▼
        节点特征: h_i = [σ₀_i, g_i, PE_i, z_v]
        每个 FEM 单元一个 token
                     │
                     ▼
          Transformer Mesh Encoder
          ┌────────────────────────┐
          │ 层归一化                │
          │ → 稀疏自注意力 (K=8+16) │  ← 只 attend 邻近+随机远距
          │ → FFN                   │
          │ × 6 层                  │
          └────────────────────────┘
                     │
                     ▼
              Δσ = OutputHead(h)
              σ̂  = σ₀ + Δσ
                     │
                     ▼
          Sigmoid [σ_min, σ_max]
                     │
                     ▼
                σ (B, n_elems)
```

**关键设计决策**:

1. **为什么 Tikhonov 初值 σ₀ 作为输入？**
   - 提供物理基线，告诉网络"正常预期是什么"
   - 网络只需学习残差 Δσ（比直接学 σ 更容易）
   - DeepPrior 已验证此方法的有效性

2. **为什么用 Transformer 替代 GNN？**
   - GNN 的 sum 聚合仍受限于 1-hop 邻域
   - Transformer 通过自注意力天然支持任意距离的交互
   - EIT 是全局灵敏度问题，Transformer 更适合
   - 稀疏注意力将复杂度从 O(N²) 降到 O(N)

3. **为什么保留 ConvEncoder？**
   - 电压特征是 13×16 规则网格，Conv2D 是最高效的编码方式
   - CNN 和 Transformer 各自在擅长的域操作

### B2. 稀疏 Transformer Mesh Encoder

```python
class SparseTransformerMeshEncoder(nn.Module):
    """
    稀疏 Transformer 网格编码器
    - 每个 FEM 单元作为一个 token
    - 稀疏注意力：K=8 几何近邻 + 16 随机采样
    - 位置编码使用 Fourier 特征
    """
    def __init__(self, d_model=256, n_layers=6, n_heads=8,
                 k_near=8, k_random=16):
        super().__init__()
        self.d_model = d_model
        self.k_near = k_near
        self.k_random = k_random

        self.layers = nn.ModuleList([
            TransformerBlock(d_model, n_heads)
            for _ in range(n_layers)
        ])

    def _build_sparse_attn_mask(self, centers, device):
        """构建稀疏注意力掩码"""
        n = len(centers)
        tree = cKDTree(centers)
        dists, idx_near = tree.query(centers, k=min(self.k_near + 1, n))
        idx_near = idx_near[:, 1:]

        idx_rand = np.random.randint(0, n, size=(n, self.k_random))
        attn_idx = np.unique(np.concatenate([idx_near, idx_rand], axis=1), axis=1)
        return torch.from_numpy(attn_idx).long()
```

### B3. 隐式神经表示辅助分支（可选）

```python
class ImplicitDecoder(nn.Module):
    """
    隐式神经表示解码器
    输入 (x, y) 坐标 → 输出 σ(x, y)
    使用 SIREN 激活函数 (sin)
    """
    def __init__(self, latent_dim=128, n_layers=4):
        super().__init__()
        layers = []
        dims = [2] + [latent_dim] * (n_layers - 1) + [1]
        for i in range(n_layers):
            layers.extend([
                nn.Linear(dims[i], dims[i+1]),
                nn.Sin() if i < n_layers - 1 else nn.Identity(),
            ])
        self.net = nn.Sequential(*layers)

    def forward(self, coords):
        return self.net(coords)  # (B, N, 1)
```

```python
class EITAdapter(nn.Module):
    """
    轻量场景适配器
    - 加在 Transformer 每层的 FFN 之后
    - 只有 ~20K 可训练参数
    - 冻结基础模型权重

    def __init__(self, d_model=256, bottleneck=32):
        super().__init__()
        self.down = nn.Linear(d_model, bottleneck)
        self.up = nn.Linear(bottleneck, d_model)

    def forward(self, x):
        return x + self.up(F.gelu(self.down(x)))
```
