# Conv-Spatial EIT 网络瓶颈分析与优化方案

> 2026-06-17 | 基于 gnn_hidden=512, 4.2M 参数模型的评估分析

---

## 当前架构

```
输入 (B,6,208)  ─┐
                  │ 仅取第1频率
  ConvEncoder  ◄──┘  (48 → 96 → 192 → 128, 13×16 不变)
  GridSampler       (13×16 双线性 → 11466 网格单元)
  位置编码          (+35维 Fourier + 半径)
  GNN × 4           (gnn_hidden=512, sum 聚合)
  OutputHead        (512 → 256 → 128 → 1)
  Sigmoid × range   → sigma (B, 11466)
```

### 参数分布

| 模块 | 参数量 | 占比 |
|------|-------:|:---:|
| Conv Encoder | 1,230,160 | 29.3% |
| GNN (4层) | 2,800,640 | 66.8% |
| Output Head | 164,353 | 3.9% |
| **总计** | **4,195,153** | 100% |

### 当前指标

| 训练阶段 | RE | CC | SSIM | IoU |
|----------|:------:|:------:|:------:|:------:|
| 有监督最佳 | **0.108** | **0.976** | **0.994** | **0.928** |
| 无监督精调 | 0.538 | -0.001 | 0.953 | 0.000 |

## 有监督训练瓶颈

### B1. 频率信息浪费 — 🔴 影响最大

**现状**：输入 (B, 6, 208) 但只取第 1 个频率 (B, 1, 13, 16)，丢失 83% 频率信息。

EIT 不同频率有本质差异：
- **低频 (1kHz)**：穿透深，对中心区域更敏感
- **高频 (500kHz)**：分辨率高，对边界变化更敏感
- 多频组合可降低逆问题病态性

**方案 A — 6 频浅层融合（推荐）**

```
(B,6,13,16) → Conv2d(6, 1, kernel=1, bias=False) → (B,1,13,16) → 原路径
```

- 仅增加 **6 个参数**
- 网络自动学习频率融合权重
- 推理速度几乎不变

**方案 B — 6 频独立编码 + 注意力融合**

```
(B,6,13,16) → 拆分为 6×(B,1,13,16) → 共享 ConvEncoder → 6×(B,128,13,16)
→ 注意力池化 → (B,128,13,16) → 原路径
```

- 参数量不增（共享 Encoder）
- 推理慢 1.3–1.5 倍
- 高频+低频互补，边界和中心重建均提升

**预期收益**：RE 0.108 → 0.07–0.08

---

### B2. 网格空间分辨率瓶颈 — 🟠

**现状**：208 个 grid 点（13×16）采样到 11466 个三角单元，**55 倍上采样**。

ConvEncoder 输出特征图只有 13×16，每个 grid 点覆盖大约 55 个网格单元，无法表达细粒度空间变化。

**方案**：增加上采样 Stage

```
(B,128,13,16) → ConvTranspose2d(128, 64, stride=2) → (B,64,26,32)
→ Conv2d(64, 256) → (B,256,26,32) → GridSampler → (B,11466,256)
```

- 空间点 4 倍增长（208 → 832）
- 每个 grid 点只对应约 14 个单元
- 增加约 0.3M 参数

**预期收益**：边界精度显著提升，细长根结构重建更好。

---

### B3. GNN 简单聚合限制表达能力 — 🟠

**现状**：`SimpleGNNLayer` 使用 `sum(neighbor × weight)` 聚合，所有邻居等权：

```python
x_agg[d] += neighbor_s * w  # 度归一化的静态权重
h = MLP([x; x_agg])
```

无法学习"哪些邻居的电压变化更值得关注"。

**方案**：GAT-style 注意力聚合

```python
# 每对源-目标计算注意力分数
attn = LeakyReLU(Linear([src_feat; dst_feat; edge_feat]))
alpha = softmax(attn)
x_agg = sum(alpha * neighbor)  # 加权聚合
```

- 每层增加约 50K 参数
- GNN 自动关注物理边界附近的邻居
- 重建的"块状伪影"会减少

**预期收益**：RE 降低 10–15%。

---

### B4. 训练数据单一 — 🟠

**现状**：全部训练样本是**单圆内含物**：
- 根区域占比 0.7%–8.8%
- 电导率固定对比度 5×
- 所有圆位于随机位置但都为规则圆形

有监督模型实际学到的是"找到一个圆形区域"，而非通用重建能力 — 泛化到真实根系横截面（不规则形状、多根交错）时会退化。

**方案**：多样化数据生成器

| 形状类型 | 说明 |
|----------|------|
| 椭圆 | 长短轴随机（模拟根截面椭圆） |
| 多圆 | 2-5 个随机位置（模拟多条根） |
| 不规则多边形 | Bezier 曲线生成（模拟真实根截面） |
| 环状 | 模拟空心根或管状结构 |
| 对比度变化 | 3× ~ 20×（模拟不同含水量土壤） |

**预期收益**：真实根系泛化能力显著提升，零样本迁移不退化。

## 无监督训练瓶颈

### U1. FEM 物理约束与有监督梯度冲突 — 🔴 致命

**现状**：

```python
loss_m: 完整FEM正向解 (fem_interval=20, fem_subset_size=4)
loss_t: TV正则 (w=0.05)
loss_d: 偏离参考惩罚 (w=0.01)

total = loss_m + 0.05*loss_t + 0.01*loss_d
```

问题分析：
1. **FEM 覆盖不足**：每 20 步只对 4/32 = 12.5% 样本跑完整 FEM，其余依赖 Jacobian 近似
2. **Jacobian 近似已证实不可靠**：之前实验 RE 从 0.14 → 0.54
3. **EIT 逆问题病态**：边界电压无法唯一确定内部电导率 → FEM 梯度方向可能**任意**
4. **loss_m 主导**：数值 0.2–0.5 vs TV 0.025 vs sigma 0.0001 → 模型主要跟随噪声梯度

**结果**：模型从 RE=0.108 退化为 RE=0.538（几乎输出均匀土壤，CC ≈ 0）。

---

### 解决方案

#### U1-Fix A — 半监督混合损失（推荐）

```python
total = 0.5 * MSE(sigma_pred, sigma_gt) + 0.5 * loss_physical
```

- 保留有监督信号作"锚点"
- 同时引入物理约束改进泛化
- 改动最小，1 行代码

**预期收益**：RE 0.54 → 0.12–0.15

#### U1-Fix B — 损失权重重调

```python
total = 0.1*loss_m + 0.5*loss_t + 0.1*loss_sigma + 0.1*loss_smooth
```

- 压制测量一致性，放大正则化
- 增加平滑项抑制高频噪声

**预期收益**：RE 0.54 → 0.15–0.20

#### U1-Fix C — 两阶段交替训练

```
偶数 epoch: full supervised (MSE on sigma)
奇数 epoch: full unsupervised (physical loss only)
```

让模型在"有监督锚点"和"无监督泛化"之间振荡。

**预期收益**：RE 0.54 → 0.10–0.13

#### U1-Fix D — 提高 FEM 频率

```python
fem_interval=1, fem_subset_size=0  # 每步全量FEM
```

代价：FEM 求解每样本约 0.5s，batch_size=32 时每步约 16s，50 epochs 约 2 小时。
配合 A/B 方案使用，不独立推荐。

---

### U2. 缺少平滑约束 — 🟠

当前 TV 正则只抑制梯度模长，没有显式约束平滑性。增加：

```python
loss_smooth = mean(|σ_pred_center - σ_pred_neighbor|²)  # 拉普拉斯平滑
```

## 瓶颈优先级总览

| 优先级 | 瓶颈 | 方案 | 预期 RE 改善 | 难度 | 计算开销 |
|:---:|------|------|:---:|:---:|:---:|
| 🔴 P0 | 无监督退化 | 半监督混合损失 | 0.54→0.12 | 低 | 无 |
| 🔴 P0 | 频率浪费 | 6 频浅层融合 | 0.108→0.07 | 低 | 1× |
| 🟠 P1 | 数据单一 | 多样形状生成器 | 泛化 ↑ | 中 | 无 |
| 🟠 P1 | GNN 简单聚合 | GAT 注意力 | RE ↓10% | 中 | 1.2× |
| 🟡 P2 | 网格分辨率 | 上采样 26×32 | 边界 ↑ | 中 | 1.3× |
| 🟡 P2 | 位置编码 | 可学习位置嵌入 | 适应 ↑ | 低 | 无 |
| 🟢 P3 | FEM 速度 | 预计算/批量化 | 训练 3× | 中 | 无 |

### 建议实施路径

```
Phase 1 (P0, 1-2h):
  ├── 6频浅层融合 → 有监督 RE 0.108→0.07
  └── 半监督混合损失 → 无监督 RE 0.54→0.12

Phase 2 (P1, 3-4h):
  ├── 数据生成器多样化 → 提升泛化
  └── GNN GAT 注意力 → 提升精度

Phase 3 (P2, 2-3h):
  ├── 特征图上采样 → 提升边界
  └── 可学习位置编码 → 提升适应
```
