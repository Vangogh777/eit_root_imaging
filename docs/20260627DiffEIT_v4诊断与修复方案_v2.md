## 0. 数据真相

```
mixed_dataset.h5 训练集:
  - BG=0.01 S/m 统一 (无多背景)
  - 每样本仅 2 个不同的 σ 值: bg=0.01 + 异常值 (0.033~0.10)
  - 异常占比: 1.8% ~ 9.1% (均值 ~5%)
  - 异常区 σ 值完全相同 ← 硬边界 phantom, 无平滑过渡
```

**这意味着**: 在标准化空间中，每样本的数据分布是:
```
[-0.22, -0.22, ..., -0.22, +2~+6, +2~+6, ..., +2~+6]
  ←── 93-98% ──→              ←── 2-7% ──→
```

这是**二值离散分布**，不是连续分布。DDPM/DDIM 假设数据服从连续分布，对二值 + 极端不平衡数据从根本上不适用。

## 1. 问题诊断（按致命程度排序）

### 🔴 致命 #1：数据是二值分布 —— DDPM 基本假设被打破

**现象**:
- 每样本仅 2 个 σ 值
- 标准化后: 95% 元素 = -0.22σ, 5% 元素 = +2~+6σ
- 无连续过渡区域

**影响**:
- DDPM 前向: `x_t = √ᾱ·x₀ + √(1-ᾱ)·ε` 产生的是两个重叠高斯的混合
- 高 t 时两高斯完全重叠 → 模型学不到区分 → 输出加权平均 → 坍缩到背景
- 低 t 时两高斯分离 → 模型能区分 → 但 95% 的 t 在重叠区
- DDIM 采样从纯噪声起步 → 整个前半段模型盲目猜测 → 倾向于输出背景（先验概率 95%）

**修复方案**:

**方案 A（推荐，零代码改动）: 给 phantom 加空间平滑 → 产生连续 σ 分布**

```python
# data/generate_mixed_dataset.py 修改:
# 不再用硬边界 mask, 而是对 mask 做高斯模糊/扩散

def smooth_sigma(sigma, centers, elements, sigma_smooth=0.005):
    """对硬边界 sigma 做图拉普拉斯平滑, 产生连续过渡"""
    # 用图 Laplacian 迭代平滑 2-3 次
    for _ in range(3):
        sigma_new = sigma.copy()
        for elem in range(len(sigma)):
            neighbors = get_neighbors(elem, elements)
            sigma_new[elem] = 0.7 * sigma[elem] + 0.3 * np.mean(sigma[neighbors])
        sigma = sigma_new
    return sigma
```

这会使边界从 2 个值变成连续的梯度过渡，产生丰富的中间 σ 值。

**方案 B: 给 σ 值加小量噪声 → 打散 Dirac delta**

```python
# 在数据生成后加 per-element 噪声
sigma += np.random.normal(0, 0.002, size=sigma.shape)  # ±0.002 S/m jitter
sigma = np.clip(sigma, sigma_min, sigma_max)
```

**方案 C: 多级对比度 phantom → 每样本 3+ 个 σ 层级**

```python
# 生成含 3-5 个嵌套区域的 phantom (类似洋葱)
# σ ∈ {bg, 0.02, 0.04, 0.06, 0.08} → 产生 5 级离散 → 更接近连续
```

### 🔴 致命 #2：标准化后的分布极端非高斯

**现象**:
```
标准化后: skewness=4.84 (正常=0), kurtosis=26.1 (正常=3)
p50 = -0.22σ  ← 一半以上元素完全相同
p90 = -0.22σ  ← 90% 元素完全相同!
p99 = +5.68σ  ← 只有最后 1% 不是背景
```

**影响**:
- DDPM 假设 `x_T ~ N(0, I)` — 前向扩散的终点是标准正态
- 但初始分布如果是离散的，`x_T` 的分布 ≠ N(0,I)（是离散卷积高斯的混合）
- 模型从 N(0,I) 初始化 DDIM → 起始分布与训练时 `x_T` 的真实分布不匹配 → 采样轨迹从错误起点出发

**修复方案**:

**方案 A: RankGauss 变换 → 强制正态分布**

```python
def compute_rankgauss_lookup(all_sigmas, n_bins=10000):
    """构建 RankGauss 查找表: σ_norm → σ_std (N(0,1))"""
    from scipy.special import erfinv
    sorted_vals = np.sort(all_sigmas)
    # 分位数 → 均匀 → 正态
    ranks = np.linspace(0, 1, len(sorted_vals))
    # 避免 ±∞
    ranks = np.clip(ranks, 1e-7, 1 - 1e-7)
    gauss_vals = np.sqrt(2) * erfinv(2 * ranks - 1)
    # 插值表
    return sorted_vals, gauss_vals

# 使用时: sigma_std = np.interp(sigma_phys, sorted_vals, gauss_vals)
```

这保证无论原始 σ 分布如何，变换后严格 N(0,1)。

**方案 B: 不用全局统计，用 per-sample 标准化**

```python
# 每个样本独立标准化（而非全局统计）
sigma_sample_mean = sigma_0.mean(dim=1, keepdim=True)
sigma_sample_std = sigma_0.std(dim=1, keepdim=True).clamp(min=0.01)
sigma_0_std = (sigma_0 - sigma_sample_mean) / sigma_sample_std
# 缺点: 推理时不知道 per-sample 统计量
```

### 🟡 重要 #3：加权 MSE 二次确认了模式坍塌方向

我之前的分析**方向正确但数据依据不足**。实际推理证实:

```
模型预测: pred_mean = 0.045~0.067 S/m (全部异常级别)
背景真实: 0.01 S/m
RE = 2.2~4.7 — 比全预测背景 (RE=0.5~0.8) 差 3-6x
```

weighted_mse_loss 的 `lambda_anomaly=15` 确实在推模型向异常值偏移。但修正此问题不能解决 #1 和 #2 — 数据二值性 + 分布非正态才是根因。

**修复**: 去除加权 loss → 纯 MSE + 强物理约束 (λ_phys=0.3~0.5)

### 🟡 重要 #4：物理一致性权重过低

```python
loss = loss_mse + 0.05 * loss_phys  # λ_phys 仅 0.05
```

物理约束占总 loss 的 ~1%，无法阻止模型输出物理不合理的 σ。

**修复**: `λ_phys = 0.3` (设计文档建议范围 0.01-0.1 太保守了)

### 🟢 次要 #5：数据无多背景 → 缺乏域泛化基础

数据 `bg_sigmas` 字段缺失 = 用 `--uniform_bg` 生成 = 所有样本 BG=0.01。

设计文档 (`20260626DiffV4重构方案.md` 4.3节) 要求:
```python

```

**修复**: 重新生成数据（加 `--uniform_bg` 以外的默认多背景模式），同时应用 #1 的平滑

## 3. 最小可行修复（P0+P1，~50行代码 + 重新生成数据）

### 3.1 数据生成改动 (`data/generate_mixed_dataset.py`)

```python
# 在 _generate_one() 中, sigma 赋值后加:
def _apply_spatial_smoothing(sigma, centers, elements, n_iter=3, strength=0.3):
    """图 Laplacian 平滑: 将二值 mask 变成连续 σ 分布"""
    from scipy.sparse import coo_matrix, eye
    n = len(sigma)
    # 构建邻接矩阵
    rows, cols, data = [], [], []
    for elem in range(n):
        neighbors = set()
        for tri in elements:
            if elem in tri:
                neighbors.update(tri)
        neighbors.discard(elem)
        for nb in neighbors:
            rows.append(elem); cols.append(nb); data.append(1.0)
    adj = coo_matrix((data, (rows, cols)), shape=(n, n)).tocsr()
    deg = np.array(adj.sum(axis=1)).flatten()
    deg[deg == 0] = 1.0
    # 迭代平滑
    s = sigma.copy()
    for _ in range(n_iter):
        s_new = adj.dot(s) / deg
        s = (1 - strength) * s + strength * s_new
    return s.astype(np.float32)

# 在 sigma 赋值后调用:
sigma = _apply_spatial_smoothing(sigma, centers, elements, n_iter=3, strength=0.3)
# 再加微小的 per-element jitter
sigma += rng.normal(0, 0.001, size=sigma.shape).astype(np.float32)
sigma = np.clip(sigma, bg_sigma * 0.9, inc_sigma * 1.5)
```

### 3.2 模型改动 (`models/diff_eit.py`)

```python
# (1) 新增 RankGauss 变换支持
def compute_rankgauss_params(all_sigmas, n_quantiles=10000):
    """构建 RankGauss 变换参数 — 训练前一次性计算"""
    from scipy.special import erfinv
    sorted_vals = np.sort(all_sigmas)
    quantiles = np.linspace(0, 1, n_quantiles)
    vals_at_quantiles = np.quantile(sorted_vals, quantiles)
    # 均匀 → 正态
    q_clipped = np.clip(quantiles, 1e-7, 1-1e-7)
    gauss_at_quantiles = np.sqrt(2) * erfinv(2 * q_clipped - 1)
    return vals_at_quantiles.astype(np.float32), gauss_at_quantiles.astype(np.float32)

# diff_eit.py: 注册为 buffer
self.register_buffer('rg_lookup_vals', torch.from_numpy(vals))
self.register_buffer('rg_lookup_gauss', torch.from_numpy(gauss))

# (2) forward() 使用 RankGauss 替代线性标准化
def _standardize(self, sigma_phys):
    """RankGauss: 物理 → 分位数 → N(0,1)"""
    sigma_norm = ((sigma_phys - self.sigma_min) / self.sigma_range).clamp(0, 1)
    # 二分查找 + 线性插值 在 lookup table 中
    idx = torch.searchsorted(self.rg_lookup_vals, sigma_phys.flatten())
    idx = idx.clamp(0, len(self.rg_lookup_gauss) - 2)
    # 简化: 用均匀分桶近似
    bin_idx = (sigma_norm * (len(self.rg_lookup_gauss) - 1)).long().clamp(
        0, len(self.rg_lookup_gauss) - 2)
    return self.rg_lookup_gauss[bin_idx].reshape_as(sigma_phys)

def _destandardize(self, sigma_std):
    """逆 RankGauss: N(0,1) → 分位数 → 物理"""
    # 反向查找
    idx = torch.searchsorted(self.rg_lookup_gauss, sigma_std.flatten())
    idx = idx.clamp(0, len(self.rg_lookup_vals) - 2)
    sigma_norm = idx.float() / len(self.rg_lookup_vals)
    return sigma_norm.reshape_as(sigma_std) * self.sigma_range + self.sigma_min

# (3) 输出头加 Tanh (mesh_unet.py)
self.out_head = nn.Sequential(
    nn.Linear(h//2, h//4), nn.GELU(), nn.Dropout(dropout * 0.5),
    nn.Linear(h//4, 1),
    nn.Tanh(),  # 约束到 [-1, 1], 覆盖核心 +-1σ 区间
)
```

## 6. 关键认知修正

### 之前（用"根"描述的版本）
> "根占 3.6%, 背景占 96.4%, 加权 MSE 导致模型输出根-level σ 处处"

**修正**: 
- 不是"根"——是通用 phantom（圆、椭圆、方形、环等 6 种形状）
- 本质问题是**数据是二值的**（每样本仅 2 个 σ 值），不是异常占比多少
- 扩散模型需要连续分布才能有效工作
- 占比 5% 只是加重了二值性导致的问题

### 核心问题链

```
数据二值（2 个 σ 值）
  → 标准化后仍是二值（-0.22σ + +2~6σ）
    → DDPM 前向 = 两个 Dirac delta 卷积高斯 → 非正态混合分布
      → 高 t 时信号被噪声完全淹没（两分布重叠）
        → 模型学不到区分, 只能输出先验均值（背景）
          → DDIM 采样从噪声起步, 早期步全输出背景
            → 后续步无法修正 → RE 比纯预测背景还差
```
