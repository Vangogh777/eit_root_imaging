### 关键洞察：扩散 EIT 仍处于早期

```
扩散 EIT 的发展时间线:
  2024: DDEIT — 首个 DDPM for EIT, 规则 grid, 无条件
  2025: Score-EIT — Score-SDE, 规则 grid, 测量一致性引导
```

**窗口期判断**：扩散 EIT 领域的论文数量 < 5 篇，方法论尚未固化。Alberti 2026 证明了"mesh 上做扩散可行"，但留了大量改进空间。我们现在进入，恰好可以定义这个子领域的标准做法。

## 2. 改进后的预期性能

### 逐层增益估算

以下估算基于各改进项解决的**结构性问题严重程度**，并结合类似架构在相关领域的已知提升幅度：

| 改进 | 解决的瓶颈 | 预期 RE 改善 | 推理依据 |
|------|-----------|:---:|------|
| **Tier 1**: 全层条件注入 | 深层盲操作 | **−20~30%** | 类似 ControlNet 的条件注入层级消融实验，去掉深层注入退化 20-40% |
| **Tier 2**: 灵敏度特征 | 空间灵敏度盲区 | **−10~18%** | J^T·V 提供的信息 ≈ 一步 GREIT 重建；已知 GREIT→GNN 提升 ~15-25% |
| **Tier 3**: Warm-start | 从 N(0,I) 起步浪费 | **−10~20%** | 残差方差约为全 σ 方差的 30-50%，等量训练下收敛更快 |
| **Tier 4**: GATv2 | 静态消息传递 | **−5~10%** | 类似架构中 GAT→GATv2 提升 3-8% (Cora/PPI benchmark) |
| **Tier 6**: x₀-pred + 余弦调度 | 数值稳定性 | **−5~8%** | 来自 DDPM 改进文献的经验值 |
| **Tier 6**: 物理引导 (C4) | 物理不一致 | **−3~8%** (OOD 更显著) | 类似 Alberti 引导 vs 无引导消融 (他们的提升 ~5-12%) |

**注意**：增益非简单叠加，有交互效应和递减。综合估算用乘法模型更合理：

```
RE_improved ≈ RE_baseline × (1 - 0.25) × (1 - 0.14) × (1 - 0.15) × (1 - 0.07) × (1 - 0.06)
            ≈ RE_baseline × 0.75 × 0.86 × 0.85 × 0.93 × 0.94
            ≈ RE_baseline × 0.48
```

## 3. 创新点论文价值评估

### 逐项评估

#### C1: 层次化 FEM Mesh 扩散 — ⭐⭐⭐ (中等创新)

| 维度 | 评价 |
|------|------|
| 新颖性 | Alberti 做了单层 mesh 扩散。我们做**多层** + skip connection。这是自然延伸但工程贡献显著 |
| 可消融 | ✅ vs 单层 GNN 扩散 |
| 论文定位 | "Improving mesh diffusion via hierarchical feature learning" |
| 风险 | 审稿人可能认为 U-Net 结构是"标准做法"，淡化贡献。需要用实验证明多尺度比单尺度好多少 |

**强化策略**：不要只宣称"我们用了 U-Net"，而是论证"单层 GNN 的感受野受限（在 4424 节点的图上需要 >10 跳才能覆盖全图），多尺度层次化在扩散的每一步将全局信息聚合成本从 O(k·N²) 降至 O(N log N)"。这是信息论理由，不只是工程偏好。

#### C2: 灵敏度感知条件注入 — ⭐⭐⭐⭐⭐ (高创新)

| 维度 | 评价 |
|------|------|
| 新颖性 | **据我们所知，首次将 J^T·V 和 J_energy 作为扩散模型的空间条件特征** |
| 可消融 | ✅ vs 仅全局电压条件 |
| 论文定位 | "Bridging physics-based and learning-based EIT: Jacobian sensitivity as spatial prior for diffusion models" |
| 风险 | 低。这个点子简单、有效、有物理解释、零成本 |

**这是论文最可能被记住的贡献**。它体现了"物理先验驱动数据驱动模型"的哲学——不是让网络从头学 EIT 物理（费数据且不可靠），而是把已知的物理（J 矩阵）直接"喂"给网络作为条件。

**强化策略**：做一张图——展示 J_energy 的空间分布（边界高、中心低），叠上重建误差的空间分布——两者高度相关。然后用消融实验证明注入灵敏度后，中心区域的重建质量显著改善。这是完美的 story。

#### C3: 确定性预热 + 残差扩散 — ⭐⭐⭐⭐ (中高创新)

| 维度 | 评价 |
|------|------|
| 新颖性 | 在 EIT 中首次。通用扩散领域有 warm-start 但 EIT 的 warm-start 来自物理模型（GREIT/GN），这与其他领域不同 |
| 可消融 | ✅ vs 纯扩散（无 warm-start），且 ablation 本身就是论文的关键图 |
| 论文定位 | "Why start from noise when you have physics? Warm-started residual diffusion for EIT" |
| 风险 | 审稿人可能说"这只是在做 residual learning，和 ResNet 一样"。需要强调**为什么在扩散中做残差和在确定性网络中做残差有本质不同** |

**强化策略**：关键论点是"扩散的生成能力 + 物理的确定性保证 = 两全其美"。散点图展示 warm-start 的 RE（例如 0.25）→ warm-start + diffusion (0.08)，两者之间的增益就是扩散的价值。

#### C4: Jacobian 物理梯度引导 — ⭐⭐⭐ (中等创新)

| 维度 | 评价 |
|------|------|
| 新颖性 | Alberti 有引导（TV+Tikhonov），我们用了更精确的 Jacobian 测量一致性。更精确但概念类似 |
| 可消融 | ✅ vs 无引导；✅ vs TV 引导 |
| 论文定位 | "Measurement-consistent physics guidance vs generic regularization for EIT diffusion sampling" |
| 风险 | 中。如果 RE 提升不大（< 5%），可能被审稿人视为 minor contribution |

**强化策略**：重点放在 OOD 泛化——TV 引导是通用图像先验，换一个成像对象可能不适用；Jacobian 引导是 EIT 物理，永远适用。用 OOD 实验（如训练在形状 phantom、测试在医学 phantom）来展示差距。

### 创新点矩阵（论文视角）

```
                    新颖性    实验可验证性    故事性    综合评分
C1: 层次化扩散       ⭐⭐⭐     ⭐⭐⭐⭐⭐      ⭐⭐⭐      ⭐⭐⭐½
C2: 灵敏度条件       ⭐⭐⭐⭐⭐   ⭐⭐⭐⭐⭐      ⭐⭐⭐⭐⭐    ⭐⭐⭐⭐⭐
```

## 4. 论文可行性结论

### 总体判断：✅ 可发表，瞄准 TMI

**4 项贡献均超过 TMI 门槛**，其中 C2（灵敏度条件注入）有成为"该子领域标准做法"的潜力。

### 对标分析：与 Alberti RDPS (2026) 比较

| 维度 | Alberti RDPS | DiffEIT (改进后) | 优势 |
|------|:---:|:---:|:---:|
| 扩散基 | Score-SDE | DDPM+DDIM | ≈ |
| Mesh 操作 | ✅ 单层 GNN | ✅ **多尺度 GNN U-Net** | DiffEIT |
| 条件注入 | 全局 V | **每层 V + J^T·V + J_energy** | DiffEIT |
| 预热 | ✗ | **线性 GREIT warm-start** | DiffEIT |
| 引导 | TV + Tikhonov | **Jacobian 测量一致性** | DiffEIT |
| 不确定性 | ✅ | ✅ **+ 校准分析** | DiffEIT |
| 实验 | 简单 phantom | **多种 phantom + OOD + 噪声鲁棒** | DiffEIT |
| 代码开源 | ? | ✅ 可开源 | DiffEIT |

**我们在每一个维度上都是 Alberti 的超集**。如果 Alberti 能发（它很可能已经被 TMI 接收或正在审稿），我们就能发更好的。

### 不发表的概率（及应对）

| 风险 | 概率 | 致命程度 | 应对 |
|------|:---:|:---:|------|
| 训练不收敛，RE > 0.15 | 20% | 🔴 致命 | Tier 1+2 先做，这两项不增加训练难度；若仍不收敛，增加监督预训练阶段（类似 ConvSpatialEIT 的两阶段） |
| 消融实验不显著（某项贡献 < 3% 提升） | 30% | 🟡 可降级 | 将不显著的贡献移到 appendix 或降级为 "design choice"；保留 2 个最显著的作为 main contributions |
| 物理引导不 work | 25% | 🟢 不致命 | 放在 appendix 或作为 "preliminary exploration"；C1+C2+C3 已经足够支撑一篇 TMI |
| 不确定性校准差（方差与误差不相关） | 35% | 🟡 可补救 | 用 temperature scaling 或 conformal prediction 做后处理校准；若仍不行，弱化不确定性 claim，作为定性展示 |
| Alberti 抢先发表 | 15% | 🟡 可调整 | 如果 Alberti 的实验更全面，我们的定位变成 "DiffEIT: Improving mesh diffusion EIT via sensitivity-aware conditioning and warm-start"——承认真实竞品但展示显著改进 |

### 综合概率估计

```
P(可发 TMI)      ≈ 60%  (需要多项改进生效 + 实验全面 + 写作好)
P(可发 MedIA)    ≈ 75%  (标准略低，更看重方法新颖性)
P(可发 IEEE TIM) ≈ 90%  (有明确的数值提升 + 应用价值即可)
P(至少发一篇)    ≈ 90%+ 
```

```
3. Method
   3.1 Preliminaries: EIT forward model & Jacobian
   3.2 Hierarchical Mesh Diffusion (C1)
```

### 5.3 实验矩阵

| 实验 | 数据集 | 指标 | 关键假设 |
|------|--------|------|---------|
| **主表** | shapes + mixed_root + medical phantom | RE, CC, SSIM, PSNR | DiffEIT > 所有 baseline |
| **消融** | shapes | ΔRE per contribution | 每个贡献 ≥ 5% 提升 |

### 5.4 写作核心叙事

> "EIT reconstructs conductivity from boundary voltages — a severely ill-posed inverse problem where different conductivity distributions can produce near-identical measurements. Standard deep learning approaches give deterministic point estimates without quantifying reliability.
>
> We introduce DiffEIT, a diffusion model that operates directly on the FEM mesh. Our key insight is that **EIT physics, encoded in the Jacobian sensitivity matrix, can serve as spatial conditioning** for the diffusion process — telling the model at every denoising step which regions are well-constrained by measurements and which are not.
>
> We also propose a warm-start strategy: rather than diffusing from random noise, we start from a linear GREIT reconstruction and diffuse only the residual. This leverages the fact that EIT, unlike natural images, admits a cheap physics-based initial guess.
>
> Experiments across multiple phantom types show that DiffEIT achieves **RE of 0.08** (vs 0.10 for the best existing method), provides calibrated uncertainty estimates, and generalizes to unseen geometries with less than 20% degradation."

## 7. 底线判断

**如果改进后 RE 能达到 0.08–0.10**（现实假设），且消融实验能证明每个贡献 ≥ 5% 的提升，这篇论文完全具备冲击 TMI 的条件。

**如果某几项改进效果不显著**，退一步——保留最显著的 2 项贡献 + 不确定性量化 + 全面的实验对比，依然可以发 MedIA 或 IEEE TIM。

**唯一不能接受的结果**是改进后 RE 仍然 > 0.15（接近 Alberti 或更差）。这种情况概率较低（估计 < 15%），但如果发生，需要检查训练是否收敛、数据集是否有问题、baseline 是否已被充分调优。
