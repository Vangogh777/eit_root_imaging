## 0. v3 为什么失败 — 根因回顾

### 定量现实

| 指标 | DiffEIT v3 | ConvSpatialEIT | 设计目标 |
|---|:---:|:---:|:---:|
| RE | 0.632 | 0.103 (best) | < 0.12 |
| CC | 0.505 | 0.954 | > 0.6 |
| SSIM | 0.000 | 0.994 | > 0.9 |
| 参数量 | 38.8M | 6M | — |
| 输出范围 | [0.0098, 0.0101] | 正常 | 匹配 GT |

模型输出几乎是纯背景值，完全未重建任何结构。

### 三个根因 (通用性视角)

**🔴 根因 #1 (致命, ~80%)：扩散在物理空间运行 → SNR 崩溃**

标准 DDPM 假设数据归一化到方差 ~1。当前直接在 σ ∈ [0.005, 0.1] S/m (std=0.0066) 上做扩散，噪声 ε ~ N(0,1) → SNR < 0.01 for 95% 步数。

更严重的是从通用性视角：不同应用的 σ 范围差异巨大 (医学 ~10⁻¹, 工业 ~10⁷, 土壤 ~10⁻²)。扩散在原始物理空间运行 = 每个应用需要完全不同的噪声调度。

**🔴 根因 #2：σ 范围 hardcode → 不可跨域迁移**

```python
# diff_eit.py:92-93 — 当前代码
sigma_min: float = 0.005,   # ← hardcoded
sigma_max: float = 0.1,     # ← hardcoded
```

Sigmoid 输出被钳位在这个范围。当前混合数据集 (circle/ellipse/square/ring 等 6 种 phantom, BG=0.01 S/m, contrast 3x-10x) 恰好落在这个范围内，但换到医学 EIT (σ ∈ [0.05, 0.5]) 或工业 EIT (σ ∈ [10⁻³, 10⁷])，模型架构上就错了。通用算法不能假设 σ 范围。

**🔴 根因 #3：Warm-start 的线性近似不可跨域迁移**

```python
# diff_eit.py:173 — hardcoded
lam = 0.01 * np.eye(J_np.shape[0])  # ← Tikhonov λ 针对 σ≈0.01
```

线性最小二乘 J_pinv 从均匀背景计算，无法处理 3x-10x 对比度。不同应用的背景 σ 差异巨大 → λ 必须不同。且 RE=2.75 的 warm-start 不如不用。

**🟡 根因 #4：noise_scale=0.5 hack**

为补偿 warm-start 残差的小方差而引入。训练前向使用 `noise_scale=0.5`，但 DDIM 反向假设标准 DDPM (noise_scale=1.0)。训练-推理不一致。

**🔴 根因 #5：类不平衡 → 背景主导梯度 (新发现)**

内含物仅占 3.6% 的元素。MSE loss 下：
- 纯背景预测的 MSE = 0.0064（归一化空间）
- v3 实际 val_loss = 0.0027
- 模型只比"永远输出背景"好 2.4 倍

96.4% 的梯度来自背景元素。模型的最优策略是先把背景学好（MSE 已经很低），内含物的微弱梯度信号不足以驱动有意义的异常重建。这是**独立于 SNR 问题的第二个致命伤**——即使归一化修复了 SNR，类不平衡仍会导致模型坍缩到背景。

### 架构本身没问题

当 t=0 (干净输入, ᾱ=1.0) 时，MeshUNet 重建 RE=0.02 —— 几乎完美。证明：
- GNN 架构 ✅
- FiLM 全层条件注入 ✅
- 灵敏度特征 J^T·V ✅
- 瓶颈 Cross-Attention ✅
- x₀-prediction + Sigmoid 输出 ✅

**问题完全在扩散过程的工程实现，不在网络架构。**

### SNR 定量分析：为什么归一化到 [0,1] 不够

归一化到 [0,1] 后，数据 std = 0.078（因为 96.4% 元素是背景，方差天然小）。与标准 DDPM 所需 SNR ≈ 1 相比仍有差距：

```
SNR @ t=250 (扩散中点, ᾱ≈0.49):
  物理空间:       4.3×10⁻⁵   ← v3 (信号完全淹没)
  归一化 [0,1]:    0.006      ← v4 初版方案 (改善 140x, 但仍太低)
  标准化 N(0,1):   0.98       ← 标准 DDPM 工作区
```

**结论**：仅归一化到 [0,1] 不足以让扩散模型正常工作。需要升级归一化策略 + 减小 T。

## 1. v4 设计原则

从"通用 EIT 算法"定位出发的五条铁律：

| # | 原则 | 含义 |
|---|------|------|
| 1 | **扩散在归一化空间** | 所有扩散操作 (加噪/去噪/采样) 在 [0,1] 或 N(0,1) 空间。物理范围仅在 I/O 边界做 scale/unscale |
| 2 | **σ 范围为输入参数** | σ_min/σ_max 从数据统计推断或配置文件读取，不 hardcode |
| 3 | **物理先验 > 数据先验** | J^T·V、J_energy、测量一致性梯度 → 这些来自 Maxwell 方程，跨域不变。数据分布的统计规律不可跨域迁移 |
| 4 | **先验证简单，再叠复杂度** | 先去 warm-start/noise_scale hack/无条件阶段。用标准 DDPM + 归一化数据验证 → 逐步加回优化 |
| 5 | **多域数据训练 + 多域评估** | 训练数据至少包含 4 种 phantom 类型 + 多对比度 + 多噪声水平。OOD 泛化测试是硬性要求，不是可选项 |

## 2. 架构改动 (v3 → v4)

### 2.1 数据流重构 (核心改动)

```
v3 (错误):
  σ_0 (物理, [0.005, 0.1]) → forward_diffuse(物理空间) → σ_t (物理)
  → MeshUNet → Sigmoid → σ_pred (归一化) → loss vs σ_true_norm
  问题: 扩散在物理空间, SNR 崩溃 (10⁻⁵), 信号完全淹没

v4 (两阶段归一化):
  Step 1 — 归一化到 [0,1]:
    σ_norm = (σ_phys - σ_min) / σ_range

  Step 2 — 标准化到 N(0,1):
    σ_std = (σ_norm - μ_data) / σ_data    ← 使数据方差=1, 与噪声 ε~N(0,1) 匹配

  → forward_diffuse(标准化空间) → σ_t_std
  → MeshUNet (去掉 Sigmoid, 改用 tanh 或无约束) → σ_pred_std
  → loss vs σ_0_std
  → unstandardize → σ_pred_norm → unnormalize → σ_pred_phys

  关键:
    - SNR @ t=250 从 4.3×10⁻⁵ → 0.98 (与标准 DDPM 假设一致)
    - 同时减小 T 到 200-300 (减少低 SNR 步数浪费)
    - 输出头从 Sigmoid 改为 tanh 或 Linear (支持负值)
```

## 3. 关键代码变更 (详细)

### 3.1 两步归一化策略

```python
# === 新增: 数据统计计算 (train_diff_eit.py 中) ===
def compute_sigma_stats(dataloader, n_samples=5000):
    """从训练数据推断归一化参数"""
    samples = []
    for batch in dataloader:
        samples.append(batch['sigmas'].numpy().ravel())
        if len(np.concatenate(samples)) > n_samples * 4424:
            break
    all_sigmas = np.concatenate(samples)

    sigma_min = float(np.percentile(all_sigmas, 0.1))
    sigma_max = float(np.percentile(all_sigmas, 99.9))

    # 归一化到 [0,1] 后的统计
    sigma_norm = (all_sigmas - sigma_min) / (sigma_max - sigma_min)
    sigma_mean = float(np.mean(sigma_norm))
    sigma_std = float(np.std(sigma_norm))

    return sigma_min, sigma_max, sigma_mean, sigma_std
```

### 3.2 `models/diff_eit.py` — forward()

```python
# === v4: 两步归一化 + 标准化空间扩散 ===
def forward(self, sigma_0, t, V):
    """
    sigma_0: (B, n_elems) 物理空间电导率
    t: (B,) 时间步
    V: (B, 6, 208) 电压

    Returns: sigma_0_pred_std (B, n_elems, 1), sigma_0_std (B, n_elems, 1)
    两者均在 N(0,1) 标准化空间
    """
    B = sigma_0.shape[0]
    device = sigma_0.device

    # === Step 1: 归一化到 [0, 1] ===
    sigma_0_norm = ((sigma_0 - self.sigma_min) / self.sigma_range).clamp(0, 1)

    # === Step 2: 标准化到 N(0,1) ===
    sigma_0_std = (sigma_0_norm - self.sigma_mean) / self.sigma_std
    # 现在 sigma_0_std ~ N(0, 1), 与噪声 ε ~ N(0,1) 匹配

    # === Step 3: 标准 DDPM 前向加噪 (标准化空间) ===
    sigma_t_std, noise = self.diffusion.forward_diffuse(sigma_0_std, t)
    # SNR @ t=250 ≈ 0.98 — 标准 DDPM 工作区

    # === Step 4: 条件编码 ===
    t_emb = self.time_embed(t)
    v_emb = self.voltage_encoder(V) if V is not None else torch.zeros(
        B, self.voltage_dim, device=device)
    extra_feat = self._compute_sensitivity_features(V)

    # === Step 5: 去噪 (标准化空间) ===
    sigma_0_pred_std = self.denoiser(
        sigma_t_std.unsqueeze(-1),  # (B, n_elems, 1)
        t_emb, v_emb,
        extra_feat=extra_feat,
    )  # (B, n_elems, 1) — Tanh 输出 (可正可负)

    return sigma_0_pred_std, sigma_0_std.unsqueeze(-1)
```

```python
    # ... 电压编码 (同 v3) ...

    def denoise_fn(sigma_t_std_batch, t_tensor, v_emb_in):
        """标准化空间 → 标准化空间"""
        # ... reshape + MeshUNet ...
        sigma_0_pred_std = self.denoiser(sigma_t_std_batch, t_emb, v_emb_in, extra_feat=ef)
        return sigma_0_pred_std.squeeze(0).squeeze(-1)  # (n_elems,)

    samples = []
    for _ in range(n_samples):
        # DDIM 采样 (标准化空间, 标准 N(0,1) 初始化)
        sigma_std = self.diffusion.ddim_sample_normalized(
            denoise_fn, v_emb, self.n_elems, n_steps=n_steps,
        )  # (n_elems,) 在标准化空间

        # === 逆变换: 标准化 → [0,1] → 物理 ===
        sigma_norm = sigma_std * self.sigma_std + self.sigma_mean  # N(0,1) → [0,1]
        sigma_norm = sigma_norm.clamp(0, 1)
        sigma_phys = sigma_norm * self.sigma_range + self.sigma_min  # [0,1] → S/m
        sigma_phys = sigma_phys.clamp(self.sigma_min, self.sigma_max)
        samples.append(sigma_phys)

    return samples[0] if n_samples == 1 else torch.stack(samples)
```

### 3.5 `train_diff_eit.py` — 加权 Loss + val_RE 监控

```python
# === 加权 MSE: 异常区域权重 ×λ_anomaly ===
def weighted_mse_loss(pred, target, mask=None, lambda_anomaly=15.0):
    """
    pred, target: (B, n_elems, 1) 标准化空间
    mask: (B, n_elems) 异常区域 mask (可选, 从 sigma_gt 计算)
          mask = (sigma_gt_norm > bg_threshold)
    """
    sq_error = (pred - target) ** 2
    if mask is not None:
        # 背景权重 1.0, 异常权重 lambda_anomaly
        weights = 1.0 + (lambda_anomaly - 1.0) * mask.float().unsqueeze(-1)
        return (weights * sq_error).mean()
    return sq_error.mean()

# 训练循环中:
sigma_0_pred, sigma_0_true = model(sigma_0, t, V)

# 计算异常 mask (物理空间: 高于背景阈值的元素)
sigma_0_norm_1d = (sigma_0 - model.sigma_min) / model.sigma_range
anomaly_mask = sigma_0_norm_1d > (bg_value_norm + 0.02)  # 比背景高 2% 以上

loss = weighted_mse_loss(sigma_0_pred, sigma_0_true, mask=anomaly_mask)

# === 每 10 epoch 跑 val_RE ===
if epoch % 10 == 0:
    val_re = compute_val_re(model, val_loader, n_steps=20, device=device)
    recorder.log_metric('val_RE', val_re, epoch)
    print(f'  Val RE (DDIM 20steps): {val_re:.4f}')
```

**这已经满足通用算法的形状多样性要求。** 对比度 3x-10x 随机，噪声 -40~-20dB 随机，位置边缘/中心平衡采样。

### 4.2 当前数据的通用性不足

从通用 EIT 视角，当前数据有两个局限:

1. **背景 σ 固定为 0.01 S/m** — `BG_SIGMA = 0.01` hardcode 在生成脚本中。通用算法应该见过不同背景 σ (模拟不同应用场景: 医学 ~0.3, 工业 ~10⁷, 土壤 ~0.01)
2. **σ 范围固定** — 所有样本的 σ ∈ [0.01, ~0.1]。模型学到的归一化映射 `(σ - 0.005) / 0.095` 在别的应用 domain 可能完全失效

## 5. GATv2 替换 (Tier 4)

### 5.1 为什么

SimpleGNN 用固定边权重 scatter_add — 静态聚合。GATv2 的动态注意力可以根据节点当前特征决定关注哪个邻居。对于通用算法，不同场景下的"有效感受野"应该不同 (高对比度需要更大范围消息传递)。

### 5.2 改动

`models/mesh_unet.py` `MeshConvBlock.__init__`:

```python
# 当前:
from models.conv_spatial_eit import SimpleGNNLayer
self.gnn = SimpleGNNLayer(in_dim, out_dim, dropout=dropout, edge_dim=edge_dim)

# v4:
from models.conv_spatial_eit import GATv2Layer
self.gnn = GATv2Layer(in_dim, out_dim, dropout=dropout, n_heads=4, edge_dim=edge_dim)
```

约束: `out_dim` 必须能被 `n_heads` 整除。当前 hidden_dim=384 → L0: 384/4=96 ✅, L1: 768/4=192 ✅, L2: 768/4=192 ✅, BN: 768/4=192 ✅。

显存增量: ~10-15%。参数增量: ~5%。

## 11. 差距分析：从"修 bug"到"高精度 + 高泛化"

v4-MVP 修的是致命 bug（SNR 崩溃 + 类不平衡）。但修完 bug ≠ 达到高精度高泛化。以下是 v4-MVP 之外仍然缺失的能力，按对泛化性的影响排序。

### 11.1 灵敏度特征仅注入 L0 输入 → 深层看不到物理灵敏度

**现状**: J^T·V 和 J_energy 只在 `node_proj` 输入层拼接。L1/L2/Bottleneck 的节点是通过 FPS 池化得来的，丢失了原始的灵敏度信息。

**问题**: EIT 灵敏度空间差异极大（中心 vs 边界 100 倍）。粗层（L2, ~275 nodes）需要知道"我代表的这片区域整体灵敏度如何"——这决定了该区域的重建可信度。没有这个信息，粗层在做盲猜测。

**修复** (`mesh_unet.py` + `mesh_pooling.py`):

```python
# 在 build_hierarchy 中为每层预计算 pooled 灵敏度
for level in range(n_levels):
    # J_energy_pooled[l] = scatter_mean(J_energy[child], cluster)
    hierarchy[l]['J_energy'] = pooled_J_energy  # 逐层预计算

# 在 MeshUNet.forward() 中:
# 每个 level 的节点特征拼接该层的 J_energy 和 J_T_V_pooled
# → 每层都能感知"我负责的区域有多灵敏"
```

**泛化性影响**: 🔴 高。灵敏度是物理先验——换 mesh 几何或电极配置后重新计算 J 即可迁移。不给深层灵敏度 = 深层依赖数据先验。

### 11.2 物理一致性 loss 缺失 → 训练不约束测量保真度

**现状**: 训练只用 MSE(σ_pred, σ_true)。模型可以输出物理上不可能的 σ（比如产生完全不同的电压但仍满足 MSE）。

**问题**: EIT 反问题是严重病态的——不同 σ 分布可以产生几乎相同的 V。MSE 约束的是 σ 空间，但真正重要的是 V 空间的一致性。对泛化性来说，**测量一致性是唯一跨域不变的硬约束**。

**修复** (`train_diff_eit.py`):

```python
# 新增: 测量一致性 loss (仅用 J 线性近似, 无需跑 FEM)
def measurement_consistency_loss(sigma_pred_phys, V_measured, J, sigma_ref):
    """
    sigma_pred_phys: (B, n_elems) 物理空间预测
    V_measured: (B, 208) 测量电压
    J: (208, n_elems) 灵敏度矩阵
    """
    delta_sigma = sigma_pred_phys - sigma_ref
    V_pred = delta_sigma @ J.T  # (B, 208) Jacobian 线性近似
    return F.mse_loss(V_pred, V_measured)  # 零额外参数, 纯物理

# 总 loss:
loss = mse_weighted + λ_meas * loss_meas  # λ_meas ≈ 0.01-0.1
```

**泛化性影响**: 🔴 高。这是零数据依赖的纯物理约束——换任何应用 domain，Maxwell 方程不变。是通用算法对抗 OOD 的最强武器。

### 11.3 物理梯度引导 (C4) 仍未实现 → 采样阶段无物理约束

**现状**: v4-MVP 的 DDIM 采样是纯数据驱动的。去噪器输出什么就是什么。

**问题**: 纯数据驱动的扩散可能生成"看起来合理"但 F(σ) ≠ V 的解。对泛化性来说这尤其危险——训练数据分布之外，模型会生成幻觉。

**修复** (`models/diffusion_utils.py` ddim_sample 中):

```python
# DDIM 每步加入 Jacobian 测量一致性梯度:
with torch.enable_grad():
    sigma_0_hat.requires_grad_(True)
    delta_sigma = sigma_0_hat - sigma_ref  # 反标准化后
    V_pred = delta_sigma @ J.T
    phys_loss = F.mse_loss(V_pred, V_measured)
    grad_phys = torch.autograd.grad(phys_loss, sigma_0_hat)[0]

epsilon_guided = epsilon_pred + w_phys(t) * grad_phys
# w_phys 调度: 早期 0.3 → 后期 0.02
```

**泛化性影响**: 🔴 高。这是设计文档 C4 的核心贡献——在采样阶段用物理引导纠正数据驱动的偏差，是泛化性的最后防线。

### 11.4 频率信息被平均丢弃 → 丢失物理信息维度

**现状**: `VoltageEncoder` 对 6 个频率做 cross-attention 后取平均 → 单个 512-dim 向量。

**问题**: 真实多频 EIT 中，不同频率的电流穿透深度和灵敏度分布不同（虽然 pyEIT 目前不区分频率，但架构应为真实多频数据做好准备）。频率维度的信息对分辨不同深度的异常至关重要。

**修复** (`models/diff_eit.py` VoltageEncoder):

```python
# 保留频率维度: 输出 (B, n_freq, voltage_dim) 而非 (B, voltage_dim)
# 在 MeshUNet 中, 不同层关注不同频率:
#   L0 (精细): 高频 → 浅层/边界信息
#   BN (粗):   低频 → 深层/全局信息
# 或: 每个 FiLM 层对不同频率做加权组合
```

**泛化性影响**: 🟡 中。pyEIT 目前不区分频率，短期收益有限。但架构应预留。

### 11.5 FPS 池化破坏 FEM 拓扑 → 边界模糊

**现状**: FPS 基于欧氏距离选锚点，不考虑三角单元连通性。

**问题**: 两个空间接近但被绝缘体隔开的 FEM 元素会被池化到同一个父节点，混合不同介质的特征。对高精度重建（需要清晰边界），这是精度瓶颈。

**修复**: 后续用 Graclus 图聚类或 learned pooling 替代 FPS。改设计文档的 Tier 5。

**泛化性影响**: 🟡 中。主要影响边界清晰度（精度），对泛化性影响相对小。

### 11.6 训练数据缺乏域多样性 → 学的是分布不是物理

**现状**: 所有训练样本 BG=0.01 S/m, σ ∈ [0.01, ~0.1]。模型没见过其他背景 σ。

**问题**: 在 σ_bg=0.3 S/m 的医学场景部署时，模型的两步归一化参数 (sigma_min/max/mean/std) 完全失配。模型需要见过多样化的 σ 范围才能学到"对比度"这个抽象概念而非记住特定 σ 值。

**修复** (`data/generate_mixed_dataset.py`):

```python
# 新增: 可变背景 σ
BG_SIGMAS = [0.005, 0.01, 0.02, 0.05, 0.1, 0.3]  # 覆盖多应用
# 生成时随机选背景，内含物用 contrast 乘数 (保持 3x-10x)
# 模型学到: "异常是相对背景的对比度变化"，而非"异常=0.05 S/m"

# 新增: 对比度外推训练
# 训练: contrast ∈ [1.5, 5]
# 验证: contrast ∈ [6, 15]  → 测试对比度泛化
```

**泛化性影响**: 🔴 高。这是域泛化的数据基础。模型必须见过多个 σ 范围才能学会"对比度"这个抽象概念。但数据生成成本低（改参数重跑即可）。

### 11.7 推理时的域自适应未设计 → 部署到新域需要重新训练

**现状**: 推理需要 sigma_min/max/mean/std 参数。如果部署到新应用（不同 σ 范围），这些参数需要手动指定或重新统计训练数据。

**问题**: 通用算法应该能从电压测量中**自动推断** σ 范围，或至少提供合理的默认值。

**修复**:

```python
# 方案 A: 从电压量级粗略推断 σ 范围
def estimate_sigma_range_from_voltage(V, J, sigma_ref):
    """利用 J_pinv 给出粗估计的 σ 范围"""
    sigma_coarse = sigma_ref + J_pinv @ (V - J @ sigma_ref)
    sigma_min = max(0, sigma_coarse.min() * 0.5)
    sigma_max = sigma_coarse.max() * 2.0
    return sigma_min, sigma_max

# 方案 B: 使用相对对比度 (推荐)
# 模型始终输出 "相对背景的对比度变化"
# σ_pred = σ_ref * (1 + α·Δσ_norm)  其中 α 是全局 contrast scale
# 推理时只需要 σ_ref (背景电导率, 用户提供或从 V 推断)
```

**泛化性影响**: 🟡 中。部署便利性，非核心精度问题。
