# EIT 深度学习重建：前沿综述与改进方案

> 创建: 2026-06-25 | 基于 arXiv 2024-2026 论文 + 当前项目实践

---

## 1. 当前项目现状

### 1.1 两条模型线

| 模型 | 架构 | 当前最佳 RE | 瓶颈 |
|------|------|:----------:|------|
| **ConvSpatialEIT** | CNN(GridSampler) → GNN → sigmoid | 0.35 | CNN插值瓶颈、sigmoid压缩、端到端盲学 |
| **ResidualEIT** | GREIT粗重建 → GNN修正残差 | 0.30 | 粗重建太渣(RE=0.52)、修正器容量不足 |

### 1.2 根本矛盾

```
208 个边界电压 → 4424~6528 个电导率值 = 1:21~31 的信息扩张比
```

EIT 逆问题是**严重病态的**（J^T J 条件数 ~10^13）。无论架构怎么变，208 个测量值携带的信息量是有理论上限的。关键不是"用更大模型暴力拟合"，而是**把物理先验嵌入架构**、**降低模型需要学习的有效复杂度**。

## 2. 前沿文献综述（2024-2026）

### 2.1 四大主流路线

```
        传统重建
           │
    ┌──────┼──────┬──────────────┐
    ▼      ▼      ▼              ▼
  后处理  迭代展开  神经校正算子   扩散模型
(CNN修)  (GN+GNN) (粗估+修正)   (采样+先验)
```

#### 路线 A: 传统重建 + CNN 后处理

| 论文 | 期刊/时间 | 做法 | 关键结论 |
|------|:--------:|------|---------|
| **Deep Calderón** (Cen et al.) | JCP 2023 | Calderón 方法粗重建 → U-Net 精修 | 后处理显著提升，对真实数据泛化好 |
| **Beltrami-Net** (Hamilton et al.) | PMB 2019 | D-bar 方法 → CNN | 训练数据不依赖边界形状 |
| **Denker et al.综述** | arXiv 2025.8 | 系统对比 full-learned / post-process / learned-iterative | **后处理和混合方法在 OOD 数据上优于端到端** |

**核心洞见:** 端到端黑盒在训练分布内表现最好，但一旦数据分布有偏移就崩溃。传统方法提供鲁棒的初始估计，网络只做精修，泛化性更好。

#### 路线 B: 迭代展开 (Deep Unfolding)

| 论文 | 时间 | 做法 |
|------|:----:|------|
| **PRGN+GNN** (Alberti et al.) | arXiv 2025.7 | Proximal Regularized Gauss-Newton 展开成 5 层网络，每层用 GNN 做近端算子 |
| **AA-HQSNet** (2024) | 2023/2024 | Half-Quadratic Splitting + Anderson 加速 |
| **MMV-Net** (Chen et al.) | IEEE TNNLS 2023 | ADMM 展开 + 自注意力 |

**核心创新:** 不是让网络直接学 208→N 的映射，而是把**优化算法的每一步迭代写成一个网络层**。每一层都有物理含义（GN 步 = 物理，GNN 步 = 学习先验），收敛更快且可解释。

```
第 k 层: σ_k = σ_{k-1} + GN_update(σ_{k-1}, V, J)  ← 物理
          σ_k = GNN(σ_k)                              ← 学习正则
```

#### 路线 C: 神经校正算子 (Neural Correction Operator)

| 论文 | 时间 | 做法 |
|------|:----:|------|
| **Neural Correction Op** (Bhat et al.) | arXiv 2025.7 | L-BFGS 粗重建 → CNN/Diffusion 修正残差 |
| **你的 ResidualEIT** | 2026.6 | GREIT 粗重建 → GNN 修正残差 |

**核心公式:**
```
σ = R(V) + C(R(V))
```
其中 R 是传统重建算子（L-BFGS / GREIT），C 是神经网络学习的修正算子。Bhat 证明这种分解优于直接学逆映射，因为 R 已经提供了对病态问题的正则化。

**和你的 ResidualEIT 的同构:**
- Bhat: L-BFGS 粗重建 → 修正器
- 你: GREIT 粗重建 → GNN 修正器
- **差距:** Bhat 的 L-BFGS 粗重建质量远好于你的 GREIT（RE 约 0.35 vs 0.52），修正目标更简单

#### 路线 D: 扩散模型 (Diffusion Models)

| 论文 | 时间 | 做法 |
|------|:----:|------|
| **Diffusion Graph PS** (Alberti et al.) | arXiv 2026.5 | 在三角 mesh 上训练无条件 score-based 扩散模型学 σ 先验分布，推理时在测量约束下采样 |
| **RDPS 变体** (同上) | 2026.5 | 扩散先验 + TV + Tikhonov 正则化 → 更稳定的采样 |
| **Score-EIT** | IEEE TMI 2025 | 得分匹配，无需配对数据 |
| **Conditional Diffusion** (Chen et al.) | arXiv 2026.2 | 条件扩散完成部分 DtN 测量，1% 测量即可重建 |

**核心创新:**
1. **扩散模型不是直接映射 V→σ，而是学习 σ 的先验分布 p(σ)**
2. 推理时：从噪声开始逐步去噪，每步用测量一致性损失引导，确保 V ≈ F(σ)
3. 不需要配对数据，只需要 σ 样本（无监督）或 V-σ 对（弱监督）
4. 天然支持多次采样 → 不确定性估计

**效果:** 当前 EIT 的 SOTA，优于所有确定性方法。对 OOD 形状泛化好，噪声鲁棒性极强。

**代价:** 推理需要 100-1000 步采样，每步都要跑完整前向传播，单张重建可能需要几秒到几十秒。

## 4. 详细改进方案

### 方案 1: 升级神经校正算子（路线C，最低风险）

**当前 ResidualEIT 的问题:**
- 粗重建用 GREIT，σ range [0.08, 0.5]，RE=0.52 —— 太差了
- GNN 只接收 39 维节点特征（sigma_0 + J^T r + PE），信息量不足
- 修正后的 σ 被 clamp 到 [0.05, 0.60]，范围不合理

**改进:**

```
改进前:
  GREIT → sigma_0 (RE=0.52) → 4层GNN → delta → sigma (RE=0.30)

改进后:
  L-BFGS/GN(5轮) → sigma_0 (RE≈0.35) → 6层GNN(512d) + 电压编码 → delta → sigma
                 + 直接用原始电压 V 与 J@Δσ 的残差作为额外输入
                 + 学习 delta 而非 sigma_0 + delta
```

**具体步骤:**
1. 把 `TraditionalReconstructor` 从 GREIT 换成 5 轮 L-BFGS 或 Proximal GN
2. 增大 `ResidualMeshGNN` 的输入维度：sigma_0 + J^T r + ||r|| + PE → 从 39 维增到 ~100 维
3. 增大 hidden_dim: 256 → 512
4. 修正器模型的输出不再加 clamp 到奇怪的范围，而是让 sigma_0 和 delta 在物理范围内
5. 训练数据增大到 20000 样本

**代码位置:** `models/residual_eit.py`, `training/residual_trainer.py`

**预期:** RE 从 0.30 → 0.15-0.22

### 方案 2: 迭代展开网络（路线B，中等风险，最具创新性）

**核心思想:** 把 Proximal Regularized Gauss-Newton 的 K 轮迭代展开成一个 K 层网络。

```
每层 = {
    1. GN step:  σ'  = σ_k + α_k * (J^T J + λI)^{-1} J^T (V - F(σ_k))
    2. GNN denoising:  σ_{k+1} = GNN_θ(σ')
}

整个网络 = K 层循环展开，端到端训练
```

**架构:**

```
Input: V (B, 208), J (208, n_elems), mesh (n_elems, 3)
       σ_0 = uniform background (0.01)
         │
  ┌──────▼──────────────────────────────────┐
  │  Layer 1:                                │
  │   1a. Jacobian linearization              │
  │       r₁ = V - J·(σ₀ - σ_ref)           │
  │       dσ₁ = solve(J^T J + λ₁I, J^T r₁)  │  ← CG solver, differentiable
  │       σ₁' = σ₀ + α₁ · dσ₁               │
  │                                          │
  │   1b. GNN refinement                     │
  │       σ₁ = GNN₁(σ₁', V_encoded, PE, J)   │  ← 学习的去噪/锐化
  ├──────────────────────────────────────────┤
  │  Layer 2-5: 同上, α_k, λ_k 可学习         │
  └──────┬──────────────────────────────────┘
         │
    Output: σ₅ (B, n_elems)
```

**关键组件:**

1. **可微 CG 求解器:** `(J^T J + λI)^{-1}` 不用显式求逆，用共轭梯度法迭代求解，整个迭代过程可微
2. **GNN 作为近端算子:** 每层的 GNN 学习去除 GN 步产生的伪影（类似 MRI 重建中的 CNN denoiser）
3. **J 嵌入:** 不是简单的 J^T r 投影，而是把 J 矩阵作为注意力权重或门控信号
4. **K=3~5 层:** 太多层过拟合，太少层物理不够

**训练:** 端到端，loss = MSE(σ_K, σ_gt) + Σ TV(σ_k)，初期可先训 GNN 部分再 joint fine-tune

**优势:**
- 每步都有物理保证，不像纯网络瞎学
- 网络只需要学"去伪影"而非"从零重建"
- 比扩散模型快得多（推理只需 3-5 次前向）
- 论文新颖性极高（Alberti 2025 是唯一做到这点的，但用的是 GNN 做去噪，你的可以加更多创新）

**劣势:**
- CG 求解器的可微实现需要小心处理
- 需要预计算 J 并且 J 要精确（你的 J 条件数 10^13 需要更好的正则化）

**预期:** RE ≈ 0.10-0.18

### 方案 3: 扩散模型（路线D，高风险/高回报/高创新性）

**为什么扩散模型适合 EIT:**

EIT 的逆问题本质上是一个**条件生成**问题：给定边界电压 V，生成内部电导率 σ。扩散模型天然适合这种"条件+生成"的模式。

**核心原理:**

```
扩散模型学的是 p(σ|V) 而非学一个确定性的 f(V)=σ

训练:  在 σ 空间加噪声，训练网络预测去噪方向
        同时学习条件 V 如何引导去噪

推理:  从随机噪声 σ_T ~ N(0,I) 开始
       循环 T=100~500 步:
         σ_{t-1} = denoise(σ_t, t, V) + guidance(V, σ_t)
       输出 σ_0
```

**针对 EIT 的具体架构:**

```
┌─────────────────────────────────────────┐
│  U-Net on mesh (GNN-based U-Net)        │
│                                         │
│  Input:  σ_t (n_elems,)  ← 当前噪声版本  │
│         t (1,)            ← 时间步       │
│         V_encoded (256,)  ← 电压条件     │
│         PE (35,)          ← 位置编码     │
│                                         │
│  Encoder: GNN ↓ ×3 (pooling)            │
│  Bottleneck: 自注意力 (全局交互)          │
│  Decoder: GNN ↑ ×3 (unpooling)          │
│  Skip connections                        │
│                                         │
│  Output: ϵ_θ(σ_t, t, V) ← 预测的噪声    │
└─────────────────────────────────────────┘

采样时的引导:
  σ_{t-1} = denoise(σ_t, t, V)
          + η · ∇_σ ||V - F(σ_t)||²     ← 物理一致性引导
          + γ · TV(σ_t)                  ← 正则化
```

**实现路线（渐进式）:**

**Phase 1: 基础扩散 (最小可行)**

- 在 4424 个 mesh 元素上训练无条件扩散模型
- 网络: GNN-based U-Net（用你的 SimpleGNN 层 + mesh 池化）
- 训练数据: 只需要 σ 样本（不需要配对 V），用你已有的 mixed_dataset 即可
- 预计 2-3 天实现

**Phase 2: 条件扩散 + 物理引导**

- 加入电压编码器，以 V 为条件引导去噪
- 加入测量一致性梯度项引导采样
- 加入 TV + Tikhonov 正则化（参考 RDPS）
- 预计 3-5 天实现

**Phase 3: 优化加速**

- 蒸馏为少步模型（1000 步 → 20 步）
- 或使用 consistency model 加速
- 预计 3-5 天实现

**关键工程挑战:**

1. **GNN U-Net 的池化/上采样:** 需要在三角网格上实现类似 MaxPool 的操作。可以用 Graclus 聚类或基于半径的点云下采样
2. **时间步编码:** 和标准扩散一样，用 sinusoidal encoding
3. **内存:** 扩散需要在训练时对每个样本加噪 → 去噪，batch 不能太大
4. **推理速度:** 100 步采样 × 模型前向 ≈ 几秒/样本。可以用 DDIM 跳到 20 步

**与 Alberti 2026 的区别:**

Alberti 用的是 score-based SDE 框架 + 图上的 score network。你的方案可以更工程化（DDPM/DDIM），更侧重实用场景。

**预期:** RE ≈ 0.08-0.15（接近 SOTA），但工程投入最大。

### 方案 4: 纯 GNN on Mesh（路线A+B的变体，最简单）

**动机:** ConvSpatial 的 GridSampler 双线性插值是信息瓶颈。去掉 CNN 和 GridSampler，直接在 FEM mesh 上做 GNN。

**架构:**

```
V (B, 208)
  │
  ▼
VoltageEncoder: MLP → z_v (B, 512)
  │
  ▼ 广播到每个 mesh 节点
[z_v, σ_initial, PE_jacobian]  (B, n_elems, ~600)
  │
  ▼
ResNet-like GNN × 8 层 (SimpleGNN, 512d)
  + skip connections
  │
  ▼
MLP head → σ (B, n_elems)  → sigmoid/clamp
```

**关键不同于 ConvSpatial:**
- 电压编码后直接和每个 mesh 节点的特征拼接，不经 GridSampler
- Jacobian 信息直接作为节点特征（J^T @ V 给每个节点一个标量特征）
- 更深的 GNN（8 层替代 4 层）+ 残差连接防退化

**优势:**
- 极简架构，无 CNN 依赖
- 信息直接从 208 维电压广播到 4424 个节点，不经插值丢失
- 训练快，参数量可控

**预期:** RE ≈ 0.15-0.22

## 5. 推荐实施路线

```
难度递增 →

方案4: 纯GNN on Mesh ───── 1-2天 ──→ 预期 RE 0.15-0.22
    │
方案1: 升级神经校正算子 ── 1-2天 ──→ 预期 RE 0.15-0.22
    │
方案2: 迭代展开网络 ───── 3-5天 ──→ 预期 RE 0.10-0.18
    │
方案3: 扩散模型 ────────── 7-14天 ─→ 预期 RE 0.08-0.15
```

**建议顺序:** 先做方案4（确认去掉 CNN 能提升多少），再做方案2（迭代展开，论文核心贡献），最后视需要做方案3（扩散模型，锦上添花）。方案1 和 4 可以并行——都只需要改模型代码，复用现有数据。

## 6. 附录: 已实现但放弃的改进

| 改进 | 为什么失败 |
|------|-----------|
| linear 输出替代 sigmoid | 初始化时 clamp 截断梯度，训练发散到 RE=1.4 |
| inclusion_weighted_mse (20x) | 配合 linear 输出时 loss 爆炸，单独用可能有效 |
| contrast_loss + gradient_loss | 需要先有收敛的 base model 再慢慢加 |
| FrequencyCrossAttention | pyEIT 1.2.4 返回 6 个完全相同的频率，纯浪费 |
| GATv2 替代 SimpleGNN | 注意力机制在 EIT 上没帮助，内存占用大 3 倍 |
| Jacobian 校正分支 | J^T J 条件数 10^13，校正信号 = 纯噪声 |
