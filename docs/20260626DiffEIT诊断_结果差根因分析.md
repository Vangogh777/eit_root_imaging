# DiffEIT v3 训练结果诊断：为什么扩散模型表现极差

> 2026-06-26 | 诊断对象: `20260625_224311_diff_eit_v3_conditional_ws_cosine_hd384/best.pt`
> Epoch 87, val_loss=0.002712

---

|------|:---:|:---:|:---:|

**核心问题**: 模型输出几乎全是背景值 (0.0098-0.0101)，根系结构 (应 ~0.05 S/m) 完全未重建出来。

---

## 2. 诊断实验

### 2.1 模型在 t=0（无噪声输入）时表现完美

```
输入 = 干净 GT σ, ᾱ=1.0:
  pred range [0.0098, 0.0645] vs GT [0.0100, 0.0625]
  RE = 0.0198  ← 完美!
```

**结论**: GNN 架构 + 条件注入本身没问题。`MeshUNet + FiLM + sensitivity features` 在输入干净时几乎完美重建。

### 2.2 模型在 t>0（有噪声）时完全崩溃

```
输入 = 加噪 σ, ᾱ=0.304 (t=400):
  pred range [0.0099, 0.0657], mean=0.0117
  GT range [0.0100, 0.0625], mean=0.0119
```

虽然均值匹配，但**方差几乎为零**——模型预测退化为几乎常数的背景值。从 t=10 到 t=499，输出范围始终 ≈ [0.0098, 0.065]，几乎不随噪声水平变化。

### 2.3 Warm-start 本身极差

```
Linear warm-start RE = 2.75, CC = -0.07
Range: [-0.14, 0.16] — 经常预测负电导率
```

线性最小二乘 (J_pinv) 对 EIT 非线性问题的初始估计完全不可用。残差 = σ_0 - σ_warm 包含了大量与根系信号无关的修正项，失去了"warm-start"的意义。

### 2.4 模型确实改善 warm-start（67%），但从极差基线起步

```
Warm-start RE: 2.75  →  DiffEIT RE: 0.63  (改善 67.7%)
Better than warm-start: 100/100 样本
```

这说明扩散部分**确实在工作**，但因为起点太差且去噪能力被噪声淹没，最终结果仍然很差。

---

## 3. 根因分析

### 🔴 根因 #1（致命）：数据未归一化导致 SNR 几乎为零

**这是最核心的 bug。**

标准 DDPM 假设数据归一化到单位方差（[-1, 1] 或 N(0,1)）。前向过程：
```
x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε,   ε ~ N(0, I)
```
这要求 x_0 和 ε 具有**可比的方差**，否则 SNR 崩溃。

**当前代码**直接对物理空间 σ ∈ [0.005, 0.1] S/m 做扩散：

| t | ᾱ_t | signal_std·√ᾱ | noise_std·0.5·√(1-ᾱ) | SNR |
|---|------|----------------|----------------------|-----|
| 499 | 0.0000 | 0.000000 | 0.5000 | **6.5×10⁻³⁷** |
| 375 | 0.1421 | 0.002489 | 0.4631 | 2.9×10⁻⁵ |
| 250 | 0.4907 | 0.004625 | 0.3568 | 1.7×10⁻⁴ |
| 125 | 0.8448 | 0.006068 | 0.1970 | 9.5×10⁻⁴ |
| 62 | 0.9572 | 0.006459 | 0.1035 | 3.9×10⁻³ |
| 0 | 0.9999 | 0.006602 | 0.0047 | 1.99 |

σ_true 的 std = 0.0066（方差 4.4×10⁻⁵），而噪声 std = 0.5（方差 0.25）。信噪比差了 **5 个数量级**。

**后果**:
- 对于 95% 的扩散步 (t > 10)，SNR < 0.01 — 信号完全淹没在噪声中
- 模型学到的"最优策略"就是预测数据均值（背景值），因为这就是 MSE 损失下能从噪声中提取的全部信息
- 只有 t=0-10（最后 2% 的步数）模型才能看到有意义的结构

### 🔴 根因 #2：DDIM 采样公式与训练噪声尺度不匹配

训练使用 `forward_diffuse_residual(noise_scale=0.5)`：
```
σ_t = σ_warm + √ᾱ_t · residual + 0.5 · √(1-ᾱ_t) · ε
```

但 DDIM 采样假设标准 DDPM 前向过程：
```
σ_{t-1} = √ᾱ_{t-1} · σ̂₀ + √(1-ᾱ_{t-1}) · ε̂
其中 ε̂ = (σ_t - √ᾱ_t · σ̂₀) / √(1-ᾱ_t)
```

**尺度失配体现在两个层面**：

1. **噪声方差**: 训练中有效噪声方差 = 0.25·(1-ᾱ_t)，DDIM 假设噪声方差 = (1-ᾱ_t)。差了 4 倍。

2. **σ̂₀ 尺度**: DDIM 更新中，`√ᾱ_{t-1}·σ̂₀` 项（信号项）和 `√(1-ᾱ_{t-1})·ε̂` 项（噪声项）应当可比。但当 σ̂₀≈0.01 且 ᾱ 非零时：
   - `√ᾱ_{t-1}·σ̂₀ ≈ 0.01`（信号项）
   - `√(1-ᾱ_{t-1})·ε̂ ≈ 1.0`（噪声项，当 ᾱ 较小时）
   - **信号项被噪声项完全淹没** → 采样轨迹没有足够"动力"离开初始猜测 → 收敛到均值

3. **Warm-start 打破 DDPM 假设**: 训练前向 `σ_t = σ_warm + ...` 不满足标准 `x_t = √ᾱ_t·x_0 + ...` 形式，σ_warm 项**不随 ᾱ_t 衰减**。DDIM 反向过程无法正确处理这个常数偏移。

### 🟡 根因 #3：训练损失地板效应掩盖了模型坍缩

```
val_loss = 0.0027 (MSE in [0,1] normalized space)
```

这看起来"很低"。但计算模型如果总是预测常数背景值的 MSE：
- σ 归一化后: 背景 ≈ 0.0526, 根系 ≈ 0.4737
- 根元素占比 ≈ 3.6%
- 常数预测 = 0.0526 的 MSE = 0.964×0 + 0.036×(0.4211)² = **0.0064**

实际 val_loss=0.0027 比常数预测好 2.4 倍，说明模型**确实学到了一些弱结构**。但这点结构远不足以重建实际根系模式。

**训练损失无法反映重建质量**——这是扩散模型未经归一化训练的通病：低 MSE 不等于好重建，因为数据方差本身就极小。

### 🟡 根因 #4：Warm-start 不仅无用还帮倒忙

```
σ_warm RE = 2.75, σ_warm ∈ [-0.14, 0.16]
```

线性最小二乘的物理假设（小扰动线性近似）在 EIT 根系成像中完全不成立：
- 根系 σ (0.05) vs 背景 σ (0.01) → 对比度 5:1 → 非线性严重
- J_pinv 从均匀背景计算 → 无法处理强对比度内含物
- 结果：σ_warm 经常预测物理不可能的负值

残差扩散本意是"只扩散根系信号"，但实际上 residual = σ_0 - σ_warm 大部分能量来自 warm-start 的误差修正，而非根系本身。

## 4. 修复方案

### 优先级 P0：归一化数据（预计修复 80% 的问题）

```python
# 在 forward_diffuse 之前：
sigma_0_norm = (sigma_0 - sigma_min) / sigma_range  # [0, 1]
# 或进一步标准化到零均值单位方差：
# sigma_0_std = (sigma_0_norm - mean) / std

# 标准 DDPM 前向（在归一化空间）：
sigma_t_norm, noise = diffusion.forward_diffuse(sigma_0_norm, t)
# ... denoiser 在归一化空间工作 ...
sigma_0_pred_norm = denoiser(sigma_t_norm, t_emb, v_emb)

# 推理时 denormalize：
sigma_0_phys = sigma_0_pred_norm * sigma_range + sigma_min
```

**关键变化**：
1. **扩散在归一化空间进行**：σ_0_norm ∈ [0, 1]，方差 ~0.04
2. **噪声与信号可比**：不再出现 SNR=10⁻³⁷ 的情况
3. **DDIM 公式正确**：ᾱ 系数按设计工作
4. **无需 noise_scale hack**：标准 DDPM 即可

### 优先级 P1：修复/移除 Warm-start

**选项 A（推荐）**: 先完全去掉 warm-start，验证标准扩散工作后再加
**选项 B**: 用可训练的 LightGNN 替代线性 LLS（按设计文档 Tier 3 方案 B）
**选项 C**: 修复线性 warm-start 的数值计算（确保 σ_warm ∈ [σ_min, σ_max]）

### 优先级 P2：验证后启用 Tier 4-6 改进

- GATv2 替换 SimpleGNN（动态注意力）
- 物理梯度引导 (C4)
- 更多扩散步数或更好的调度

## 6. 关键教训

1. **扩散模型必须在归一化数据上运行** — 这是 DDPM/DDIM 数学推导的基本假设，不可省略
2. **低训练 loss 不等于好模型** — 当数据方差极小时，MSE 地板效应会掩盖模型坍缩
3. **Warm-start 只在质量够好时有意义** — 太差的初始猜测会让残差扩散退化为全量扩散
4. **noise_scale hack 破坏了 DDIM 一致性** — 任何偏离标准 DDPM 前向过程的修改都需要配套修改反向过程
