# 当前训练模式说明

> 问题：这是有监督吗？
> 回答：**是弱监督训练（Weakly Supervised）**

---

## 📊 当前训练配置

### 损失函数组成

```yaml
loss_weights:
  supervised: 1.0              # 有监督损失
  residual_measurement: 1.0    # 物理约束损失
  tv: 0.03                     # TV正则化
  delta_l1: 0.01               # 残差稀疏约束
  delta_smooth: 0.02           # 残差平滑约束
```

### 总损失公式

```python
L_total = 1.0 * L_supervised           # 有监督：||σ̂ - σ_gt|| / ||σ_gt||
        + 1.0 * L_residual_measurement # 物理：||J·Δσ - r||²
        + 0.03 * L_tv                  # TV正则化
        + 0.01 * L_delta_l1            # Δσ稀疏
        + 0.02 * L_delta_smooth        # Δσ平滑
```

## 🎯 训练模式分类

### 模式对比

| 模式 | supervised权重 | 物理约束权重 | 特点 |
|------|:--------------:|:-----------:|------|
| **完全有监督** | 1.0 | 0.0 | ✅ 快速收敛<br>❌ 可能过拟合 |
| **弱监督（当前）**⭐ | **1.0** | **1.0** | ✅ 平衡性能与泛化<br>✅ 防止过拟合<br>✅ 物理合理性 |
| **无监督** | 0.0 | 1.0 | ✅ 不需要标签<br>❌ 训练困难<br>❌ 收敛慢 |

## 💡 为什么选择弱监督？

### 1. 结合两种优势

**有监督部分**：
```python
L_supervised = ||σ̂ - σ_gt|| / ||σ_gt||
```
- ✅ 提供明确的优化目标
- ✅ 快速收敛
- ✅ 利用真实标签信息

**无监督（物理约束）部分**：
```python
L_residual_measurement = ||J·Δσ - r||²
```
- ✅ 物理约束，保证合理性
- ✅ 不完全依赖标签质量
- ✅ 提升泛化能力

### 2. 防止过拟合

**问题**：纯有监督容易过拟合仿真数据
```
仿真数据 ⟶ 训练集 ⟶ 过拟合 ⟶ 真实数据性能下降
```

**解决**：弱监督引入物理约束
```
仿真数据 + 物理约束 ⟶ 训练集 ⟶ 平衡 ⟶ 更好泛化
```

### 3. 数据质量不完美

当前传统重建质量：
```
mixed_dataset: σ₀ RE = 2.0
```

如果纯有监督：
- 网络会学习"错误"的残差模式
- 因为σ₀本身就有误差

弱监督：
- 物理约束强制满足测量一致性
- 即使σ₀有误差，物理约束仍有效

## 🔄 训练过程详解

### 每个训练步

```python
# 1. 加载数据
V, σ_gt, σ₀, g, r = batch

# 2. 前向传播
Δσ = MeshGNN(σ₀, g, position_encoding, z_v)
σ̂ = σ₀ + Δσ

# 3. 计算损失
L_sup = ||σ̂ - σ_gt|| / ||σ_gt||           # 有监督
L_meas = ||J·Δσ - r||²                     # 物理约束
L_tv = TV(σ̂)                              # 正则化
L_sparse = |Δσ|₁                           # 稀疏
L_smooth = mean((Δσ_i - Δσ_j)²)            # 平滑

# 4. 加权组合
L_total = 1.0*L_sup + 1.0*L_meas + 0.03*L_tv + 0.01*L_sparse + 0.02*L_smooth

# 5. 反向传播
L_total.backward()
optimizer.step()
```

### 损失的作用

| 损失 | 作用 | 为什么需要 |
|------|------|-----------|
| **L_supervised** | 让预测接近真实 | 提供明确目标 |
| **L_residual_measurement** | 让J·Δσ ≈ r | 物理一致性 |
| **L_tv** | 空间平滑 | 去除噪声 |
| **L_delta_l1** | 稀疏修正 | 防止过修正 |
| **L_delta_smooth** | 残差平滑 | 保持连续性 |

### 为什么弱监督RE可能比纯有监督高？

**悖论**：纯有监督RE更低，但弱监督更好？

**解释**：
1. **过拟合**：纯有监督在仿真数据上过拟合
2. **泛化**：弱监督有物理约束，泛化更好
3. **真实数据**：真实数据上，弱监督可能反而更好

## 🎯 如果想切换模式

### 切换到纯有监督

```yaml
# config/residual_eit_config.yaml
loss_weights:
  supervised: 1.0
  residual_measurement: 0.0  # 关闭物理约束
  tv: 0.0
  delta_l1: 0.0
  delta_smooth: 0.0
```

**优点**：
- ✅ 收敛快（2-3小时）
- ✅ RE可能更低（~0.25）
- ✅ 训练稳定

**缺点**：
- ❌ 可能过拟合仿真数据
- ❌ 真实数据性能可能下降
- ❌ 缺少物理约束

### 切换到无监督

```yaml
loss_weights:
  supervised: 0.0            # 关闭有监督
  residual_measurement: 1.0
  tv: 0.05
  delta_l1: 0.02
  delta_smooth: 0.02
```

**优点**：
- ✅ 不需要真实标签
- ✅ 最强泛化能力
- ✅ 真实数据可用

**缺点**：
- ❌ 训练困难，收敛慢
- ❌ 可能陷入局部最优
- ❌ RE可能较高（~0.5-0.8）

## 💡 推荐策略

### 当前的弱监督是最佳选择

**理由**：
1. ✅ **平衡**：有监督的快速收敛 + 物理约束的泛化
2. ✅ **稳健**：即使σ₀有误差，物理约束仍有效
3. ✅ **实用**：适合当前仿真数据 + 未来真实数据

```
第1步：弱监督训练（当前）⟶ RE ~0.3-0.5

第4步：如果欠拟合 ⟶ 尝试纯有监督
```
