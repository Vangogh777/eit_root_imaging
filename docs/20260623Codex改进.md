# Codex改进建议：传统成像 + 物理残差校正路线落地方案

> 日期：2026-06-23  
> 目标：将“先传统成像再残差校正”方案收敛为当前代码库可实现、可验证、可迭代的高精度 EIT 重建路线。  
> 结论：路线方向合理，但应先定位为“固定 EIT 系统下的高精度物理残差框架”，通过实验验证后再扩展为通用算法。

---

## 1. 总体判断

当前文档提出的路线B：

```text
V -> 传统重建 -> sigma_0
V, sigma_0 -> 物理残差 r
J^T r -> 网格物理特征 g
MeshGNN(sigma_0, g, position, voltage_global) -> delta_sigma
sigma_hat = sigma_0 + delta_sigma
```

是比当前端到端 `V -> sigma` 更稳健的方向。核心原因是：EIT 是严重不适定逆问题，直接从边界电压预测绝对电导率会把“物理反演”和“结构先验”都压给神经网络；而传统重建先给出物理可解释的粗解后，网络只负责修正残差，任务更小、更稳定、更容易解释。

但这条路线目前还不能直接称为“通用高精度 EIT 算法”。更准确的定位应该是：

```text
面向当前桶式 2D 16 电极 EIT 系统的高精度残差重建框架；
在固定几何、电极协议、噪声模型下先验证精度和稳定性；
之后再逐步引入多几何、多协议、多频材料模型，扩展通用性。
```

---

## 2. 当前代码基础与缺口

### 2.1 已有基础

当前代码已经具备路线B的部分组件：

1. `models/two_stage_model.py`
   - 已有 `TraditionalReconstructor`
   - 支持 BP/JAC 粗重建
   - 已有 `TwoStageEITModel`
   - 但目前是“粗解 -> UNet/Graph 精修”，没有把 `J^T r` 作为主物理特征

2. `models/conv_spatial_eit.py`
   - 已有 `ConvEncoder`
   - 已有 `GATv2Layer`
   - 已有 mesh 图构建逻辑
   - 已有 `J^T r` correction head
   - 但 `J^T r` 只是辅助校正，不是主干输入

3. `training/loss.py`
   - 已有 `MeasurementConsistencyLoss`
   - 已有 `TVRegularizationLoss`
   - 已有 `SigmaDeviationLoss`
   - 但现有测量一致性仍主要围绕固定参考电导率 `sigma_ref`，路线B需要围绕 `sigma_0 + delta_sigma` 的残差形式重写

4. `data/eit_forward.py`
   - 已有 pyEIT forward solver
   - 已有 Jacobian 获取接口
   - 但 `solve_multi_frequency()` 当前只是复制单频结果，多频数据目前没有真实物理差异

### 2.2 关键缺口

路线B要真正成立，必须补齐以下闭环：

1. 预计算或在线计算 `sigma_0`
2. 计算电压残差 `r`
3. 计算物理反投影特征 `g = J^T r`
4. 模型显式输入 `[sigma_0, g, position_encoding, voltage_global]`
5. 模型只预测 `delta_sigma`
6. 损失函数使用 `||J delta_sigma - r||`
7. 数据集能够加载 `sigma_0/g/r`
8. 训练脚本能够对比：
   - 传统重建
   - 当前端到端模型
   - 当前 two-stage 监督模型
   - 新 residual unsupervised/weak-supervised 模型

## 3. 核心架构修改方向

### 3.1 新增模型：`models/residual_eit.py`

新增主模型 `ResidualEIT`，不要直接改旧模型。旧模型保留用于对比实验。

建议接口：

```python
class ResidualEIT(nn.Module):
    def forward(self, voltages, sigma_0=None, g=None, residual=None):
        """
        voltages: (B, F, M)
        sigma_0: (B, E), optional, 传统重建粗解
        g:       (B, E), optional, J^T r 物理残差特征
        residual:(B, M), optional, 电压残差 r
        """
```

设计原则：

1. `sigma_0` 是主起点，不参与梯度。
2. `g = J^T r` 是主节点特征，不是 correction head 的附属输入。
3. 网络预测 `delta_sigma`，不直接预测绝对 `sigma`。
4. 输出：

```python
return {
    "sigma": sigma,
    "sigma_0": sigma_0,
    "delta_sigma": delta_sigma,
    "g": g,
    "residual": residual,
    "z_v": z_v,
}
```

### 3.2 残差组合方式

不建议使用：

```python
sigma = sigma_0 + softplus(delta_sigma) * sign(delta_sigma)
```

这个形式在 0 附近不够自然，且会引入不必要的非线性偏置。

建议使用有界残差：

```python
raw_delta = self.delta_head(h).squeeze(-1)
delta_sigma = self.delta_scale * torch.tanh(raw_delta)
sigma = torch.clamp(sigma_0 + delta_sigma, self.sigma_min, self.sigma_max)
```

其中：

```python
delta_scale = 0.02  # 初始建议，可配置
```

如果当前背景电导率是 `0.01`，根系目标约 `0.05`，则 `delta_scale` 可以从 `0.01-0.03` 之间做消融。

### 3.3 节点特征设计

MeshGNN 每个单元节点建议输入：

```text
node_feat = [
    sigma_0,
    g,
    |g|,
    normalized_radius,
    x,
    y,
    FourierPositionEncoding(x, y)
]
```

可选增强：

```text
node_feat += [
    sigma_0_gradient_or_tv_proxy,
    traditional_recon_confidence,
    jacobian_column_norm
]
```

第一版不要过复杂，建议先用：

```text
[sigma_0, g, x, y, radius, fourier_pe]
```

### 3.4 全局电压编码 `z_v`

复用 `ConvSpatialEIT` 中的 `FrequencyCrossAttention` 和 `ConvEncoder`，但不要再 `GridSampler` 到每个单元作为主空间特征。路线B中空间主特征应该来自 `sigma_0` 和 `J^T r`。

建议新增：

```python
class VoltageGlobalEncoder(nn.Module):
    def forward(self, voltages):
        x = voltages.view(B, F, 13, 16)
        x = freq_fusion(x)
        feat, _ = encoder(x)
        z_v = global_pool_and_project(feat)
        return z_v
```

`z_v` 作为全局条件广播到每个 mesh node：

```python
z_expand = z_v.unsqueeze(1).expand(B, E, -1)
h = torch.cat([node_feat, z_expand], dim=-1)
```

## 4. 传统重建模块修改方向

### 4.1 第一阶段先不要直接上 SBL/BSBL

文档中 SBL/BSBL 方向合理，但当前网格规模下直接实现全量 SBL 矩阵求逆风险很大。

当前 `mesh_config.yaml` 的 `mesh_resolution=0.0025` 对应约 1 万多个单元。朴素 SBL 需要处理：

```text
(n_elems, n_elems)
```

矩阵，内存和时间都容易不可接受。

建议分阶段：

1. Phase 1：使用现有 BP/JAC 生成 `sigma_0`
2. Phase 2：实现轻量 Tikhonov/GN 版本作为更稳定 baseline
3. Phase 3：实现可扩展 SBL
4. Phase 4：再考虑 BSBL

### 4.2 新增统一接口

建议新增目录：

```text
models/traditional/
    __init__.py
    reconstructor.py
    bp_reconstructor.py
    jac_reconstructor.py
    tikhonov_reconstructor.py
    sbl_reconstructor.py
```

统一接口：

```python
class BaseReconstructor:
    def reconstruct(self, voltage):
        """
        returns:
            sigma_0: (n_elems,)
            info: dict
        """

    def batch_reconstruct(self, voltages):
        ...
```

其中 `info` 建议包含：

```python
{
    "method": "bp",
    "residual_norm": float,
    "confidence": optional_array,
    "failed": bool,
}
```

### 4.3 `sigma_0` 质量控制

路线B依赖 `sigma_0`，所以必须监控粗解质量。建议每个样本记录：

```text
coarse_voltage_residual = ||V - F_linear(sigma_0)||
coarse_sigma_range
coarse_tv
coarse_nan_flag
```

如果传统重建失败：

```python
if failed or np.isnan(sigma_0).any():
    sigma_0 = sigma_ref
    confidence = zeros
```

不要让坏粗解静默进入训练。

## 5. 物理残差计算修改方向

### 5.1 新增 `training/residual_physics.py` 或 `models/residual_physics.py`

建议新增：

```python
class ResidualComputer(nn.Module):
    def forward(self, V_meas, sigma_0):
        delta0 = sigma_0 - sigma_ref
        V0 = J @ delta0
        r = V_meas - V0
        g = J.T @ r
        return g, r
```

注意当前 `EITForwardSolver.solve()` 返回的是差分电压：

```python
v_diff = v - V_uniform
```

因此如果 `V_meas` 是差分电压，线性近似应保持一致：

```python
V0_linear = J @ (sigma_0 - sigma_ref)
r = V_diff_measured - V0_linear
```

不要混用绝对电压和差分电压。

### 5.2 对 `g` 做归一化

`J^T r` 数值尺度可能不稳定，必须归一化。建议第一版使用 per-sample 标准化：

```python
g = (g - g.mean(dim=-1, keepdim=True)) / (g.std(dim=-1, keepdim=True) + 1e-6)
```

可选再加：

```python
g_abs = torch.abs(g)
```

让网络同时看到方向和强度。

## 6. 损失函数修改方向

### 6.1 新增 `training/residual_loss.py`

不要直接替换 `training/loss.py`，避免影响现有路线A。

建议新增：

```python
class ResidualMeasurementConsistencyLoss(nn.Module):
    def forward(self, delta_sigma, residual):
        V_delta = J @ delta_sigma
        return mse(normalize(V_delta), normalize(residual))
```

核心物理形式：

```text
L_meas = ||J delta_sigma - r||^2
```

其中：

```text
r = V_measured - J(sigma_0 - sigma_ref)
```

### 6.2 替换 `SigmaDeviationLoss`

路线B不建议继续使用：

```text
||sigma - sigma_ref||^2
```

改为：

```text
L_res = ||delta_sigma||_1
```

原因：网络应该做最小必要修正，而不是被强行拉回背景电导率。

实现：

```python
class ResidualSparsityLoss(nn.Module):
    def forward(self, delta_sigma):
        return delta_sigma.abs().mean()
```

### 6.3 保留 TV，但作用于最终 sigma

```text
L_tv = TV(sigma_hat)
```

不要只对 `delta_sigma` 做 TV。最终图像的空间合理性更重要。

### 6.4 增加残差平滑

```text
L_delta_smooth = mean((delta_i - delta_j)^2), for mesh neighbors i,j
```

作用：避免网络在单个单元产生尖锐伪修正。

### 6.5 推荐第一版总损失

弱监督阶段：

```text
L = lambda_sup * L_sup
  + lambda_meas * L_residual_meas
  + lambda_tv * L_tv
  + lambda_sparse * L_delta_l1
  + lambda_smooth * L_delta_smooth
```

无监督阶段：

```text
L = lambda_meas * L_residual_meas
  + lambda_tv * L_tv
  + lambda_sparse * L_delta_l1
  + lambda_smooth * L_delta_smooth
```

建议初始权重：

```yaml
loss_weights:
  supervised: 1.0
  residual_measurement: 1.0
  tv: 0.03
  delta_l1: 0.01
  delta_smooth: 0.02
```

训练无监督时：

```yaml
loss_weights:
  residual_measurement: 1.0
  tv: 0.05
  delta_l1: 0.02
  delta_smooth: 0.02
```

## 8. 训练流程修改方向

### 8.1 新增训练脚本

建议新增：

```text
train_residual_eit.py
```

不要直接改 `train.py` 或 `train_conv_spatial.py`。

### 8.2 第一阶段：监督验证上限

目的：证明“传统重建 + 残差网络”架构本身能提升重建质量。

训练：

```text
input: voltages, sigma_0, g, r
target: sigma_gt
loss: supervised + residual physics losses
```

对比：

```text
RE(sigma_0, sigma_gt)
RE(sigma_hat, sigma_gt)
```

如果监督都不能明显超过 `sigma_0`，说明架构或特征有问题，不要进入无监督阶段。

### 8.3 第二阶段：弱监督

减少监督权重：

```text
lambda_sup: 1.0 -> 0.1 -> 0.01
```

观察：

```text
RE 是否稳定
delta_sigma 是否过大
measurement residual 是否下降
```

### 8.4 第三阶段：无监督

完全去掉 `sigma_gt` loss，只保留：

```text
L_residual_meas + L_tv + L_delta_l1 + L_delta_smooth
```

验证仍使用 `sigma_gt` 计算 RE/CC/SSIM，但不参与训练。

## 9. 多频修改方向

### 9.1 当前多频不能支撑复杂注意力

当前 `solve_multi_frequency()` 返回同一份电压的 tile，因此多频 attention 暂时没有真实物理意义。

第一版路线B建议：

```text
只用第 1 个频率作为物理主通道
其余频率暂时不作为核心证据
```

### 9.2 真实多频应后置

等单频路线B验证成功后，再新增：

```text
data/multi_freq_solver.py
```

实现 Cole-Cole 或经验频散模型。

但注意：Cole-Cole 参数不能随便拍脑袋，否则会生成漂亮但错误的多频规律。建议至少做三档：

1. no-dispersion baseline
2. weak-dispersion synthetic
3. strong-dispersion synthetic

再看模型是否真的利用多频。

### 9.3 多频路线B节点特征

真实多频后，节点特征可以扩展为：

```text
[sigma_0_mean, g_1, g_2, ..., g_F, pe]
```

或者：

```text
sigma_0 = weighted_sum(sigma_0_f)
g = weighted_sum(g_f)
```

第一版多频不要太复杂，建议先使用：

```text
sigma_0_mean + concat(g_f)
```

## 10. SBL/BSBL 修改方向

### 10.1 SBL 应作为第二阶段优化，不是第一阶段前置依赖

朴素 SBL 对当前 mesh 规模压力大，不建议作为路线B最小可行版本的阻塞项。

### 10.2 可扩展 SBL 方向

如果后续实现 SBL，应避免直接求逆 `E x E` 矩阵。建议考虑：

1. Woodbury 形式，转到测量维度 `M x M`
2. active set，只保留高响应单元
3. coarse-to-fine，先在粗网格 SBL，再插值到细网格
4. block sparse 时使用局部块，而不是全局 dense block covariance

当前 16 电极相邻模式测量数约 208，`M << E`，因此优先使用测量空间低秩形式。

## 11. 验证指标与消融实验

### 11.1 必须比较的模型

至少比较：

1. 传统重建 `sigma_0`
2. 当前 `SFSBLC`
3. 当前 `ConvSpatialEIT`
4. 当前 `TwoStageEITModel` 监督精修
5. 新 `ResidualEIT` 监督版
6. 新 `ResidualEIT` 无监督版

### 11.2 必须报告的指标

```text
RE
CC
SSIM
measurement residual
delta_sigma L1
inference time
failure rate
```

仅报告 RE 不够，因为 EIT 中可能出现数值接近但结构错误。

### 11.3 必须做的消融

```text
sigma_0 only
sigma_0 + g
sigma_0 + pe
sigma_0 + g + pe
sigma_0 + g + pe + z_v
```

如果 `g` 没有明显提升，说明残差物理特征计算或尺度处理有问题。

### 11.4 分布外验证

要证明“更通用”，至少做：

```text
train: taproot
test: fibrous/herringbone

train: low noise
test: high noise

train: one contrast range
test: different contrast range

train: centered inclusions
test: boundary-near inclusions
```

没有这些实验，不建议使用“通用算法”的表述。

## 13. 推荐实施顺序

### Phase 0：确认数据与 Jacobian

1. 检查 `data/generated/eit_dataset.h5` 是否与当前 mesh 单元数一致
2. 检查 `data/generated/jacobian.npy` shape 是否为 `(n_meas, n_elems)` 或 `(n_freq, n_meas, n_elems)`
3. 确认电压是差分电压，不要和绝对电压混用

### Phase 1：最小路线B

1. 用 BP 生成 `sigma_0`
2. 用固定 Jacobian 生成 `g` 和 `r`
3. 写入 HDF5
4. 实现 `ResidualEIT`
5. 监督训练验证是否超过 `sigma_0`

### Phase 2：无监督路线B

1. 实现 `ResidualMeasurementConsistencyLoss`
2. 去掉 `SigmaDeviationLoss`
3. 加入 `delta_l1` 和 `delta_smooth`
4. 跑无监督训练
5. 与当前 `UnsupervisedTrainer` 对比

### Phase 3：传统重建增强

1. 增加 Tikhonov/GN baseline
2. 增加 SBL 的低秩版本
3. 对比 BP/JAC/Tikhonov/SBL 的 `sigma_0` 质量和最终 `sigma_hat` 质量

### Phase 4：真实多频

1. 实现材料频散模型
2. 生成真实多频数据
3. 扩展多频 `g_f`
4. 验证多频是否真的提升

## 14. 风险与处理

### 风险1：`sigma_0` 太差，网络被错误粗解拖累

处理：

```text
加入 coarse residual norm
加入 confidence feature
传统重建失败时回退 sigma_ref
训练时随机 drop sigma_0，让网络不要过度依赖粗解
```

### 风险2：`J^T r` 尺度不稳定

处理：

```text
per-sample 标准化
clip 极端值
加入 |g| 但保留 g 的符号
记录 g mean/std 到日志
```

### 风险3：无监督 loss 下降但 RE 不提升

处理：

```text
检查电压差分/绝对值是否混用
检查 Jacobian 与 mesh 是否匹配
检查 residual r 的定义
增加 FEM 验证指标
先退回弱监督
```

### 风险4：GNN 过平滑

处理：

```text
减少 GNN 层数
增加 residual connection
delta 使用 tanh 有界输出
TV 权重不要过大
引入 edge-aware weighting
```

### 风险5：高精度依赖仿真分布，真实数据退化

处理：

```text
加入接触阻抗扰动
加入电极位置扰动
加入幅值漂移
加入噪声分布变化
使用真实空桶/均匀介质校准数据
```

## 15. 最终建议

建议将当前方案改写为三句话：

```text
1. 路线B是当前项目最值得推进的下一代主线。
2. 第一目标不是直接宣称通用算法，而是在当前桶式 2D EIT 系统上形成可验证的高精度残差重建框架。
3. 通用性应通过多几何、多协议、多噪声、多材料频散的系统实验逐步证明。
```

第一版实现不要追求完整大而全。最小闭环应该是：

```text
BP/JAC sigma_0
+ J^T r 物理残差特征
+ MeshGNN 预测有界 delta_sigma
+ ResidualMeasurementConsistencyLoss
+ 与现有路线A严格对比
```

只要这个闭环能稳定超过传统重建和当前端到端无监督模型，路线B就成立；之后再投入 SBL、真实多频和更强先验才是值得的。
