# DiffEIT v4 诊断与修复方案

> 2026-06-27 | 基于完整代码审查 + 实际推理结果 | 当前 RE=2.2~4.7, 比全预测背景差3-6x

---

## 执行摘要

v4 修复了 v3 的 SNR 崩溃问题（归一化扩散 ✅），但引入了**两个新的致命问题**替代了旧问题：

| 问题 | 严重度 | 症状 |
|------|:---:|------|
| **#1 加权MSE 分布失配** | 🔴 致命 | 模型输出 ~0.05-0.07 S/m 处处是"根", RE 比全预测背景差 3-6x |
| **#2 标准化分布严重非高斯** | 🔴 致命 | 背景=-0.22σ, 根=+2.8σ, 极端长尾导致扩散模型无法有效去噪 |
| **#3 物理一致性权重过低** | 🟡 重要 | λ=0.05, 实际 phys_loss 贡献 < 总 loss 的 0.5% |
| **#4 DDIM 20步 insufficient** | 🟡 重要 | 大T余弦调度下 20 步 DDIM 跳过了关键的高 SNR 区域 |
| **#5 输出头无约束** | 🟡 重要 | Linear 输出无界, 但后续 clamp 粗暴截断, 信息丢失 |

## 1. 问题 #1（致命）：加权 MSE 分布失配 —— 优化方向错误

### 现象

```
实际模型输出: pred_mean = 0.045 ~ 0.067 S/m  (全"根"级别)
真实数据:     gt_mean   = 0.011 ~ 0.017 S/m  (96% 背景 0.01)
RE = 2.2 ~ 4.7   →   比"全预测背景"(RE=0.5~0.8) 差 3-6 倍
```

### 根因

`weighted_mse_loss` 在**标准化空间** (N(0,1)) 计算异常权重, 但背景阈值用的是**归一化空间** ([0,1]):

```python
# train_diff_eit.py:37-45
bg_norm_threshold = 0.08  # [0,1] 空间
sigma_norm = ((sigma_0_phys - sigma_min) / sigma_range).clamp(0, 1)
anomaly_mask = (sigma_norm > bg_norm_threshold)  # 物理 > 0.017 S/m → 权重 15x
weights = 1.0 + (lambda_anomaly - 1.0) * anomaly_mask  # 背景1x, 异常15x
return (weights * (pred - target)**2).mean()  # ← 在标准化空间算 MSE!
```

**关键矛盾**: 权重计算基于物理空间（谁该被关注）, 但 loss 在标准化空间计算。标准化空间中:

| 位置 | 物理 σ | 归一化 | 标准化 (target) | 权重 |
|------|--------|--------|-----------------|:---:|
| 背景 | 0.010 | 0.0 | **-0.22** | 1x |
| 弱根 | 0.025 | 0.17 | **+0.93** | 15x |
| 强根 | 0.050 | 0.45 | **+2.84** | 15x |
| 极强根 | 0.063 | 0.60 | **+3.84** | 15x |

问题在于：
- Target 范围从 -0.22 到 +6.6（不是对称的 N(0,1)!）
- 异常区域 target 均值 ≈ +2.5, 背景 target 均值 ≈ -0.22
- 模型输出头是 Linear（无约束）—— 可以输出任意值
- 加权 MSE(15x) 推动模型向 +2.5 靠近 → 物理空间输出 ~0.05 S/m

**为什么 val_loss=0.145 看起来"低"但 RE 极差**：

当模型预测常数 +2.0σ 时：
- 背景误差 (权重 1x): (2.0 - (-0.22))² = 4.93, 贡献 4.93 * 0.964 = 4.75
- 根误差 (权重 15x): (2.0 - 2.84)² = 0.71, 贡献 0.71 * 0.036 * 15 = 0.38
- 加权 MSE ≈ 5.13

当模型预测 +2.5σ 时：
- 背景误差 (权重 1x): (2.5 - (-0.22))² = 7.40, 贡献 7.13
- 根误差 (权重 15x): (2.5 - 2.84)² = 0.12, 贡献 0.06
- 加权 MSE ≈ 7.19

当模型预测 -0.22σ (背景) 时：
- 背景误差 (权重 1x): 0, 贡献 0
- 根误差 (权重 15x): (-0.22 - 2.84)² = 9.36, 贡献 9.36 * 0.036 * 15 = 5.05
- 加权 MSE ≈ 5.05

**所以最优策略：预测 +2.0σ 附近（加权 MSE ≈ 5.13）vs 预测背景（加权 MSE ≈ 5.05）。两者几乎等价！**

但等等——val_loss=0.145 远低于 5.0。这是因为 val_loss 是对所有 t 均匀采样的。在低 t 时（t<50, ᾱ≈1），σ_t ≈ σ_0_std, 去噪几乎是恒等映射——MSE 极低。高 t 时（t≈200, ᾱ≈0），σ_t ≈ 纯噪声, 模型无法重建——MSE 极高。

**结论**: val_loss=0.145 是"低 t 拉低均值"的数学假象。单步去噪的 MSE 与 20 步 DDIM 生成质量之间没有直接对应关系。

### 修复方案

**方案 A（推荐）：在标准化空间计算异常权重**

```python
def weighted_mse_loss_v2(pred, target, sigma_0_phys, sigma_min, sigma_range,
                          sigma_mean, sigma_std, lambda_anomaly=8.0):
    """
    权重和 MSE 在同一空间（标准化空间）。
    异常阈值在标准化空间定义：> 1.0σ 以上视为异常区域。
    """
    sq_error = (pred - target) ** 2
    
    # 标准化空间的异常阈值：> 1σ 以上（覆盖 ~84% 的背景, < 16% 的异常）
    # 但在我们的分布中, 背景集中在 -0.22σ, 根在 +2.8σ
    # 使用中位数作为阈值更合理
    std_anomaly_threshold = 0.5  # 标准化空间: 0.5σ 以上 → 异常
    
    sigma_norm = ((sigma_0_phys - sigma_min) / (sigma_range + 1e-8)).clamp(0, 1)
    sigma_std = (sigma_norm - sigma_mean) / sigma_std
    anomaly_mask = (sigma_std > std_anomaly_threshold).float().unsqueeze(-1)
    
    # 降低权重比: 8:1（而非 15:1）
    weights = 1.0 + (lambda_anomaly - 1.0) * anomaly_mask
    return (weights * sq_error).mean()
```

**方案 B（更激进）：使用 focal-like loss 替代硬权重**

```python
def focal_mse_loss(pred, target, gamma=2.0, delta=0.5):
    """
    自适应加权: 难样本（高误差）自动获得更高权重。
    不需要预定义异常 mask。
    """
    abs_error = (pred - target).abs()
    # 误差越大, 权重越高（focal loss 的逆）
    weights = (abs_error / (abs_error.mean() + 1e-8)) ** gamma
    weights = weights.clamp(0.1, 10.0)  # 防止极端权重
    return (weights * (pred - target) ** 2).mean()
```

**方案 C（保守）：去掉加权, 回归简单 MSE + 增强物理约束**

```python
loss = F.mse_loss(pred, target) + 0.3 * physics_consistency_loss(...)
```

### 建议

**先用方案 C 验证基础能力**（去掉加权 loss 这个最大变量），拿到可用的 baseline 后再逐步引入方案 A 或 B。

## 2. 问题 #2（致命）：标准化分布严重非高斯

### 现象

```
sigma_stats: min=0.010, max=0.099
  → 归一化 [0,1]: mean=0.032, std=0.147
  → 标准化 N(0,1): 背景=-0.22σ, 根=+2.8σ, max=+6.6σ
```

### 根因

DDPM/DDIM 的数学基础假设数据近似 N(0,1)。但当前数据:

```
分布形状（标准化空间）:
  背景（96.4%）: 集中在 -0.22σ — 尖峰
  根（3.6%）:   散布在 +0.9σ ~ +6.6σ — 极长右尾
  
  均值 = 0（按构造）
  但方差的 99% 来自 3.6% 的根元素 — 重尾
```

这导致两个问题：
1. **前向加噪**: 尖峰 + 长尾分布加噪后不是 N(0,1)，DDPM 的 terminal distribution 假设被破坏
2. **x₀-prediction**: 对高 σ 值 (>3σ), 训练样本极少, 模型在该区域的预测完全不可靠

### 修复方案

**方案 A：对数变换压缩动态范围**

```python
# 用 log-ratio 替代线性归一化
# σ_norm = log(σ / σ_bg) / log(contrast_max)
# 这使 3x~10x 对比度映射到更均匀的 [0,1]

sigma_ratio = sigma_0_phys / (sigma_ref + 1e-8)  # 相对背景的比值
sigma_log = torch.log(sigma_ratio.clamp(0.5, 20.0))  # 对数空间
sigma_norm = (sigma_log - log_min) / (log_max - log_min)  # [0, 1]
```

**方案 B：分位数归一化（推荐）**

```python
# 用分位数映射使数据强制服从均匀/正态分布
from scipy import stats
# 计算 per-element CDF
sigma_uniform = stats.rankdata(all_sigmas) / len(all_sigmas)  # [0, 1] 均匀
# 转为 N(0,1)
from scipy.special import erfinv
sigma_std = np.sqrt(2) * erfinv(2 * sigma_uniform - 1)  # N(0,1)!
```

**方案 C：增加训练数据中根元素的比例**

```python
# data/generate_mixed_dataset.py:
# 当前 phantom 内含物占 ~3.6%。增加到 15-20%。
# 更简单的方案：在 dataloader 中做 class-balanced sampling
```

### 建议

**先用方案 C 快速试**（改数据生成参数，0 代码改动），观察 RE 是否改善。如果不够，再加方案 B。

## 3. 问题 #3（重要）：物理一致性权重过低

### 现象

```python
loss = loss_mse + 0.05 * loss_phys  # line 219
```

`loss_mse ≈ 0.2`, `loss_phys ≈ 0.05` → 物理 loss 占总 loss 的 `0.05*0.05/(0.2+...) ≈ 1.2%`。

### 根因

v4 设计文档 (`20260626DiffV4重构方案.md:665`) 建议 `λ_meas ≈ 0.01-0.1`, 但也说 **"物理一致性是唯一跨域不变的硬约束"**。当前 0.05 的下限使用使物理约束几乎无效。

物理一致性 loss 的意义：
- 如果模型预测高 σ 值处处都是 → V_pred = Δσ @ J_T 会产生巨大的测量电压 → phys_loss 会惩罚
- 这就是对抗"全预测根"模式坍塌的正确力量——但它权重太低了

### 修复方案

```python
# 提高到 0.3-0.5, 并加入自适应调度
lambda_phys = 0.3  # 从 0.05 提高到 0.3
loss = loss_mse + lambda_phys * loss_phys
```

预期 phys_loss 增加后, 模型不能再"全预测高 σ"而不受惩罚——因为测量电压会完全不匹配。

## 4. 问题 #4（重要）：DDIM 20 步采样跳过高 SNR 区域

### 现象

```
T=200, 20-step DDIM:
  stride = 200/20 = 10
  timesteps = [0, 10, 20, ..., 190]
```

### 根因

余弦调度的 SNR 分布极端不均：
- t=0-20: ᾱ ≈ 0.999-0.96, SNR=1000-23 → 信号主导, 几乎不需要去噪
- t=20-100: ᾱ ≈ 0.96-0.49, SNR=23-0.98 → **关键去噪区间**
- t=100-200: ᾱ ≈ 0.49-0.0, SNR=0.98-0 → 噪声主导

20 步 DDIM 中, [0,10,20,...] 只分配了 2 步给关键区间 (t=20-100), 分配了 4 步给几乎不需要去噪的区间 (t=0-20), 分配了 8 步给完全噪声的区间 (t=100-200)。

### 修复方案

**方案 A：非均匀 DDIM 步长**

```python
# 在 SNR 快速变化的区域（低 t）使用更密集的步长
def get_ddim_timesteps(T, n_steps, schedule='cosine'):
    if schedule == 'cosine':
        # 用二次函数扭曲: 更多步在低 t
        x = torch.linspace(0, 1, n_steps)
        x_warped = x ** 0.5  # sqrt: 密集在低 t
        timesteps = (x_warped * (T - 1)).long().tolist()
    return timesteps
```

**方案 B：增加 val_RE 的采样步数**

```python
# val_RE 监控用 50 步（不是 20）
sigma_pred = model.sample(V_val, n_steps=50)
```

### 建议

方案 B 零成本，先试。方案 A 需要改 DDIM。

## 5. 问题 #5（重要）：输出头 Linear 无约束 + 后处理 clamp 截断

### 现象

```python
# mesh_unet.py:128-131 — Linear 输出（无约束）
self.out_head = nn.Sequential(
    nn.Linear(h//2, h//4), nn.GELU(), nn.Dropout(dropout * 0.5),
    nn.Linear(h//4, 1),
)

# diff_eit.py:306-309 — 后处理 clamp
sigma_norm = sigma_std * self.sigma_std + self.sigma_mean
sigma_norm = sigma_norm.clamp(0, 1)
sigma_phys = sigma_norm * self.sigma_range + self.sigma_min
sigma_phys = sigma_phys.clamp(self.sigma_min, self.sigma_max)
```

### 根因

设计文档说"Tanh 输出 [-1,1]"但实际代码用了 Linear（无界）。这导致：
1. 模型可能输出 +10σ → clamp 到 [sigma_min, sigma_max] → 信息丢失
2. 梯度在 clamp 区域为零 → 模型收不到"你预测太极端了"的信号
3. 推理时所有极端值被截断, 但训练时不受约束

### 修复方案

```python
# 方案 A（温和）: Tanh 输出
self.out_head = nn.Sequential(
    nn.Linear(h//2, h//4), nn.GELU(), nn.Dropout(dropout * 0.5),
    nn.Linear(h//4, 1),
    nn.Tanh(),  # [-1, 1], 覆盖 ~±4σ 物理范围 → 约 [0, 0.07] S/m
)

# 方案 B（推荐）: Tanh × scale, 可配置
self.out_head = nn.Sequential(
    nn.Linear(h//2, h//4), nn.GELU(), nn.Dropout(dropout * 0.5),
    nn.Linear(h//4, 1),
    nn.Tanh(),
)
# 在 diff_eit.forward() 中:
# sigma_0_pred_std = self.denoiser(...) * self.out_scale  # scale=4.0 覆盖 ±4σ
```

### 7.2 `models/diff_eit.py` 改动

```python
# (3) forward() 使用分位数归一化替代线性标准化
# line 234-238 替换为:
def _normalize(self, sigma_phys):
    """分位数归一化: 物理 → [0,1] → N(0,1) via RankGauss"""
    sigma_norm = ((sigma_phys - self.sigma_min) / self.sigma_range).clamp(0, 1)
    # 用 pre-computed lookup table 做 RankGauss 变换
    # （训练前计算, 存为 buffer）
    sigma_std = self._rank_gauss_transform(sigma_norm)
    return sigma_std, sigma_norm

def _denormalize(self, sigma_std):
    """逆变换: N(0,1) → [0,1] → 物理"""
    sigma_norm = self._inverse_rank_gauss_transform(sigma_std)
    sigma_phys = sigma_norm * self.sigma_range + self.sigma_min
    return sigma_phys.clamp(self.sigma_min, self.sigma_max)
```
