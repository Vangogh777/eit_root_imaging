## 0. 定位：什么是"通用 EIT 算法"

当前 EIT 领域的一个核心问题是：大多数方法针对特定应用场景设计（医学肺成像、工业管道、植物根系等），换个对象就需要重新调参甚至重新设计网络。

一套**通用 EIT 算法**应当满足：

| 维度 | 要求 | DiffEIT 的回应 |
|------|------|---------------|
| **几何无关** | 同一套代码处理圆形/方形/任意 2D/3D 域 | 直接在 FEM 三角网格上操作，无 Grid 插值 |
| **对象无关** | 不依赖特定形状先验（根/肺/气泡/内含物） | 扩散模型学习通用 σ 分布，不对形状做假设 |
| **电极无关** | 适应不同电极数量和排列 | 测量编码器只依赖 n_meas，电极布局信息编码在 J 中 |
| **分辨率可变** | 换 mesh 分辨率不需要改网络 | 图网络基于节点拓扑，与网格细化程度无关 |
| **噪声鲁棒** | 不同 SNR 下稳定重建 | 扩散模型的随机性天然提供去噪能力 |
| **不确定性量化** | 给出重建置信度 | 多次采样方差 = 逐像素不确定性 |

**DiffEIT 的核心赌注**：将扩散模型部署在非结构化 FEM 网格上，用物理灵敏度信息（Jacobian）驱动条件注入，使得网络学到的是 EIT 反问题的**通用解空间结构**，而非某个特定数据集的统计规律。

## 3. 结构性问题诊断

### 🔴 致命: 条件注入仅发生在 L0

**现象**: 测量电压的条件注入（`time_mod` + `volt_mod`）只在 encoder 入口做了一次。L1、L2、bottleneck —— 这些决定重建全局结构的层 —— 完全感知不到测量信息。

**为什么这是通用性的致命伤**: 
- Bottleneck 只有 ~70 个节点，通过 Self-Attention 建模全局上下文。它要回答的问题是："整个域中有哪些异常区域、它们的对比度如何、边界在哪里"
- 但 bottleneck **看不到电压**，只能从 L0 逐层池化下来的特征中间接推断
- EIT 反问题的核心困难是**不同 σ 分布可以产生几乎相同的 V**（严重病态）。不给深层提供电压条件，等于让模型在无限多解空间中裸奔
- 对于通用算法来说尤其危险：不同成像对象（医学 vs 工业 vs 根部）的 σ 分布差异巨大，深层如果不能直接访问测量值，会倾向于记住训练分布的统计先验而不是真正求解反问题

**标准做法对比**: Stable Diffusion、ControlNet、Imagen 等条件扩散模型，条件通过 cross-attention 注入**每一个 UNet 层级**。这不是工程偏好，而是信息论的必要——扩散的每一步去噪都需要条件来约束解空间。

### 🔴 缺失: 灵敏度空间信息 (C2) — 通用性的关键

**问题**: EIT 的空间灵敏度差异极大。对于环形电极桶，中心区域的灵敏度只有边界区域的 ~1/100。这意味着：
- 边界附近的小扰动会产生大电压变化 → 容易重建
- 中心区域的大扰动可能只产生微小电压变化 → 极难重建

当前模型对全部 N 个元素**一视同仁**。它对"这个位置容易被感知吗"完全没有概念。

**为什么这是通用性的关键**: 灵敏度分布是 EIT **物理本身的属性**，与成像对象无关。无论你用它看肺、看根、看管道，Jacobian 矩阵都编码了同一套物理——灵敏度场。将 J^T·V 和 J_energy 作为特征注入，相当于给模型提供了**物理先验**而非数据先验。物理先验是可以跨场景迁移的。

### 🟡 次优: 从纯噪声起步 — 浪费通用先验

**问题**: σ 的值域通常很窄（例如背景 σ₀ 占 90%+ 的元素）。从 N(0, I) 起步浪费大量扩散步在"发现背景值"上。更严重的是，对于通用算法来说，不同场景的背景 σ 可能不同（医学 ~0.3 S/m，工业 ~10⁷ S/m，土壤 ~0.01 S/m），模型需要从噪声中"推断"正确的背景范围——这是不必要的负担。

### 🟡 次优: SimpleGNN — 静态聚合限制跨场景泛化

`SimpleGNNLayer` 用固定边权重 scatter_add。每条边的权重仅由图的静态结构决定，与当前的 σ_t 状态无关。这意味着：
- 一个元素在扩散早期（高噪声）和后期（接近干净）接收邻居信息的方式完全相同
- 对于通用算法，不同场景下的"有效感受野"应该不同（高对比度场景需要更大范围的消息传递）

GATv2 的动态注意力可以根据节点当前特征决定关注哪个邻居——这对跨场景泛化至关重要。

### 🟡 次优: FPS 池化忽略拓扑

FPS 基于欧氏距离选锚点，不考虑 FEM 元素之间的连通性。在通用场景中这是隐患——两个空间接近但被绝缘介质隔开的元素可能被错误聚类，混淆不同介质的边界。

## 4. 改进方案（按预期收益排序）

### 🥇 Tier 1: 条件注入到所有层级

**解决问题**: 深层看不见测量值 → 盲猜全局结构

**预期收益**: 最大。这是当前架构最致命的结构缺陷，修复后深层网络可以基于电压信息做全局结构决策。

**实现**: 为每一层添加独立的 time/voltage modulation：

```python
# mesh_unet.py — __init__:
self.time_mods = nn.ModuleList([
    nn.Linear(time_dim, hidden_dim),     # L0
    nn.Linear(time_dim, hidden_dim * 2), # L1
    nn.Linear(time_dim, hidden_dim * 2), # L2
    nn.Linear(time_dim, hidden_dim * 2), # BN
])
self.volt_mods = nn.ModuleList([
    nn.Linear(voltage_dim, hidden_dim),
    nn.Linear(voltage_dim, hidden_dim * 2),
    nn.Linear(voltage_dim, hidden_dim * 2),
    nn.Linear(voltage_dim, hidden_dim * 2),
])

# forward() — 每层 encoder 入口:
x0 = x0 + self.time_mods[0](t_emb).unsqueeze(1) + self.volt_mods[0](v_emb).unsqueeze(1)
x1 = x1 + self.time_mods[1](t_emb).unsqueeze(1) + self.volt_mods[1](v_emb).unsqueeze(1)
x2 = x2 + self.time_mods[2](t_emb).unsqueeze(1) + self.volt_mods[2](v_emb).unsqueeze(1)
x_bn = x_bn + self.time_mods[3](t_emb).unsqueeze(1) + self.volt_mods[3](v_emb).unsqueeze(1)
# decoder 每层同理
```

**更优方案 — FiLM**（推荐）:

```python
class FiLM(nn.Module):
    """Feature-wise Linear Modulation: γ·x + β, 逐层独立条件注入"""
    def __init__(self, cond_dim: int, feat_dim: int):
        super().__init__()
        self.gamma = nn.Sequential(
            nn.Linear(cond_dim, feat_dim), nn.Tanh())
        self.beta = nn.Sequential(
            nn.Linear(cond_dim, feat_dim), nn.Tanh())
        # 初始化 γ≈1, β≈0：条件初始不影响特征，让网络逐渐学会利用
        nn.init.zeros_(self.gamma[0].weight)
        nn.init.zeros_(self.beta[0].weight)

    def forward(self, x, cond):
        return self.gamma(cond).unsqueeze(1) * x + self.beta(cond).unsqueeze(1)

# 每层: x = film_t(x, t_emb) + film_v(x, v_emb)
```

FiLM 优于简单加法：γ 可以放大或抑制特定通道，β 可以做偏移——比纯加法多了乘法交互。

**Bottleneck 更激进的方案 — Cross-Attention**:

```python
# BN 层: 用 Cross-Attention 替代 FiLM
# 70 个 mesh 节点作为 query, 多个可学习的 latent token 作为 key/value
# 让 bottleneck 显式地从电压条件中提取全局信息
self.bn_cross_attn = nn.MultiheadAttention(hidden_dim*2, num_heads=4, batch_first=True)
# V_cond 展成 (B, n_latents, voltage_dim) 作为 key/value
x_bn, _ = self.bn_cross_attn(x_bn, v_latents, v_latents)
```

**改动量**: ~40 行（FiLM）或 ~60 行（FiLM + Cross-Attn）。不改外部接口。

### 🥈 Tier 2: 灵敏度特征注入 (C2)

**解决问题**: 模型不知道每个 mesh 元素对测量有多大影响

**预期收益**: 大。这是 EIT 物理特有的信息，几乎零成本，且是**可跨场景迁移的物理先验**。

**实现**:

```python
# diff_eit.py — setup_mesh() 中注册 Jacobian 相关缓冲:
self.register_buffer('J_T', jacobian.T.float().contiguous())  # (N, 208)
self.register_buffer('J_energy', (jacobian ** 2).sum(dim=0).float())  # (N,)

# forward() 中计算逐样本灵敏度特征:
J_T_V = (V[:, 0, :] @ self.J_T.T)  # (B, N) — V 反投影到 mesh
J_energy = self.J_energy.unsqueeze(0).expand(B, -1)  # (B, N)

# node_proj 输入增加 2 通道:
# 当前: cat(σ_t, v_node, pe, radius) → 1+512+35+1 = 549
# 改进: cat(σ_t, v_node, pe, radius, J_T_V, J_energy) → 551
```

**J^T·V 的物理含义**: 它本质上是 GREIT/一步线性反演的核心操作——对每个元素，把边界电压通过灵敏度反向投影到空间域。值为正表示「该位置的电导率可能高于背景」，为负表示「可能低于背景」。给扩散模型这个特征，相当于提供了**传统物理方法的"第一印象"**作为条件先验。

**通用性价值**: J 矩阵编码的是 EIT 物理（电极布局 + 域几何），与成像对象无关。模型学到「如何结合灵敏度信息做去噪」后，换一个 mesh 几何或电极配置，只需要重新计算 J 即可迁移。

**改动量**: ~30 行。不改网络结构（仅增加 2 个输入通道），不增加训练时间。

### 🥉 Tier 3: 残差扩散 Warm-Start (C3)

**解决问题**: 从纯噪声起步浪费容量；不同场景的背景 σ 不同

**预期收益**: 大。收敛更快 + 采样步数可减半 + 天然的消融实验（deterministic → +diffusion 的增益）。

**方案 A: 零参数线性最小二乘**（推荐先试）:

```python
# 预计算伪逆: J_pinv = J^T (J J^T + λI)^{-1}  # (N, 208)
# 一步粗估计:
delta_V = V - J @ sigma_ref         # 测量残差
sigma_warm = sigma_ref + J_pinv @ delta_V  # (N,) GREIT 式重建

# 扩散目标改为残差:
residual = sigma_true - sigma_warm  # 方差 << 全 σ 方差
r_T ~ N(0, σ_residual * 0.5)       # 从减小了的噪声起步
sigma_final = sigma_warm + r_0
```

**方案 B: 可训练的 LightGNN**（更好但需额外训练）:

2 层 SimpleGNN, ~1M 参数, 先单独训 50 epoch 达到 RE≈0.25。然后将它的输出作为 warm-start，特征作为扩散的额外条件。

**通用性价值**: 线性最小二乘 warm-start 只需要换 J_pinv（由 mesh 和电极决定），对新几何零成本适配。这让 DiffEIT 可以在新场景下快速部署：先跑一步线性反演得到粗估计，然后用扩散细化。

**改动量**: ~50 行（方案 A）或 ~150 行（方案 B）。

### 🏅 Tier 4: GNN 层升级 (SimpleGNN → GATv2)

**解决问题**: 静态消息传递，无法根据去噪进度动态调整感受野

**预期收益**: 中-大。动态注意力对跨场景泛化尤其有价值。

GATv2 已实现在 `models/conv_spatial_eit.py:235`，可直接替换：

```python
# mesh_unet.py MeshConvBlock:
# 当前:
self.gnn = SimpleGNNLayer(in_dim, out_dim, dropout=dropout, edge_dim=edge_dim)
# 替换为:
from models.conv_spatial_eit import GATv2Layer
self.gnn = GATv2Layer(in_dim, out_dim, dropout=dropout, n_heads=4, edge_dim=edge_dim)
```

**核心差异**:

| 特性 | SimpleGNNLayer | GATv2Layer |
|------|:---:|:---:|
| 聚合权重 | 静态（仅依赖图结构） | 动态（sender + receiver 特征决定） |
| 边特征利用 | sigmoid 门控缩放 | 注意力 logit 偏置 |
| 多头 | 无 | 4 头 → 不同子空间的不同注意力模式 |
| 归一化 | 无 | per-destination softmax → 防止 hub 节点过载 |
| 参数量 | 1× | ~1.1× |

**为什么 GATv2 对通用性重要**: 在扩散早期（高噪声），模型需要大范围平滑，注意力应该均匀分布；在扩散后期（接近收敛），模型需要锐化边界，注意力应该聚焦于相似 σ 的邻居。GATv2 的动态注意力可以自适应地调整这种"有效感受野"，而 SimpleGNN 的静态聚合做不到。

**注意**: GATv2 要求 `out_dim` 能被 `n_heads` 整除。当前 hidden_dim=384, heads=4 → head_dim=96 ✅。但 L1 的 768/4=192 ✅，L2 768/4=192 ✅。

**改动量**: 3 行 import + 替换类名。约 5% 参数增量。显存增加约 10-15%。

### Tier 6: 训练/推理改进

| 改进 | 说明 | 收益 | 通用性影响 |
|------|------|:---:|:---:|
| **余弦噪声调度** | 替代线性 β。早期保留更多信号，对窄值域 EIT 更友好 | 小-中 | 不同 σ 范围受益一致 |
| **x₀-prediction** | 直接预测干净 σ，输出头加 sigmoid 约束到物理范围 | 中 | 防止生成物理不可能的 σ |
| **物理梯度引导 (C4)** | DDIM 每步加 ∇||V - J·(σ̂₀-σ_ref)||² | 中-大 | 纯物理约束，零数据依赖 |
| **多频 Cross-Attn 编码** | 复用 `FrequencyCrossAttention` 替代均值 | 小-中 | 利用频间差异（物理信息） |
| **梯度检查点** | `torch.utils.checkpoint` 减少显存 | — | 允许更深/更宽网络 |

#### 余弦噪声调度

```python
def cosine_beta_schedule(timesteps, s=0.008):
    steps = timesteps + 1
    x = torch.linspace(0, timesteps, steps)
    alphas_cumprod = torch.cos(((x / timesteps) + s) / (1 + s) * torch.pi * 0.5) ** 2
    alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
    betas = 1 - (alphas_cumprod[1:] / alphas_cumprod[:-1])
    return torch.clamp(betas, max=0.999)
```

#### x₀-prediction（推荐与 Tier 3 配合）

```python
# 输出头改为:
out_head = nn.Sequential(
    nn.Linear(hidden//2, hidden//4), nn.GELU(),
    nn.Linear(hidden//4, 1),
    nn.Sigmoid()  # 保证输出在 [0, 1]
)
# 训练: 直接监督 σ, loss = MSE(σ_pred * (σ_max-σ_min) + σ_min, σ_true)

# DDIM 采样时 denoiser 直接返回 σ₀_hat, 无需 ε 反算, 减少数值误差:
eps_pred = (sigma_t - sqrt_alpha_bar * sigma_0_hat) / sqrt(1 - alpha_bar)
sigma_next = sqrt_alpha_next * sigma_0_hat + sqrt(1 - alpha_next) * eps_pred
```

#### 物理梯度引导 (C4)

with torch.enable_grad():
    sigma_0_hat.requires_grad_(True)
    V_pred = J @ (sigma_0_hat - sigma_ref)
    phys_loss = F.mse_loss(V_pred, V_measured)

# 修改预测的 epsilon:
epsilon_guided = epsilon_pred + w_phys(t) * grad_phys

# w_phys 调度: 早期大 (0.3), 后期小 (0.02)

## 7. 通用性设计原则总结

上述改进背后有五条设计原则，它们共同构成了通用 EIT 算法的骨架：

1. **物理条件优于数据条件** — J^T·V、J_energy 来自 Maxwell 方程，不依赖训练数据分布。换了成像对象，物理不变。

2. **几何无关 = 图神经网络** — 在 FEM 网格上直接做 GNN，不做 Grid 插值。2D bucket、3D 胸腔、方形管道……只要给 mesh 就能跑。

3. **多层条件注入 = 解空间约束** — 扩散的每一层去噪都需要测量信息来收窄解空间。只在 L0 注入条件相当于让深层自行脑补——那是记住训练分布，不是求解反问题。

4. **残差建模 = 先验分离** — 传统方法（GREIT/GN）提供粗结构 → 扩散补充细节。两者的分工清晰：传统方法保证物理可行性，扩散模型补充高频信息和不确定性估计。

5. **物理引导 > 纯数据驱动** — 在采样阶段用 Jacobian 测量一致性做引导，不依赖任何训练数据。这是在新场景下保证重建质量的最后防线。
