## 3. S-1: GATv2 注意力图卷积层

### 3.1 作用

将当前的 `SimpleGNNLayer`（sum 聚合，边特征通过固定 sigmoid 门控调制）替换为 **GATv2 多头注意力图卷积层**。GATv2 (2022 ICLR) 改进了原始 GAT，解决了 GAT 的静态注意力问题（所有邻居的注意力排序只取决于 query 节点，不取决于 key 节点），使得注意力真正动态：

```
SimpleGNN:   α_ij = sigmoid(W_e · e_ij)           ← 静态，不依赖节点特征
GATv2:       α_ij = softmax(a([Wh_i || Wh_j]))     ← 动态，同时依赖 i 和 j
```

### 3.2 收益

| 收益项 | 说明 | 预期改善 |
|--------|------|:--------:|
| 动态边权重 | 依赖双方节点特征的注意力权重，非固定门控 | RE ↓ 0.02 |
| 多头注意力 | 4 个头并行关注不同关系模式 | RE ↓ 0.01 |
| 边特征融合 | 作为注意力偏置直接参与注意力计算 | RE ↓ 0.01 |
| **累计** | | **RE ↓ 0.03-0.05** |

### 3.3 修改详情

#### 3.3.1 文件: `models/conv_spatial_eit.py`

**当前行 ~65-114**: `SimpleGNNLayer` 类定义

**变更**: 保留 `SimpleGNNLayer` 作为基线（不删除），新增 `GATv2Layer` 类。在 `ConvSpatialEIT.__init__` 和 `setup_mesh` 中通过 `self.use_gat` 参数控制使用哪一层。

```python
# ≈ 行 65 后新增

class GATv2Layer(nn.Module):
    """
    GATv2 图注意力层 (改进版 GAT，2022 ICLR)
    
    GAT 原始问题: 注意力系数 α_ij = a([Wh_i || Wh_j])
    静态排序: 对所有 j, α_ij 的排序不依赖于 j（因为 a 是线性层后 LeakyReLU）
    
    GATv2 改进: α_ij = a(LeakyReLU([Wh_i || Wh_j]))
    动态排序: a 中的全连接层在拼接特征之后，注意力取决于双方
    """
    def __init__(self, in_dim: int, out_dim: int, n_heads: int = 4,
                 dropout: float = 0.1, edge_dim: int = 0):
        super().__init__()
        self.n_heads = n_heads
        self.head_dim = out_dim // n_heads
        assert out_dim % n_heads == 0, f"out_dim({out_dim}) must be divisible by n_heads({n_heads})"

        # Q/K/V 投影（通过 Linear 实现）
        self.W_q = nn.Linear(in_dim, out_dim, bias=False)
        self.W_k = nn.Linear(in_dim, out_dim, bias=False)
        self.W_v = nn.Linear(in_dim, out_dim, bias=False)

        # GATv2 注意力 MLP: 在拼接 Q_src || K_dst 后过 MLP
        # 这比 GAT 的线性层 + LeakyReLU 更动态
        attn_in = self.head_dim * 2 + edge_dim
        self.a = nn.Sequential(
            nn.Linear(attn_in, self.head_dim, bias=False),
            nn.LeakyReLU(0.2),
            nn.Linear(self.head_dim, 1, bias=False),
        )

        self.dropout = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor, edge_idx: torch.Tensor,
                edge_weight: torch.Tensor,
                edge_feat: Optional[torch.Tensor] = None) -> torch.Tensor:
        """
        参数:
            x: (B, N, D_in) 节点特征
            edge_idx: (2, E) 边索引 [src, dst]
            edge_weight: (E,) 边权重（归一化系数）
            edge_feat: (E, edge_dim) 边特征（可选）
        返回:
            (B, N, D_out) 更新后的节点特征
        """
        B, N, D = x.shape
        device = x.device
        E = edge_idx.shape[1]
        src, dst = edge_idx  # (E,)

        # Q/K/V 投影 → 多头
        Q = self.W_q(x).view(B, N, self.n_heads, self.head_dim)  # (B, N, H, hd)
        K = self.W_k(x).view(B, N, self.n_heads, self.head_dim)
        V = self.W_v(x).view(B, N, self.n_heads, self.head_dim)

        # 对每条边取 src 和 dst 的特征
        Q_src = Q[:, src]  # (B, E, H, hd)
        K_dst = K[:, dst]  # (B, E, H, hd)

        # GATv2: 拼接 Q_src || K_dst || edge_feat → MLP → 注意力系数
        attn_input = torch.cat([Q_src, K_dst], dim=-1)  # (B, E, H, 2*hd)
        if edge_feat is not None:
            ef = edge_feat.unsqueeze(0).unsqueeze(2).expand(B, -1, self.n_heads, -1)
            attn_input = torch.cat([attn_input, ef], dim=-1)

        e = self.a(attn_input).squeeze(-1)  # (B, E, H)

        # 掩码无效边 (edge_weight=0) + softmax
        e = e.masked_fill(edge_weight.unsqueeze(0).unsqueeze(-1) == 0, float('-inf'))
        alpha = F.softmax(e, dim=1)  # (B, E, H)
        alpha = self.dropout(alpha)

        # 消息聚合: V_src * α → scatter_add 到 dst
        V_src = V[:, src]  # (B, E, H, hd)
        msg = V_src * alpha.unsqueeze(-1)  # (B, E, H, hd)

        x_agg = torch.zeros(B, N, self.n_heads, self.head_dim,
                            device=device, dtype=msg.dtype)
        x_agg.scatter_add_(
            1,
            dst.view(1, -1, 1, 1).expand(B, -1, self.n_heads, self.head_dim),
            msg,
        )
        x_agg = x_agg.view(B, N, -1)  # (B, N, D_out)
        return x_agg
```

## 4. S-2: 多频 Cross-Attention 融合层

### 4.1 作用

将当前的 `freq_fusion = nn.Conv2d(6, 1, 1, bias=False)` 替换为 **自注意力融合层**。

当前: `6 个频率 → 1×1 Conv → 1 个融合通道`

问题: 1×1 Conv 等价于 `f_out = Σ w_f · f_f`，即 6 个频率的线性加权组合。无法建模频率间的非线性交互（例如：低频信号决定背景形状、高频信号决定边界细节）。

改进: 将 13×16 电压图展平为 208 个 token，每个 token 的初始特征为 6 维（6 个频率）。用自注意力在 token 间建模全局关系后，投影回单频。

### 4.2 收益

| 收益项 | 说明 | 预期改善 |
|--------|------|:--------:|
| 非线性融合 | 自注意力可以建模频率间的复杂交互 | RE ↓ 0.005-0.01 |
| 全局感受野 | 每个 token attend 所有 208 个测量位置 | RE ↓ 0.005 |
| 位置编码 | 注入电极位置，告诉模型"这个测量来自哪对电极" | RE ↓ 0.005 |
| **累计** | | **RE ↓ 0.01-0.02** |

### 4.3 修改详情

#### 4.3.1 文件: `models/conv_spatial_eit.py`

**当前行 ~153**: `self.freq_fusion = nn.Conv2d(...)`

**变更**: 替换为 `FrequencyCrossAttention` 模块

```python
# ≈ 行 153 替换

class FrequencyCrossAttention(nn.Module):
    """
    频率交叉注意力融合 v1
    
    架构:
        6 频 13×16 → Conv1x1 投影到 d_model → 展平为 208 tokens
        → 自注意力 (QKV) → 恢复 13×16 → Conv1x1 投影到 1 通道
    
    设计理由:
        - 自注意力允许每个测量位置 attend 所有其他位置
          这对于 EIT 特别重要，因为每个测量是全场电导率的积分
        - 位置编码告诉模型"电流从电极对 (i,j) 注入"
    """
    def __init__(self, n_freq: int = 6, d_model: int = 64):
        super().__init__()
        self.d_model = d_model

        # 输入投影: 6 通道 → d_model 通道
        self.proj_in = nn.Conv2d(n_freq, d_model, 1, bias=False)
        # 可学习位置编码 (13×16 网格位置)
        self.pos_embed = nn.Parameter(torch.randn(1, d_model, 13, 16) * 0.02)

        # 自注意力
        self.q_proj = nn.Linear(d_model, d_model, bias=False)
        self.k_proj = nn.Linear(d_model, d_model, bias=False)
        self.v_proj = nn.Linear(d_model, d_model, bias=False)
        self.scale = d_model ** -0.5

        # 输出投影: d_model → 1 通道
        self.proj_out = nn.Conv2d(d_model, 1, 1, bias=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        参数:
            x: (B, 6, 13, 16) 多频电压图
        返回:
            (B, 1, 13, 16) 融合后的电压图
        """
        B = x.shape[0]

        # 投影到 d_model 空间 + 位置编码
        h = self.proj_in(x) + self.pos_embed  # (B, d_model, 13, 16)

        # 展平为 token 序列
        h_flat = h.view(B, self.d_model, -1)         # (B, d_model, 208)
        h_flat = h_flat.transpose(1, 2)               # (B, 208, d_model)

        # 自注意力
        Q = self.q_proj(h_flat)                       # (B, 208, d_model)
        K = self.k_proj(h_flat)
        V = self.v_proj(h_flat)

        attn = (Q @ K.transpose(-2, -1)) * self.scale
        attn = F.softmax(attn, dim=-1)                # (B, 208, 208)

        out = attn @ V                                 # (B, 208, d_model)

        # 恢复 13×16 空间
        out = out.transpose(1, 2).view(B, self.d_model, 13, 16)
        out = self.proj_out(out)                       # (B, 1, 13, 16)
        return out
```

## 5. S-3: 编码器容量升级 + SE 通道注意力

### 5.1 作用

提升 ConvEncoder 的容量和表示能力，同时引入跳跃连接将中间层特征传递到 GNN 层。

当前编码器:
```
stem(base_ch=48) → stage1(base_ch*2=96) → stage2(base_ch*4=192) → out_proj(128)
输出: (B, 128, 13, 16)  总参数量: ~190K
```

改进后的编码器:
```
stem(base_ch=96) → stage1(192) → stage2(384) → SE(384) → out_proj(256)
输出: (B, 256, 13, 16)  总参数量: ~560K
                 ↘ 跳跃连接 → GridSampler → concat → GNN
```

### 5.2 收益

| 收益项 | 说明 | 预期改善 |
|--------|------|:--------:|
| 容量翻倍 | 输出通道 128→256，提升特征表达能力 | RE ↓ 0.01 |
| SE 注意力 | 通道自适应重校准，抑制无关通道 | RE ↓ 0.005 |
| 跳跃连接 | 浅层空间信息传递到 GNN，保留高分辨率细节 | RE ↓ 0.005 |
| **累计** | | **RE ↓ 0.02-0.03** |

### 5.3 修改详情

#### 5.3.1 文件: `models/conv_spatial_eit.py`

**当前行 ~20-60**: `ConvEncoder` 和 `SEModule`（新增）

```python
# ≈ 行 20-60 替换

class SEModule(nn.Module):
    """Squeeze-and-Excitation 通道注意力"""
    def __init__(self, channels: int, reduction: int = 16):
        super().__init__()
        self.gap = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction, bias=False),
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels, bias=False),
            nn.Sigmoid(),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        b, c, _, _ = x.shape
        y = self.gap(x).view(b, c)
        y = self.fc(y).view(b, c, 1, 1)
        return x * y
```

**修改 `ConvEncoder`**:

```python
class ConvEncoder(nn.Module):
    """
    Conv2D 编码器 v3
    - base_ch: 48 → 96（容量翻倍）
    - 新增 SE 通道注意力
    - 返回多级特征（跳跃连接用）
    
    输出:
        out_feat: (B, 256, 13, 16) 编码特征
        skip_feats: [(B, 96, 13, 16), (B, 192, 13, 16)] 中间特征
    """
    def __init__(self, in_channels: int = 1, base_ch: int = 96):
        super().__init__()
        # 注意: out_proj 输出 256 而不是 128
        self.out_channels = base_ch * 2 + 64  # = 256 当 base_ch=96
        
        self.stem = nn.Sequential(
            nn.Conv2d(in_channels, base_ch, 3, padding=1, bias=False),
            nn.BatchNorm2d(base_ch),
            nn.ReLU(inplace=True),
        )

        self.stage1 = nn.Sequential(
            nn.Conv2d(base_ch, base_ch * 2, 3, padding=1, bias=False),
            nn.BatchNorm2d(base_ch * 2),
            nn.ReLU(inplace=True),
            ResBlock(base_ch * 2),
            ResBlock(base_ch * 2),
        )

        self.stage2 = nn.Sequential(
            nn.Conv2d(base_ch * 2, base_ch * 4, 3, padding=1, bias=False),
            nn.BatchNorm2d(base_ch * 4),
            nn.ReLU(inplace=True),
            ResBlock(base_ch * 4),
        )

        # SE 通道注意力（stage2 输出后）
        self.se = SEModule(base_ch * 4)

        # 输出投影: base_ch*4 → out_channels
        self.out_proj = nn.Sequential(
            nn.Conv2d(base_ch * 4, self.out_channels, 1, bias=False),
            nn.BatchNorm2d(self.out_channels),
            nn.ReLU(inplace=True),
        )

    def forward(self, x: torch.Tensor):
        f0 = self.stem(x)       # (B, base_ch, 13, 16)
        f1 = self.stage1(f0)    # (B, base_ch*2, 13, 16)
        f2 = self.stage2(f1)    # (B, base_ch*4, 13, 16)
        f2 = self.se(f2)        # 通道重校准
        out = self.out_proj(f2) # (B, out_channels, 13, 16)
        # 跳跃连接：返回 stage1 和 stage2 的特征
        return out, [f1, f2]
```

```python
gnn_in_dim = self.encoder.out_channels + self.pos_dim
```

**在 `forward` 中**（行 ~245-265）:

#### 6.2.3 边缘加权 MSE — 文件: `training/loss.py` 或 `train_conv_spatial.py`

**新增损失函数**:

```python
def edge_weighted_mse(pred: torch.Tensor, target: torch.Tensor,
                       sigma_soil: float = 0.01,
                       sigma_root: float = 0.05) -> torch.Tensor:
    """
    边缘加权 MSE 损失
    
    核心思路:
        EIT 重建的困难区域是"过渡区"（从土壤到根的边界）
        给过渡区单元更高的权重，迫使模型更关注边界精度
    
    过渡区判定: target ∈ [1.2×σ_soil, 0.9×σ_root]
    权重: 过渡区 ×3，其他区域 ×1
    """
    low = sigma_soil * 1.2
    high = sigma_root * 0.9
    edge_mask = (target > low) & (target < high)
    weights = torch.where(edge_mask, 3.0, 1.0)
    loss = (weights * (pred - target).pow(2)).mean()
    return loss
```

**在 `train_conv_spatial.py` 中使用**:

```python
# ← 在阶段 1 中，criterion = nn.MSELoss()
# 改为：
criterion = nn.MSELoss()             # 验证集用普通 MSE
train_criterion = edge_weighted_mse   # 训练集用边缘加权
# 训练循环中：loss = train_criterion(out['sigma'], S)
```

#### 6.2.4 电压掩码数据增强 — 文件: `train_conv_spatial.py`

```python
# ← 在 forward 之前：
def voltage_masking(V: torch.Tensor, mask_ratio: float = 0.15) -> torch.Tensor:
    """
    电压通道随机掩码增强
    
    作用:
        随机掩码 15% 的测量通道 → 迫使模型从部分信息恢复全局
        类似于 MAE 的掩码策略，增强泛化性
    
    不影响:
        测试/验证时不进行掩码
    """
    if self.training and mask_ratio > 0:
        mask = torch.rand_like(V) > mask_ratio
        return V * mask
    return V

# 在训练循环中：
V = voltage_masking(V, mask_ratio=0.15)  # 随机掩码 15% 通道
```

## 9. 风险与回退

### 9.1 风险矩阵

| 风险 | 概率 | 影响 | 缓解 | 回退 |
|------|:----:|:----:|------|:----:|
| GATv2 显存不足 (OOM) | 中 | 高 | 降 n_heads=2；增大 chunk_size 分块 | 设 `use_gat=False` |
| CrossAttn 不收敛 | 低 | 中 | 添加 LayerNorm；降低 lr | 回退到 1×1 Conv |
| Encoder 升级后梯度爆炸 | 低 | 中 | 梯度裁剪 5.0；降低 lr | 回退到 base_ch=48 |
| EMA 导致保存/加载兼容问题 | 低 | 低 | 分离保存 model 和 ema 权重 | 关闭 EMA |
| 多项改进叠加后性能下降 | 中 | 高 | 逐项回退定位问题 | 按 S-1→S-4 倒序回退 |

### 9.2 回退策略

每个 S-x 都是独立模块，通过以下方式可独立开关：

```python
# S-1: GATv2
model = ConvSpatialEIT(..., use_gat=False)  # 使用 SimpleGNN

# S-2: Cross-Attention
model.freq_fusion = nn.Conv2d(6, 1, 1, bias=False)  # 替换回线性融合

# S-3: 编码器升级
model.encoder = ConvEncoder(in_channels=1, base_ch=48)  # 替换回 v2

# S-4: 训练增强
# 在 train_conv_spatial.py 中注释掉对应代码块
```
